## 빠진 기능 — 만들 순서

남은 것은 could 하나(일부)입니다.

- [could] 목록·쿼리: 기준선 비교(과거 시점 대비 변경 표시), partial  (S06 | 빌드: 툴바 '기준선'(어제·1주 전·한 달 전·날짜 지정): 그날 0시 뒤 바뀐 셀에 표시와 그때 값(작업 기록에서 되짚음), 그 뒤 생긴 작업에 '새로 생김'. 보기에 저장. 그때는 조건에 맞았지만 지금은 빠진 작업은 보이지 않음)

- 빠진 부분: 그때는 목록 조건에 맞았지만 지금은 빠진 작업(예: 그 뒤 닫힌 작업)을 "빠짐"으로 보여 주는 것. 서버(`query/Baselines.java`)는 지금 페이지의 행만 저널로 되짚으므로, 그때의 조건을 그때의 값으로 다시 평가하는 쿼리가 따로 필요합니다. 기준선이 켜진 동안 합계·그룹 건수도 지금 값 기준입니다.
- 지난 보고서의 "REST API 항목의 약 120개 경로"는 features.csv를 고치면서 사라졌습니다. 지금 컨트롤러 매핑은 173개(dev 전용 1개 포함)입니다(`replica/backend.md`).

지난 보고서에서 빠진 목록에 있다가 이번에 끝난 것: Gantt 라벨 위치, 키보드 단축키, PDF 내보내기(표·보고서·Gantt), 권한 보고서, 속성 강조 표시, REST API(사내 연동용 토큰·OpenAPI·버전 정책), 웹훅, 내부 코멘트, 프로젝트 복사(이상 no → yes), 다크 모드·고대비 테마, 활동 필터·정렬 순서, 프로젝트 개요 위젯 대시보드(이상 partial → yes), 기준선 비교(no → partial).
