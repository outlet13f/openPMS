## 1. 개요

### 1.1 목적

이 문서는 openPMS가 갖춰야 할 기능 요구사항과 비기능 요구사항, 제약사항을 정의합니다. openPMS는 OpenProject 17.9.1 Community Edition의 작업 관리·계획 기능을 사내용으로 다시 구현한 시스템입니다. 이 문서의 요구사항 ID는 02-요구사항추적표에서 화면·API·테스트와 연결합니다.

### 1.2 범위

범위는 **작업 패키지 핵심과 계획 뷰**입니다. 프로젝트, 멤버·권한, 작업 패키지(유형·상태·워크플로·사용자 정의 필드), 목록과 필터·저장된 보기, 상세 화면, 활동·코멘트, 관계·계층, 일정과 진행률, Gantt, 보드, 캘린더·팀 플래너, 알림, 검색, 관리 기능을 포함합니다.

요구사항의 원천은 `replica/features.csv`의 기능 행입니다. 전체 161행 중 범위 밖(skip) 20행을 뺀 **141개**를 기능 요구사항으로 정의합니다.

### 1.4 현재 상태 기준
