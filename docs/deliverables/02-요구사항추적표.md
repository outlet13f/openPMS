## 1. 개요

### 1.1 목적

01-요구사항정의서의 각 요구사항이 어느 화면에서 제공되고, 어떤 API 경로로 처리되며, 어떤 자동 테스트로 검증되는지 연결합니다. 반대 방향(테스트·경로·화면 → 요구사항)도 함께 실어 빠진 연결과 요구사항 없는 구현을 찾을 수 있게 합니다.
