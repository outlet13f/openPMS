## 1. 이 매뉴얼에 대하여

### 1.1 목적

openPMS는 사내에서 프로젝트와 작업을 관리하는 웹 시스템입니다. 이 매뉴얼은 일반 사용자와 프로젝트 관리자가 openPMS로 하는 일을 순서대로 설명합니다. 시스템 관리자 전용 기능(관리 메뉴)은 10 운영자 매뉴얼(`10-운영자매뉴얼.md`)의 "관리 화면 운영 절차"에서 다루며, 이 매뉴얼에서는 사용자에게 영향을 주는 부분만 짧게 언급합니다.

### 1.2 표기 규칙

| 표기 | 뜻 |
| --- | --- |
| **굵은 글씨** | 화면에 보이는 버튼·메뉴·항목 이름(화면 문구 그대로) |
| A › B | A 메뉴(또는 화면) 안의 B |
| ⋯ | 더 보기 메뉴 버튼(점 세 개 아이콘) |
| `글자` | 주소창에 입력하는 주소 등 |
| 개선 진행 중 | 1.0에서 바뀌고 있던 기능에 붙인 표시. 1.1에서 해당 기능(목록 그룹화·합계, 보드 개선, 날짜 형식)을 모두 설명했으므로 지금은 쓰지 않음 |
| 확인 필요 | 운영 환경에 따라 다를 수 있어 담당자 확인이 필요한 부분 |

### 1.3 이용 환경

- 웹 브라우저로 회사가 안내한 openPMS 주소에 접속합니다. 지원 브라우저 목록은 **확인 필요**(운영 담당자에게 문의)입니다.
- 화면 폭이 768px보다 좁은 휴대폰에서는 목록이 카드 모양으로 바뀌고, 작업 상세가 화면 전체를 덮습니다. 1024px보다 좁으면 왼쪽 메뉴는 화면 왼쪽 위 **메뉴 열기** 버튼으로 엽니다.
- 화면 언어는 한국어입니다.

### 1.4 권한에 따라 다른 화면

같은 화면이라도 내 역할(권한)에 따라 버튼이 보이지 않을 수 있습니다. 예를 들어 작업을 만들 권한이 없으면 **만들기** 버튼이 없습니다. 기본 역할의 예시는 [14.1](#141-기본-역할별로-할-수-있는-일)을 참고하세요. 역할은 시스템 관리자가 바꿀 수 있습니다.

### 1.5 용어

| 용어 | 설명 |
| --- | --- |
| 프로젝트 | 작업을 모아 관리하는 단위. 영문 **식별자**(예: `web-platform`)가 주소에 쓰임 |
| 작업 | 할 일 하나. 번호(#12)로 구분. 유형(작업·마일스톤·요약·기능·버그 등)이 있음 |
| 상태 | 작업의 진행 단계(예: 신규, 진행 중, 완료). 역할별로 바꿀 수 있는 상태가 정해져 있음(워크플로) |
| 담당자 / 책임자 | 작업을 실제로 하는 사람 / 작업을 책임지는 사람 |
| 주시자 | 작업이 바뀔 때마다 알림을 받는 사람 |
| 보기 | 필터·열·정렬을 저장한 목록 설정 |
| 모듈 | 프로젝트에서 켜고 끄는 기능(Gantt, 보드, 캘린더, 팀 플래너, 1.6부터 시간 기록) |
| 근무일 | 일정 계산에 쓰는 날. 주말·공휴일은 관리자가 정함 |
| 내부 코멘트 | 정해진 역할(기본: 프로젝트 관리자)만 볼 수 있는 코멘트. 프로젝트에서 켜야 씀 |

| API 토큰 | 사내 시스템이 내 권한으로 openPMS API를 부를 때 쓰는 비밀 문자열(`opms_…`) |
| 웹훅 | 작업이 바뀌면 openPMS가 다른 시스템의 주소로 보내는 알림 요청 |
| 공수(시간 기록) | 작업에 쓴 시간. 사람·날짜·작업·활동별로 기록하고 **내 공수**에서 입력, **공수 보고서**에서 모아 봄(15장) |
| 활동 | 기록한 시간의 종류(개발, 설계, 회의, 테스트, 문서, 관리, 기타 등). 시스템 관리자가 정함 |
| 하루 근무 시간 | 하루로 치는 근무 시간(기본 8시간). 내 공수에서 하루 합계가 이 값을 넘으면 경고 |

## 2. 시작하기

### 2.1 비밀번호로 로그인하기

1. 브라우저에서 openPMS 주소를 엽니다. 로그인하지 않았다면 **openPMS에 로그인** 화면이 나옵니다.
2. **이메일**에 회사 이메일을 입력합니다.
3. **비밀번호**를 입력합니다.
4. **로그인**을 누릅니다.
5. 로그인되면 **홈**이 열립니다. 다른 주소(예: 메일로 받은 작업 링크)로 들어왔다가 로그인 화면으로 넘어온 경우에는 원래 열려던 화면으로 돌아갑니다.

- 빈 칸이 있으면 **이메일과 비밀번호를 모두 입력하세요.**가 나옵니다.
- 이메일이나 비밀번호가 틀리면 **이메일 또는 비밀번호가 올바르지 않습니다.**가 나옵니다. 어느 쪽이 틀렸는지는 알려 주지 않습니다.
- 정해진 횟수 이상 틀리면 계정이 잠시 잠기고 **잠긴 계정입니다. 관리자에게 잠금 해제를 요청하세요.**가 나옵니다. 잠금 횟수와 시간은 시스템 관리자가 정합니다(기본 5회, 15분). 잠긴 동안에는 맞는 비밀번호를 넣어도 로그인되지 않습니다. 다음 중 하나로 풀립니다.
  - 잠금 시간이 지나기를 기다립니다.
  - [2.3](#23-비밀번호를-잊었을-때)의 재설정으로 새 비밀번호를 정합니다(정하는 즉시 풀림).
  - 시스템 관리자에게 잠금 해제를 요청합니다. 관리자는 사용자 목록에서 이 상태를 **일시 잠김**으로 보고 바로 풀 수 있습니다([13장](#13-자주-묻는-질문)).
- 짧은 시간에 로그인을 너무 많이 시도하면 **요청이 너무 많습니다**가 나올 수 있습니다. 잠시 뒤 다시 시도하세요. 이 제한은 접속한 PC의 주소마다 따로 걸리므로, 보통은 다른 사람이 로그인을 많이 시도해도 내 로그인은 막히지 않습니다.
- 개발·시험 환경에서는 예시 계정(예: `haneul.lee@openpms.local`)을 쓸 수 있습니다. 비밀번호는 이 문서에 적지 않으므로 시험 담당자에게 문의하세요.

### 2.2 회사 계정(SSO)으로 로그인하기

시스템 관리자가 사내 SSO를 연결해 두었다면 로그인 화면 아래 **또는** 구분선 밑에 **{{공급자 이름}}(으)로 로그인** 버튼(예: **사내 계정(으)로 로그인**)이 보입니다.

1. 로그인 화면에서 **{{공급자 이름}}(으)로 로그인**을 누릅니다.
2. 회사 계정 시스템의 로그인 화면으로 이동합니다. 회사 계정으로 로그인합니다(이미 로그인되어 있으면 이 단계가 지나갈 수 있습니다).
3. openPMS로 돌아와 홈(또는 원래 열려던 화면)이 열립니다.

- 처음 SSO로 로그인할 때 이메일이 같은 openPMS 계정이 있으면 자동으로 연결됩니다.
- openPMS 계정이 없으면 **openPMS 계정이 없습니다. 관리자에게 초대를 요청하세요.**가 나옵니다. 관리자가 "계정 자동 생성"을 켜 두었다면 처음 로그인할 때 계정이 만들어집니다. 이렇게 만들어진 계정은 프로젝트 멤버로 추가되어야 프로젝트가 보입니다.
- 이렇게 자동으로 만들어진 계정에는 비밀번호가 없어 로그인 화면의 이메일·비밀번호 칸으로는 로그인할 수 없습니다. 회사 계정 시스템이 멈췄을 때를 대비해 비밀번호로도 로그인하고 싶으면 **내 계정**에서 비밀번호를 만드세요([10.2](#102-비밀번호-바꾸기)).
- 그 밖의 안내 문구와 대처는 [13. 자주 묻는 질문](#13-자주-묻는-질문)을 참고하세요.

### 2.3 비밀번호를 잊었을 때

1. 로그인 화면에서 **비밀번호를 잊으셨나요?**를 누릅니다. (이 링크가 없으면 회사에서 비밀번호 재설정을 꺼 둔 것입니다. 관리자에게 문의하세요.)
2. **비밀번호 재설정** 화면의 **이메일**에 가입한 이메일을 입력하고 **재설정 링크 보내기**를 누릅니다.
3. **메일을 확인하세요** 화면이 나옵니다. 메일함에서 재설정 메일을 엽니다.
4. 메일의 링크를 누르면 **새 비밀번호 정하기** 화면이 열립니다.
5. **새 비밀번호**와 **새 비밀번호 확인**에 같은 비밀번호를 입력합니다. 입력 칸 아래 안내(예: **10자 이상**)에 맞춰야 합니다.
6. **비밀번호 저장**을 누릅니다.
7. **비밀번호를 바꿨습니다** 화면에서 **로그인**을 눌러 새 비밀번호로 로그인합니다.

- 재설정 링크는 한 번만 쓸 수 있고 정해진 시간(기본 60분)이 지나면 만료됩니다. 만료된 링크를 열면 **쓸 수 없는 링크입니다**가 나오며, **새 링크 받기**로 다시 요청합니다.
- 비밀번호를 바꾸면 모든 기기에서 로그아웃됩니다.
- 메일이 오지 않으면 주소를 확인하고 **다른 주소로 다시 보내기**를 누르거나 관리자에게 문의하세요. 보안을 위해 가입하지 않은 주소를 넣어도 같은 안내가 나옵니다.

### 2.4 초대를 받았을 때

관리자가 나를 openPMS에 초대하면 초대 메일이 옵니다.

1. 초대 메일의 링크를 누릅니다. **초대 수락** 화면이 열립니다.
2. **이메일**은 초대받은 주소로 고정되어 있습니다. 바꾸려면 관리자에게 요청합니다.
3. **이름**을 확인하거나 고칩니다.
4. **새 비밀번호**와 **새 비밀번호 확인**을 입력합니다.
5. **수락하고 시작하기**를 누릅니다.
6. **{{이름}}님, 환영합니다** 안내와 함께 홈이 열립니다.

- 다른 계정으로 로그인한 상태에서 링크를 열면 **지금 {{name}} 계정으로 로그인되어 있습니다. 수락하면 새 계정으로 바뀝니다.**가 나옵니다.
- 링크가 만료됐거나 이미 썼다면 **쓸 수 없는 링크입니다**가 나옵니다. 관리자에게 초대를 다시 보내 달라고 요청하세요. 이미 수락했다면 로그인 화면에서 로그인하면 됩니다.

### 2.5 로그아웃하기

1. 화면 오른쪽 위 내 아바타(계정 메뉴)를 누릅니다.
2. **로그아웃**을 누릅니다. 로그인 화면으로 돌아갑니다.

### 2.6 화면 구성 둘러보기

| 위치 | 구성 |
| --- | --- |
| 위쪽 헤더 | 모듈 메뉴(격자 아이콘), openPMS 로고(홈으로), **전체 검색** 입력란, **새로 만들기**(+), **알림**(읽지 않은 수 표시), **도움말**(**키보드 단축키**, **API 문서**, **디자인 시스템**), 계정 메뉴(아바타) |
| 왼쪽 메뉴 | 프로젝트 밖: **홈**, **내 페이지**, **내 공수**(1.6), **프로젝트**, **작업**, **Gantt**, **알림**(관리자는 **관리**도 보임) / 프로젝트 안: 프로젝트 전환 메뉴, **개요**, **작업**, **Gantt**, **보드**, **캘린더**, **팀 플래너**, **공수 보고서**(1.6), **멤버**, **프로젝트 설정**(켜진 모듈과 권한에 따라 다름) |
| 가운데 본문 | 브레드크럼(현재 위치), 화면 제목, 화면별 버튼, 내용 |
| 오른쪽 분할 패널 | 목록에서 작업을 고르면 열리는 작업 상세 |

- 왼쪽 메뉴 아래 **메뉴 접기**를 누르면 메뉴가 얇게 접히고, **메뉴 펼치기**로 다시 엽니다. 이 설정은 브라우저에 기억됩니다.
- 프로젝트 안에서 다른 프로젝트로 가려면 왼쪽 메뉴 맨 위 프로젝트 이름을 눌러 목록에서 고릅니다(즐겨찾는 프로젝트가 먼저 나옵니다). **모든 프로젝트**를 누르면 프로젝트 목록으로 갑니다.
- 키보드로 Tab을 처음 누르면 **본문으로 건너뛰기**가 나타나 메뉴를 건너뛸 수 있습니다.
- `?`를 누르면 화면 전체에서 쓰는 단축키 목록이 열립니다([12.1](#121-화면-전체-단축키)).

## 3. 홈과 내 페이지

### 3.1 홈 보기

로그인하면 처음 보이는 화면입니다. 왼쪽 메뉴 **홈** 또는 헤더의 openPMS 로고를 눌러도 열립니다.

| 영역 | 내용 | 할 수 있는 일 |
| --- | --- | --- |
| **내게 할당된 작업** | 내가 담당자인 열린 작업을 완료일이 가까운 순서로 최대 8건 | 제목을 누르면 작업이 열림. **모두 보기**를 누르면 전체 목록(**내게 할당됨** 보기) |
| **읽지 않은 알림** | 읽지 않은 알림 수 | **알림**을 누르면 알림 화면 |
| **즐겨찾는 프로젝트** | 별표를 누른 프로젝트와 상태(순조로움·주의·지연) | 이름을 누르면 프로젝트 개요 |

- 완료일이 지난 작업은 날짜가 빨간 굵은 글씨로 보입니다.
- 즐겨찾는 프로젝트가 없으면 **프로젝트 목록에서 별표를 누르면 여기에 모입니다.**가 나옵니다.

### 3.2 내 페이지 꾸미기

**내 페이지**는 나와 관련된 작업 목록(위젯)을 골라 보는 개인 화면입니다.

1. 왼쪽 메뉴에서 **내 페이지**를 누릅니다.
2. 오른쪽 위 **위젯 편집**을 누릅니다.
3. 보여 줄 위젯을 체크합니다. 고를 수 있는 위젯은 **내게 할당된 작업**, **내가 만든 작업**, **주시 중인 작업**, **내가 책임자인 작업**, **2주 안에 끝내야 할 작업**, **최근 1주일 동안 바뀐 작업**입니다.
4. 위젯 오른쪽 위·아래 화살표 버튼으로 순서를 바꿉니다.
5. 바꾸는 즉시 저장됩니다(**저장 중…** → **저장됨**). 다 끝나면 **편집 끝내기**를 누릅니다.

- 위젯마다 최대 10건이 보이고, 더 있으면 **모두 보기 ({{건수}})**로 전체 목록을 엽니다.
- 위젯을 모두 끄면 **보이는 위젯이 없습니다**가 나옵니다.

## 4. 프로젝트

### 4.1 프로젝트 찾기

1. 왼쪽 메뉴에서 **프로젝트**를 누릅니다.
2. 위쪽 버튼으로 범위를 고릅니다: **진행 중**(기본), **내 프로젝트**, **즐겨찾기**, **보관됨**.
3. 필요하면 상태 선택에서 **모든 상태**, **순조로움**, **주의**, **지연** 중 하나를 고릅니다.
4. 오른쪽 **프로젝트 이름으로 찾기**에 이름 일부를 입력합니다.
5. 목록에서 프로젝트 이름을 누르면 **개요**가 열립니다.

- 목록 아래에서 **페이지당** 20개·100개를 고르고, 화살표로 페이지를 넘깁니다.
- 내가 볼 수 없는 프로젝트는 목록에 나오지 않습니다.

### 4.2 즐겨찾기

1. 프로젝트 목록에서 이름 왼쪽 별(☆)을 누릅니다. 별이 채워지면 즐겨찾기에 추가된 것입니다.
2. 다시 누르면 즐겨찾기에서 빠집니다.

- 프로젝트 개요 화면 오른쪽 위 **즐겨찾기** 버튼으로도 할 수 있습니다.
- 즐겨찾는 프로젝트는 홈과 프로젝트 전환 메뉴 맨 위에 보입니다.

### 4.3 프로젝트 개요 보기

프로젝트 이름을 누르거나 프로젝트 메뉴의 **개요**를 누르면 열립니다.

| 영역 | 내용 |
| --- | --- |
| **설명** | 프로젝트 설명(없으면 **설명이 없습니다.**) |
| **작업 현황** | **열린 작업** 수, **기한 지남** 수, **상태별** 작업 수 막대. 숫자를 누르면 해당 작업 목록이 열림 |
| **프로젝트 상태** | 순조로움·주의·지연(또는 **상태 없음**)과 상태 설명 |
| **멤버** | 멤버(최대 8명)와 역할. **멤버 모두 보기**로 멤버 화면 |
| **버전 진행** | 진행 중인 버전마다 기간과 **n개 중 n개 완료**, 진행 막대 |
| **곧 완료일(14일 안)** | 14일 안에 완료일이 오는 열린 작업(최대 8건, **모두 보기**) |
| **최근 바뀐 작업(7일)** | 지난 7일 동안 바뀐 작업(최대 8건, **모두 보기**) |
| **내게 할당된 작업** | 이 프로젝트에서 내가 담당자인 열린 작업(최대 8건, **모두 보기**) |

- 개요에 어떤 위젯이 보일지는 프로젝트 관리자가 정합니다(처음에는 **설명**, **작업 현황**, **프로젝트 상태**, **멤버**). 모든 사람에게 같은 구성이 보입니다([11.12](#1112-개요-위젯-편집)).
- 오른쪽 위 **작업**을 누르면 이 프로젝트의 작업 목록이 열립니다.
- 보관된 프로젝트에는 **보관됨** 표시가 있고 읽기 전용입니다.

## 5. 작업 다루기

### 5.1 작업 만들기

**방법 1: 만들기 버튼**

1. 프로젝트의 **작업** 화면을 엽니다.
2. 오른쪽 위 **만들기**를 누르고 유형(예: **작업**, **마일스톤**, **요약**)을 고릅니다.
3. 오른쪽 패널에 생성 폼이 열립니다. **제목**을 입력합니다(필수).
4. 필요하면 **설명**, **상태**, **우선순위**, **담당자**, **버전**, **카테고리**, **시작일**, **완료일**(마일스톤은 **날짜** 하나), **상위 작업**(#번호), 회사가 추가한 항목(**추가 정보**)을 입력합니다.
5. **저장**을 누릅니다. **#{{번호}} 작업을 만들었습니다** 안내가 나오고 같은 패널에 새 작업이 열립니다.

**방법 2: 목록 맨 아래에서 바로 만들기**

1. 작업 목록 표 맨 아래 **새 작업 추가**를 누릅니다.
2. **제목을 입력하고 Enter** 칸에 제목을 쓰고 Enter를 누릅니다. 작업이 바로 만들어지고, 칸이 비워져 다음 작업을 이어서 입력할 수 있습니다.
3. 그만 만들려면 Esc를 누릅니다.

- 이 방법으로 만든 작업의 유형은 그 프로젝트의 첫 번째 유형입니다. 나머지 항목은 만든 뒤에 고칩니다.

**방법 3: 헤더의 새로 만들기**

1. 프로젝트 안 어느 화면에서든 헤더의 **새로 만들기**(+)를 누릅니다.
2. **새 작업**을 누릅니다. 작업 목록에 생성 폼이 열립니다.

- 유형을 바꾸면 폼이 그 유형에 맞게 다시 구성되고, 유형에 정해 둔 기본 설명이 채워집니다.
- **카테고리**를 고르고 **담당자**를 비워 두면 카테고리의 기본 담당자가 들어갑니다.
- 제목이나 설명을 쓰다가 화면을 떠나려 하면 브라우저가 확인을 묻습니다(계정 설정에서 끌 수 있음, [10.3](#103-화면-설정)).
- **취소** 또는 패널 오른쪽 위 x를 누르면 만들지 않고 닫힙니다.
- **저장**을 누른 순간 인터넷이 잠깐 끊겨도 작업은 한 번만 만들어집니다. 화면이 같은 요청을 한 번 더 보내고, 서버는 이미 만든 작업이면 그 결과를 돌려줍니다. 코멘트 쓰기, 작업 복사, 프로젝트 만들기·복사도 같습니다. 끊긴 상태가 길면 오류가 나니, 다시 연결된 뒤 목록을 새로 고쳐 작업이 생겼는지 확인하고 없을 때만 다시 만드세요.

### 5.2 작업 열기

| 여는 방법 | 결과 |
| --- | --- |
| 작업 목록에서 행이나 제목·번호를 누름 | 오른쪽 분할 패널에 작업 상세(목록은 그대로) |
| 패널 오른쪽 위 **전체 화면으로 열기**(⤢) | 작업 전체 화면(왼쪽 속성, 오른쪽 활동 등) |
| 패널 오른쪽 위 **상세 패널 닫기**(x) | 패널을 닫고 목록으로 |
| 전체 화면 왼쪽 위 **← 작업** | 프로젝트 작업 목록으로 |

분할 패널에는 탭 **요약**, **활동**, **파일**, **관계**, **주시자**가 있습니다(괄호 안 숫자는 개수). 전체 화면에서는 요약 내용이 왼쪽에 늘 보이고 오른쪽에 나머지 탭이 있습니다.

- 작업 링크를 다른 사람에게 보내려면 상세 오른쪽 위 ⋯ › **링크 복사**를 누릅니다(**링크를 복사했습니다**).

### 5.3 바로 고치기(인라인 편집)

**상세에서 고치기**

1. 작업 상세에서 고칠 항목(제목, 담당자, 책임자, 유형, 우선순위, 버전, 카테고리, 작업량, 남은 작업, 완료 % 등)을 누릅니다.
2. 글자 항목(제목, 숫자)은 입력 칸으로 바뀝니다. 값을 고치고 Enter를 누르거나 다른 곳을 누르면 저장됩니다. Esc를 누르면 취소됩니다.
3. 선택 항목(담당자, 우선순위 등)은 목록이 열립니다. 값을 고르면 바로 저장됩니다.

**설명 고치기**

1. 요약 탭의 설명에 마우스를 올리고 연필 모양 **설명 수정** 버튼을 누릅니다. 설명이 비어 있으면 **클릭해서 설명을 입력하세요**를 누릅니다.
2. 서식 도구(굵게, 기울임, 밑줄, 취소선, 코드, 글머리 기호 목록, 번호 목록, 인용, 코드 블록, 링크)로 내용을 씁니다.
3. **저장**을 누릅니다(Ctrl+Enter도 저장). **취소** 또는 Esc로 그만둡니다.

**목록에서 고치기**

1. 작업 목록 표에서 **상태**, **담당자**, **우선순위** 칸을 누릅니다.
2. 열리는 목록에서 값을 고르면 바로 저장됩니다.

- 고칠 권한이 없는 항목은 눌러도 바뀌지 않습니다(글자로만 보임).
- 다른 사람이 먼저 같은 작업을 고쳤다면 **다른 사람이 먼저 수정했습니다** / **최신 내용으로 바꿨습니다. 확인한 뒤 다시 수정하세요.**가 나오고 화면이 최신 내용으로 바뀝니다. 내용을 확인하고 다시 고치세요.
- 하위 작업이 있는 작업은 **합계 작업량**, **합계 남은 작업**, **합계 완료 %**가 함께 보입니다(자신과 하위 작업의 합계).
- 진행률을 상태 기준으로 계산하도록 설정된 경우 **완료 %**는 직접 바꿀 수 없습니다(**완료 %는 상태를 따릅니다.**).

### 5.4 상태 바꾸기

1. 작업 상세의 제목 아래 상태 표시(예: **진행 중 ▾**)를 누릅니다. 작업 목록의 상태 칸에서도 됩니다.
2. **상태 바꾸기** 목록에서 새 상태를 고릅니다. 바로 저장되고 활동에 기록됩니다.

- 목록에는 내 역할로 바꿀 수 있는 상태만 나옵니다. 하나도 없으면 **내 역할로 바꿀 수 있는 상태가 없습니다**가 나옵니다. 필요한 상태가 없으면 프로젝트 관리자나 시스템 관리자에게 문의하세요(워크플로 설정).
- 읽기 전용 상태(예: 완료 처리된 상태)의 작업에는 **'{{상태}}' 상태에서는 상태만 바꿀 수 있습니다**가 보이며, 상태 말고는 고칠 수 없습니다.
- 보드에서 카드를 다른 상태 열로 끌어도 상태가 바뀝니다([7.2](#72-보드)).

### 5.5 날짜 정하기

1. 작업 상세 요약의 **날짜** 항목(날짜 범위 또는 **날짜 없음**)을 누릅니다. **날짜** 대화상자가 열립니다.
2. 일정 방식을 고릅니다.
   - **수동**: 입력한 날짜를 그대로 씁니다. 선행 작업이 바뀌어도 움직이지 않습니다.
   - **자동**: 선행 작업이 끝난 다음 근무일에 시작하고, 하위 작업이 있으면 그 기간을 따릅니다.
3. 주말·공휴일을 빼고 셀지 **근무일만 계산**으로 정합니다(기본 켬).
4. 날짜를 정합니다. 다음 중 편한 방법을 씁니다.
   - 두 달짜리 달력에서 시작일을 누르고, 이어서 완료일을 누릅니다. 달력 위 안내(**달력에서 고르는 날짜가 시작일이 됩니다** / **…완료일이 됩니다**)가 다음에 누를 날짜를 알려 줍니다. 시작일보다 앞 날짜를 누르면 그 날이 새 시작일이 됩니다.
   - **시작일**, **완료일** 칸에 직접 입력하거나 칸 아래 **오늘**을 누릅니다.
   - **기간(근무일)**에 일수를 입력합니다.
5. 세 값(시작일·완료일·기간) 중 두 개를 정하면 나머지 하나는 자동으로 계산되어 채워집니다.
6. 이 변경으로 다른 작업(후행 작업, 상위 작업)의 날짜도 바뀌면 **이 변경으로 작업 {{n}}개의 일정이 함께 바뀝니다**와 바뀔 날짜가 보입니다.
7. **저장**을 누릅니다.

- 마일스톤은 **날짜** 하나만 정합니다.
- 달력의 첫 열(요일)은 시스템 관리자가 정한 주 시작 요일을 따릅니다(기본 일요일).
- **근무일만 계산**이 켜져 있으면 달력에서 쉬는 날은 고를 수 없습니다.
- 자동 일정인 상위 작업은 **날짜는 하위 작업에서 정해집니다**가 보이고 날짜를 직접 고칠 수 없습니다. 하위 작업의 날짜를 바꾸세요.
- 완료일이 지난 열린 작업은 날짜가 빨간 굵은 글씨로 보입니다.
- Gantt·캘린더·팀 플래너에서 막대를 끌어도 날짜가 바뀝니다([7장](#7-계획-도구)). Gantt에서는 날짜 없는 작업에 막대를 그려 날짜를 정할 수도 있습니다([7.1](#71-gantt)).

**선행·후속·하위 작업 함께 보기**

날짜 대화상자 위쪽에는 탭 **날짜**, **선행**, **후속**, **하위 작업**이 있습니다(탭 옆 숫자는 개수). 대화상자는 늘 **날짜** 탭으로 열립니다.

1. 날짜 대화상자에서 **선행** 탭을 누릅니다. 이 작업보다 먼저 끝나야 하는 작업이 번호·유형·제목·상태·기간과 함께 보입니다. 관계에 간격을 둔 경우 **· 간격 {{n}}일**이 붙습니다.
2. **후속** 탭에는 이 작업이 끝난 뒤에 시작하는 작업이, **하위 작업** 탭에는 이 작업의 하위 작업과 그 기간이 보입니다.
3. 목록의 제목을 누르면 대화상자가 닫히고 그 작업의 전체 화면이 열립니다. 저장하지 않은 날짜 변경은 버려지므로, 바꾼 날짜가 있으면 먼저 **저장**하세요.
4. 다시 날짜를 고치려면 **날짜** 탭을 누릅니다. **저장**·**취소**는 어느 탭에서든 누를 수 있습니다.

- 일정 방식이 **자동**이고 선행 작업이 있으면 **날짜** 탭 위에 **자동 일정: #{{번호}} {{제목}}(완료 {{날짜}})이 끝난 뒤에 시작합니다.**가 나옵니다. 선행 작업이 여럿이면 가장 늦게 끝나는 작업을 알려 줍니다. 옆의 **선행 작업 보기**를 누르면 **선행** 탭이 열립니다.
- 탭은 보기만 합니다. 선행·후행 관계나 하위 작업을 더하거나 지우려면 작업 상세의 **관계** 탭을 씁니다([5.6](#56-관계-걸기), [5.7](#57-상위하위-작업계층)).
- 관련 작업이 없으면 **이 작업보다 먼저 끝나야 하는 작업이 없습니다**, **이 작업이 끝난 뒤에 시작하는 작업이 없습니다**, **하위 작업이 없습니다**가 보입니다.

### 5.6 관계 걸기

1. 작업 상세에서 **관계** 탭을 엽니다.
2. **관계 추가**를 누릅니다.
3. **관계 추가** 선택에서 종류를 고릅니다.

   | 종류 | 뜻 |
   | --- | --- |
   | **선행 작업** | 이 작업은 선택한 작업이 끝난 뒤에 시작합니다. |
   | **후행 작업** | 선택한 작업은 이 작업이 끝난 뒤에 시작합니다. |
   | **관련 항목** | 서로 연결만 하고 일정에는 영향이 없습니다. |
   | **차단 중** / **차단됨** | 이 작업이 선택한 작업을 막음 / 선택한 작업에 막힘 |
   | **중복 원본** / **중복 항목** | 중복 관계 |
   | **포함** / **포함됨** | 포함 관계 |
   | **필요** / **필요로 함** | 필요 관계 |

4. **연결할 작업 (#번호나 제목)**에 번호(예: `#12`)나 제목 일부를 입력하고, 나타나는 목록에서 작업을 고릅니다.
5. **관계 추가**를 누릅니다(**관계를 추가했습니다**).

- 추가한 관계는 종류별 묶음으로 보입니다. 관계를 지우려면 카드 오른쪽 휴지통(**관계 삭제**)을 누릅니다.
- 선행·후행 관계가 있으면 자동 일정 작업의 날짜가 선행 작업에 맞춰 움직입니다.
- 자기 자신과는 관계를 맺을 수 없고, 순환이 생기는 선후행(예: 상위·하위 작업끼리)은 **순환 관계가 됩니다.**로 거부됩니다.
- 관계를 관리할 권한이 없으면 **관계 추가** 버튼이 없습니다.

### 5.7 상위·하위 작업(계층)

**새 하위 작업 만들기**

1. 상위로 삼을 작업의 **관계** 탭에서 **새 하위 작업 만들기**를 누릅니다.
2. 생성 폼의 **상위 작업**에 이 작업 번호가 채워져 있습니다. 제목 등을 입력하고 **저장**합니다.

**이미 있는 작업을 하위로 연결하기**

1. 상위 작업의 **관계** 탭에서 **관계 추가**를 누릅니다.
2. 종류에서 **기존 작업을 하위로 연결**을 고릅니다.
3. 연결할 작업을 찾아 고르고 **관계 추가**를 누릅니다.

**이 작업의 상위 작업 정하기**

1. 하위가 될 작업의 **관계** 탭에서 **관계 추가** › 종류 **기존 작업을 상위로 지정**을 고릅니다.
2. 상위 작업을 찾아 고르고 **관계 추가**를 누릅니다.

- 새 작업을 만들 때 **상위 작업** 칸에 `#번호`를 넣어도 됩니다.
- 관계 탭 위쪽에 **상위 작업**과 **하위 작업** 묶음이 보이고, 상세 제목 위에 **상위 작업: #번호 제목** 링크가 보입니다.
- 자기 자신이나 자기 하위 작업을 상위로 정할 수 없습니다.
- 하위 작업이 생긴 상위 작업은 자동 일정이면 날짜가 하위 작업 범위로 정해지고, 진행률 합계가 보입니다.
- 작업 목록에서 **계층 표시**를 켜면 상위·하위가 들여쓰기로 보입니다([6.4](#64-계층-표시와-하위-프로젝트-포함)).

### 5.8 코멘트와 멘션

**코멘트 쓰기**

1. 작업 상세의 **활동** 탭을 엽니다.
2. 코멘트 입력란(**코멘트를 입력하세요. @이름으로 사람을 언급할 수 있습니다.**)에 내용을 씁니다. 서식 도구를 쓸 수 있습니다.
3. **코멘트 남기기**를 누르거나 Ctrl+Enter를 누릅니다.

**사람 언급(멘션)하기**

1. 코멘트 입력 중에 `@`를 입력합니다.
2. **언급할 사람** 목록이 열립니다. 이름 일부를 더 입력해 좁힐 수 있습니다.
3. 위·아래 화살표로 사람을 고르고 Enter(또는 Tab)를 누르거나 마우스로 누릅니다. `@이름`이 들어갑니다.
4. 코멘트를 남기면 언급된 사람에게 알림이 갑니다(설정에 따라 메일도 바로 감).

**내 코멘트 고치기**

1. 활동에서 내 코멘트 옆 연필 모양 **코멘트 수정**을 누릅니다.
2. 내용을 고치고 **저장**(또는 Ctrl+Enter)을 누릅니다. 고친 코멘트에는 **· 수정됨**이 붙습니다.

- 활동에는 코멘트와 함께 바뀐 내역(예: **상태: 신규 → 진행 중**), 파일 첨부·삭제, 일정 자동 조정 사유가 시간순으로 보입니다.
- 최신 활동을 맨 위에 보려면 계정 설정의 **최신 활동을 맨 위에**를 켭니다. 그러면 입력란도 위로 옮겨집니다.
- 코멘트를 쓸 권한이 없으면 **코멘트를 쓸 권한이 없습니다.**가 보입니다.

**활동 거르기와 정렬 바꾸기**

1. **활동** 탭 위쪽에서 **모두** / **코멘트만** / **변경만** 중 하나를 누릅니다. 목록이 바로 좁혀집니다. 고른 값은 이 브라우저에 기억되어 다음에 활동 탭을 열어도 그대로입니다.
2. 옆의 정렬 버튼(**정렬 바꾸기 (지금: 오래된 순)** 등)을 누르면 최신 순과 오래된 순이 바뀝니다. 계정 설정의 **최신 활동을 맨 위에**와 같은 설정이라, 바꾸면 모든 작업의 활동 탭에 똑같이 적용됩니다.

- 고른 조건에 맞는 활동이 없으면 **이 조건에 맞는 활동이 없습니다**가 나옵니다.

**내부 코멘트 남기기**(프로젝트에서 내부 코멘트를 켰고 쓰기 권한이 있을 때)

내부 코멘트는 정해진 역할(기본: 프로젝트 관리자)만 볼 수 있는 코멘트입니다. 관리자끼리 나누는 메모처럼 일부 사람만 봐야 할 내용에 씁니다.

1. 코멘트 입력란에 내용을 씁니다.
2. 입력란 아래 **내부 코멘트**를 체크합니다(**내부 코멘트를 볼 수 있는 역할만 읽습니다.**).
3. **코멘트 남기기**를 누릅니다. 활동에 **내부** 표시와 다른 배경으로 보입니다.

- **내부 코멘트** 체크박스가 없으면 그 프로젝트에서 내부 코멘트를 켜지 않았거나 쓰기 권한이 없는 것입니다(켜는 방법은 [11.6](#116-유형카테고리사용자-정의-필드내부-코멘트)).
- 볼 권한이 없는 사람에게는 내부 코멘트가 활동·검색·알림 어디에도 나오지 않습니다. 다른 시스템으로 보내는 웹훅에도 실리지 않습니다.
- 내부 코멘트로 남긴 뒤에는 일반 코멘트로 바꿀 수 없습니다. 모두가 봐야 하는 내용이면 체크하지 말고 남기세요.

### 5.9 파일 첨부

1. 작업 상세의 **파일** 탭을 엽니다.
2. 파일을 점선 영역(**파일을 여기에 끌어다 놓거나**)에 끌어다 놓거나, **파일 선택**을 눌러 고릅니다. 여러 파일을 한 번에 올릴 수 있습니다.
3. 올리는 동안 파일 옆에 진행 표시가 보이고, 끝나면 목록에 추가됩니다.

- 파일 하나에 25MB까지 올릴 수 있습니다. 실패한 파일은 빨간 줄과 사유가 보이며, x(**오류 닫기**)로 지웁니다.
- 이미지(png, jpeg, gif, webp)는 미리 보기가 보이고 누르면 새 탭에서 열립니다. 그 밖의 파일은 누르면 내려받습니다.
- 파일을 지우려면 휴지통(**{{파일명}} 삭제**)을 누르고 **파일을 삭제할까요?**에서 **삭제**를 누릅니다. 되돌릴 수 없습니다.
- 첨부·삭제는 활동에 기록됩니다.

### 5.10 주시자

**내가 주시하기**

1. 작업 상세 오른쪽 위 눈 모양 버튼(**주시하기**)을 누릅니다.
2. 다시 누르면(**주시 해제**) 주시를 그만둡니다.

**다른 사람을 주시자로 추가하기**

1. **주시자** 탭을 엽니다.
2. **사람 선택**에서 프로젝트 멤버를 고르고 **추가**를 누릅니다.
3. 주시자에서 빼려면 이름 오른쪽 x(**{{이름}} 주시자에서 빼기**)를 누릅니다.

- 주시자는 작업이 바뀔 때마다 알림을 받습니다.
- 다른 사람을 추가하거나 빼려면 해당 권한이 필요합니다. 나 자신은 언제든 뺄 수 있습니다.
- 이 작업을 볼 수 없는 사람은 주시자로 추가할 수 없습니다.

### 5.11 공유

프로젝트 멤버가 아닌 사람에게 작업 하나만 보여 줄 때 씁니다. 공유 권한이 있는 사람에게만 버튼이 보입니다.

1. 작업 상세 오른쪽 위 공유 버튼(**작업 공유**)을 누릅니다.
2. **사람 찾기**에 이름 또는 이메일을 입력합니다.
3. **공유할 사람**에서 사람을 고릅니다.
4. **권한**을 고릅니다: **보기**(작업을 볼 수 있습니다), **코멘트**(보기 + 코멘트), **편집**(코멘트 + 속성·파일 수정).
5. **공유**를 누릅니다. 공유받은 사람에게 알림이 갑니다.

- 아래 **공유받은 사람** 목록에서 권한을 바꾸거나 휴지통(**공유 해제**)으로 공유를 끝낼 수 있습니다.
- 공유받은 사람이 작업을 열면 **나와 공유됨 · {{권한}}** 표시가 보입니다.

### 5.12 복사와 이동

**작업 복사하기**

1. 작업 상세 오른쪽 위 ⋯ › **작업 복사**를 누릅니다.
2. **대상 프로젝트**를 고르고(기본은 같은 프로젝트), **제목**을 확인합니다.
3. 하위 작업도 함께 복사하려면 **하위 작업도 복사**를 켭니다.
4. **복사**를 누릅니다. 새 작업이 열립니다.

- 설명·상태·우선순위·날짜·작업량·사용자 정의 값을 가져갑니다. 코멘트·첨부·관계는 복사하지 않습니다. 대상 프로젝트의 멤버가 아닌 담당자, 다른 프로젝트의 버전·카테고리는 비워집니다.
- 대상 프로젝트가 같은 유형을 쓰지 않으면 복사할 수 없습니다.
- (1.6) 작업에 기록된 시간(공수)은 복사하지 않습니다.

**다른 프로젝트로 이동하기**

1. ⋯ › **다른 프로젝트로 이동**을 누릅니다(이동 권한이 있을 때).
2. **대상 프로젝트**를 고릅니다.
3. 대상 프로젝트가 이 작업의 유형을 쓰지 않으면 **새 유형**을 고릅니다.
4. **이동**을 누릅니다.

- 번호는 그대로이고 하위 작업도 함께 옮겨집니다. 버전·카테고리, 대상 프로젝트의 멤버가 아닌 담당자·책임자는 비워집니다.
- 옮긴 작업의 예전 주소를 열면 새 프로젝트 주소로 자동으로 이동합니다.
- (1.6) 작업에 기록된 시간도 함께 옮겨져, 그때부터 새 프로젝트의 공수 보고서에 셉니다([15.2](#152-작업에-시간-기록하기시간-탭)).

### 5.13 삭제

1. 작업 상세 오른쪽 위 ⋯ › **삭제**를 누릅니다(삭제 권한이 있을 때).
2. **작업을 삭제할까요?** 대화상자에서 내용을 확인합니다.
3. 하위 작업이 있으면 **하위 작업 {{n}}개도 함께 삭제**를 켤지 정합니다. 끄면 하위 작업은 남고 한 단계 위로 올라갑니다.
4. **삭제**를 누릅니다. 되돌릴 수 없습니다.

- (1.6) 작업을 삭제하면 그 작업에 기록된 시간(공수)도 함께 지워지고, 지난 기간의 공수 보고서 합계도 줄어듭니다. 기록된 시간이 있으면 대화상자에 **이 작업에 기록된 시간 {{n}}시간도 함께 지워지고 공수 보고서에서 빠집니다.**라는 경고가 나옵니다(내가 볼 수 있는 기록만 셉니다). 공수를 기록한 작업은 지우지 말고 상태로 정리하세요. 프로젝트를 삭제할 때는 이런 경고 없이 그 프로젝트의 시간 기록도 모두 지워집니다.

### 5.14 여러 작업 한꺼번에 바꾸기

**체크박스로 골라 바꾸기**

1. 작업 목록 표 왼쪽 체크박스로 작업을 고릅니다. 머리글 체크박스는 이 페이지의 작업을 모두 고릅니다.
2. 표 위에 **{{n}}건 선택** 바가 나타납니다.
3. 할 일을 고릅니다.
   - **상태**, **담당자**, **우선순위**: 목록에서 값을 고르면 고른 작업 모두에 적용됩니다.
   - **복사**: 아래 "여러 작업 복사하기"를 보세요.
   - **다른 프로젝트로 이동**: **대상 프로젝트**를 고르고 **이동**.
   - **삭제**: **작업 {{n}}건을 삭제할까요?**에서 **삭제**.
4. 끝나면 **{{n}}건을 바꿨습니다** 같은 안내가 나옵니다. **선택 해제**로 선택을 비웁니다.

**행을 우클릭해 바꾸기**

1. 작업 목록 표에서 작업 행을 마우스 오른쪽 버튼으로 누릅니다(키보드로는 행에 포커스를 두고 메뉴 키). 그 자리에 메뉴가 열립니다.
2. 체크하지 않은 행을 우클릭하면 그 작업 하나에, 체크한 행 중 하나를 우클릭하면 체크한 작업 모두에 적용됩니다. 여러 건이면 메뉴 맨 위에 **{{n}}건 선택**이 보입니다.
3. 메뉴에서 고릅니다.
   - **상세 패널에서 열기** / **전체 화면으로 열기**(한 건일 때만)
   - **상태**, **담당자**, **우선순위**: 항목에 마우스를 올리거나 → 키로 하위 목록을 열고 값을 고릅니다.
   - **복사**, **다른 프로젝트로 이동**, **삭제**: 체크박스 바의 같은 버튼과 똑같이 동작합니다.

**여러 작업 복사하기**

1. 복사할 작업을 체크하고 바의 **복사**를 누릅니다(또는 체크한 행을 우클릭 › **복사**).
2. **작업 {{n}}건 복사** 대화상자에서 **대상 프로젝트**를 고릅니다. 처음에는 지금 프로젝트가 골라져 있습니다.
3. **복사하기**를 누릅니다(**{{n}}건을 복사했습니다**). 새 번호로 사본이 만들어집니다.

- 고른 작업끼리의 상위-하위 관계는 사본에도 그대로 남습니다. 예를 들어 상위 작업 #7과 그 하위 작업 #9를 함께 고르면 #9의 사본은 #7의 사본 아래에 들어갑니다. 고르지 않은 하위 작업은 복사되지 않습니다.
- 가져가는 것과 비우는 것은 작업 하나를 복사할 때와 같습니다([5.12](#512-복사와-이동)). 코멘트·첨부·관계는 복사하지 않습니다.
- 대상 프로젝트가 고른 작업의 유형을 쓰지 않는 등 한 건이라도 복사할 수 없으면 아무것도 만들지 않고, 바 아래에 그 작업 번호와 사유(예: **#12: …**)가 보입니다.

- 한 건이라도 바꿀 수 없으면(예: 허용되지 않은 상태 전환) 아무것도 바뀌지 않고, 바에 거부된 작업과 사유가 나열됩니다.
- 한 번에 200건까지 바꿀 수 있습니다.
- 휴대폰 화면(카드 목록)에서는 일괄 편집과 우클릭 메뉴를 쓸 수 없습니다.
- 필터에 맞지 않아 흐리게 보이는 상위 작업 행(맥락 행)에는 체크박스와 우클릭 메뉴가 없습니다.

## 6. 목록 보기 다루기

작업 목록은 프로젝트 메뉴의 **작업**(그 프로젝트의 작업) 또는 전역 메뉴의 **작업**(내가 볼 수 있는 모든 프로젝트의 작업)에서 엽니다. 처음에는 **모두 열림** 보기가 열립니다.

화면 위 제목은 지금 보기의 이름입니다. 필터·열·정렬을 바꾸면 제목 옆에 **저장하지 않은 변경**이 표시됩니다. 지금 화면 주소에 설정이 담기므로, 주소를 복사해 보내면 같은 목록을 보여 줄 수 있습니다.

### 6.1 필터

1. 목록 위 **필터** 버튼을 누릅니다. 필터 패널이 열립니다.
2. 제목이나 번호로 빨리 찾으려면 **제목이나 #번호로 찾기**에 입력합니다.
3. 조건을 더하려면 **필터 추가**에서 항목을 고릅니다(예: **담당자**).
4. 추가된 줄에서 조건(예: **다음과 같음**)을 고르고 값(예: **나**)을 고릅니다. 값은 여러 개 고를 수 있는 항목도 있습니다.
5. 결과는 바로 반영됩니다. **필터** 버튼 옆 숫자는 적용 중인 필터 수입니다.
6. 줄 오른쪽 x(**{{항목}} 필터 삭제**)로 필터 하나를 지우고, **필터 초기화**로 모두 지웁니다.

자주 쓰는 필터 예:

| 하고 싶은 일 | 필터 |
| --- | --- |
| 내 작업만 | **담당자** · **다음과 같음** · **나** |
| 담당자 없는 작업 | **담당자** · **담당자 없음** |
| 열린 작업만 | **상태** · **열림** |
| 기한이 지난 작업 | **완료일** · **기한 지남** |
| 이번 주 시작하는 작업 | **시작일** · **이번 주**(주 시작 요일부터 7일, 기본 일요일~토요일) |
| 앞으로 7일 안에 끝나는 작업 | **완료일** · **앞으로 며칠 안** · 7 |
| 특정 기간에 걸친 작업 | **일정 기간** · **기간과 겹침** · 시작일–끝 |
| 하위 작업이 아닌 작업 | **상위 작업** · **상위 작업 없음** |
| 다른 작업에 막힌 작업 | **다른 작업에 막힘** · **예** |
| 설명이나 코멘트에 낱말이 있는 작업 | **설명** 또는 **코멘트** · **포함** |

- 고를 수 있는 항목: 번호, 제목, 설명, 코멘트, 상태, 유형, 우선순위, 담당자, 담당자의 그룹, 담당자의 역할, 책임자, 작성자, 주시자, 버전, 카테고리, 프로젝트, 상위 작업, 시작일, 완료일, 일정 기간, 만든 날, 최근 수정, 기간(일), 완료 %, 작업량(시간), 남은 작업(시간), 일정 방식, 마일스톤, 다른 작업에 막힘, 그리고 관리자가 필터로 쓰게 한 사용자 정의 필드.
- 결과가 없으면 **조건에 맞는 작업이 없습니다**와 **필터 초기화** 버튼이 나옵니다.

### 6.2 열 고르기

**열 보이기·숨기기**

1. 목록 오른쪽 위 ⋯(**보기 메뉴**)를 누릅니다.
2. **표시할 열**에 마우스를 올리면(또는 누르면) 열 목록이 나옵니다.
3. 열 이름을 눌러 체크하면 보이고, 체크를 풀면 숨겨집니다.

**열 순서 바꾸기·숨기기**

1. 표의 열 제목을 누릅니다(**{{열}} 열 메뉴**).
2. **왼쪽으로 이동** / **오른쪽으로 이동**으로 순서를 바꾸고, **열 숨기기**로 숨깁니다(번호·제목 열은 숨길 수 없음).

- 고를 수 있는 열: 번호, 제목, 유형, 상태, 우선순위, 담당자, 책임자, 작성자, 버전, 시작일, 완료일, 기간, 작업량, 남은 작업, 완료 %, 최근 수정, 프로젝트, 그리고 켜진 사용자 정의 필드.
- **작업량**·**남은 작업**은 시간 단위로 보입니다(예: 8시간).

### 6.3 정렬

1. 정렬할 열의 제목을 누릅니다.
2. **오름차순 정렬** 또는 **내림차순 정렬**을 고릅니다. 열 제목에 화살표가 표시됩니다.
3. 두 번째 기준을 더하려면 다른 열 제목에서 **정렬 기준에 추가**를 고릅니다. 기준은 3개까지이며 열 제목에 순번이 표시됩니다.
4. 기준을 빼려면 그 열에서 **정렬 기준에서 빼기**를 고릅니다.

- 정렬할 수 있는 열: 번호, 제목, 유형, 상태, 우선순위, 담당자, 책임자, 작성자, 버전, 시작일, 완료일, 작업량, 남은 작업, 최근 수정, 프로젝트, 사용자 정의 필드.
- 목록을 그룹화했으면 그룹 순서가 먼저이고, 그룹 안에서 정렬 기준을 따릅니다([6.7](#67-그룹화와-합계)).

### 6.4 계층 표시와 하위 프로젝트 포함

- **계층 표시** 버튼을 누르면 상위·하위 작업이 들여쓰기로 보입니다. 제목 앞 화살표(**하위 작업 펼치기** / **하위 작업 접기**)로 하위 작업을 접고 펼칩니다. 필터에 맞지 않는 상위 작업은 흐린 글씨로 함께 보입니다.
- **하위 프로젝트 포함** 버튼(프로젝트 목록에서만)을 누르면 하위 프로젝트의 작업까지 함께 보입니다.
- 화면이 좁으면 두 버튼은 아이콘만 보입니다.
- 목록을 그룹화하면 **계층 표시**가 꺼집니다. 그룹화 중에 **계층 표시**를 누르면 그룹화가 풀리고 계층 표시가 켜집니다([6.7](#67-그룹화와-합계)).

### 6.5 저장된 보기

**보기 고르기**

1. 프로젝트의 작업 화면 왼쪽 메뉴에 보기 목록이 나옵니다: **기본 보기**(모두 열림, 내게 할당됨, 내가 만듦, 최근 업데이트, 기한 지남, 모든 작업), **즐겨찾기**, **공개 보기**, **내 보기**.
2. 보기 이름을 누르면 그 설정으로 목록이 바뀝니다. 위쪽 **보기 이름으로 찾기**로 보기를 찾을 수 있습니다.
3. 왼쪽 메뉴 위 **프로젝트 메뉴로**를 누르면 프로젝트 메뉴로 돌아갑니다.

**새 보기로 저장하기**

1. 필터·열·정렬을 원하는 대로 바꿉니다.
2. ⋯(**보기 메뉴**) › **다른 이름으로 저장**을 누릅니다.
3. **보기 이름**을 입력합니다.
4. 프로젝트 멤버 모두와 함께 쓰려면 **프로젝트 멤버 모두에게 공개**를 켭니다(공개 보기 관리 권한이 있을 때만 보임).
5. **저장**을 누릅니다(**보기를 저장했습니다**). 새 보기가 왼쪽 메뉴에 나타납니다.

**지금 보기에 덮어쓰기**

1. 내가 만든 보기(또는 고칠 수 있는 공개 보기)에서 설정을 바꿉니다.
2. ⋯ › **보기 저장**을 누릅니다.

**그 밖의 보기 관리**

| 메뉴 | 하는 일 |
| --- | --- |
| **변경 취소** | 저장하지 않은 변경을 버리고 보기의 원래 설정으로 |
| **즐겨찾기에 추가** / **즐겨찾기에서 빼기** | 왼쪽 메뉴 **즐겨찾기** 묶음에 넣거나 뺌 |
| **보기 이름 바꾸기** | 이름 변경(**보기 이름을 바꿨습니다**) |
| **보기 삭제** | 보기 삭제(작업은 지워지지 않음) |

- 기본 보기는 이름 바꾸기·삭제·덮어쓰기를 할 수 없습니다. 바꾼 설정은 **다른 이름으로 저장**으로 남기세요.
- 보기 저장은 프로젝트 안 작업 목록에서 합니다. 전역 작업 목록에서는 저장할 수 없습니다.

### 6.6 내보내기

1. 내보낼 목록을 필터와 정렬로 준비합니다.
2. ⋯(**보기 메뉴**) › **내보내기**를 누릅니다(내보내기 권한이 있을 때).
3. 대화상자 위에 **작업 {{n}}건을 내보냅니다. 페이지와 상관없이 필터에 맞는 전부입니다.**가 보입니다.
4. **파일 형식**을 고릅니다: **Excel (.xlsx)**(기본), **CSV**, **PDF**. PDF는 아래 "PDF로 내보내기"를 보세요.
5. **내보낼 열**을 확인합니다. 목록에 보이는 열로 시작하며, 화살표로 순서를 바꾸고 x로 빼고, **추가할 열**에서 골라 **열 추가**로 더합니다.
6. 설명까지 넣으려면 **설명도 넣기 (마지막 열, 서식 없는 글)**를 켭니다.
7. **내보내기**를 누릅니다. 파일이 내려받아집니다(**{{파일명}} 파일을 만들었습니다**).

- 한 번에 5,000건까지 내보낼 수 있습니다. 더 많으면 필터로 나눠 내보내세요.
- 내보내기 권한이 없는 프로젝트의 작업이나 공유받아 보기만 하는 작업은 빠지며, 빠지는 건수가 안내됩니다.
- 파일의 날짜는 화면의 날짜 형식과 관계없이 `YYYY-MM-DD`, 최근 수정 시각은 `YYYY-MM-DD HH:mm`(24시간)로 들어갑니다.

**PDF로 내보내기**

인쇄하거나 그대로 나눠 볼 문서가 필요할 때 씁니다.

1. ⋯(**보기 메뉴**) › **내보내기**에서 **파일 형식**을 **PDF**로 고릅니다.
2. **PDF 종류**를 고릅니다.

   | 종류 | 내용 |
   | --- | --- |
   | **표**(기본) | 고른 열로 만든 표. 가로 A4, 쪽마다 머리글이 반복되고 쪽 번호가 붙음 |
   | **보고서** | 작업마다 속성과 설명을 차례로. 세로 A4 |
   | **Gantt** | 작업마다 기간 막대·마일스톤과 오늘 선. 가로 A4 |

3. **표**를 골랐다면 **내보낼 열**과 **설명도 넣기**를 정합니다(**보고서**·**Gantt**는 열을 고르지 않습니다).
4. **내보내기**를 누르면 PDF 파일이 내려받아집니다. 문서 제목은 보기 이름이고, 그 아래에 건수·만든 시각·만든 사람이 적힙니다.

- PDF는 한 번에 1,000건까지 만들 수 있습니다. 더 많으면 **PDF로 내보내기에는 작업이 너무 많습니다.**가 나옵니다. 필터로 줄이거나 Excel·CSV를 쓰세요.
- 한글은 PDF에 들어 있는 글꼴로 그대로 보입니다. 글꼴에 없는 일부 기호·이모지는 '?'로 보일 수 있습니다.

### 6.7 그룹화와 합계

**항목별로 묶어 보기(그룹화)**

1. 목록 오른쪽 위 ⋯(**보기 메뉴**)를 누릅니다.
2. **그룹화**에 마우스를 올리면(또는 누르면) 기준 목록이 나옵니다: **그룹화 안 함**, **유형**, **상태**, **우선순위**, **담당자**, **책임자**, **작성자**, **버전**, **프로젝트**, 그리고 이 프로젝트에서 켜진 목록·사용자·예/아니요 형식의 사용자 정의 필드.
3. 기준을 고르면 목록이 그룹으로 나뉩니다. 그룹마다 머리글이 붙습니다.
   - 머리글에는 그룹 이름과 건수(예: **3건**)가 보입니다. 유형·상태·우선순위로 묶으면 이름 앞에 그 색의 점이 붙습니다.
   - 값이 없는 작업(예: 담당자가 없는 작업)은 **(값 없음)** 그룹으로 묶여 맨 뒤에 옵니다.
4. 머리글을 누르면 그 그룹을 접고, 다시 누르면 펼칩니다.
5. 그룹화를 풀려면 **그룹화** › **그룹화 안 함**을 고릅니다.

- 그룹화를 고른 뒤 곧바로 **합계 표시**나 **표시할 열**을 눌러도 앞에서 고른 설정은 그대로 남습니다.

**합계 보기**

1. ⋯(**보기 메뉴**) › **합계 표시**를 누릅니다. 다시 누르면 꺼집니다.
2. 그룹화한 목록에서는 그룹마다 마지막 행 아래에 **{{그룹 이름}} 합계** 행이, 표 맨 아래에 **전체 합계** 행이 나옵니다. 그룹화하지 않았으면 **전체 합계** 행만 나옵니다.
3. 합계는 목록에 보이는 열 중 **작업량**, **남은 작업**(시간 합), **완료 %**, 숫자 형식 사용자 정의 필드에 나옵니다. 합계를 보려면 그 열을 먼저 켜 두세요([6.2](#62-열-고르기)).

**완료 % 합계는 이렇게 계산합니다**

작업 상세의 **합계 완료 %**와 같은 방식이며, 시스템 관리자가 **관리** › **진행률 추적**에서 정한 합계 방식을 따릅니다.

- **작업량 가중**(기본): (작업량 합 − 남은 작업 합) ÷ 작업량 합. 작업량은 적었지만 남은 작업을 비워 둔 작업은 아직 시작하지 않은 것으로 칩니다. 예를 들어 작업량 8시간, 남은 작업이 빈 작업 하나뿐인 그룹의 완료 % 합계는 0%입니다. 진행 상황을 반영하려면 남은 작업이나 완료 %를 입력하세요.
- **단순 평균**: 완료 %가 입력된 작업들의 평균입니다.
- 어느 방식이든 **취소**처럼 합계에서 빼도록 정한 상태의 작업은 완료 % 합계에 넣지 않습니다. **작업량**·**남은 작업** 합계에는 목록에 든 모든 작업이 들어갑니다.

- 그룹의 건수와 합계는 지금 보이는 페이지가 아니라 필터에 맞는 작업 전체를 기준으로 합니다.
- 그룹화하면 **계층 표시**가 꺼지고, **계층 표시**를 켜면 그룹화가 풀립니다.
- 그룹화와 합계 표시도 보기 설정이므로 ⋯ › **보기 저장** 또는 **다른 이름으로 저장**으로 남길 수 있습니다([6.5](#65-저장된-보기)). 그룹을 접은 상태는 저장되지 않습니다.
- 내보내기 파일에는 그룹 머리글과 합계 행이 들어가지 않습니다.
- 휴대폰처럼 좁은 화면에서는 카드 목록 사이에 그룹 제목과 건수가 보입니다(접기와 합계 행은 없음).

### 6.8 강조 표시

상태·우선순위·유형에 따라 행에 색을 입히거나, 우선순위와 완료일 칸만 눈에 띄게 할 수 있습니다.

1. 목록 오른쪽 위 ⋯(**보기 메뉴**) › **강조 표시**에 마우스를 올립니다(또는 누릅니다).
2. 방식을 고릅니다.

   | 방식 | 보이는 모습 |
   | --- | --- |
   | **없음**(기본) | 색 없음 |
   | **셀 강조(우선순위, 완료일 지남·임박)** | 우선순위 칸에 그 우선순위 색, 완료일 칸은 기한이 지났으면 빨간색, 3일 안이면 주황색 계열 |
   | **행 색: 상태** / **행 색: 우선순위** / **행 색: 유형** | 행 왼쪽에 그 값의 색 막대와 옅은 배경 |

- 색은 글자가 잘 읽히도록 옅게 섞습니다. 기한 지난 날짜는 색 말고도 화면 낭독기에 **(기한 지남)**으로 읽힙니다.
- 강조 표시도 보기 설정입니다. ⋯ › **보기 저장** 또는 **다른 이름으로 저장**으로 남기고, 주소를 보내면 같은 강조로 보입니다.

### 6.9 기준선 비교

어제나 지난주와 비교해 무엇이 바뀌었는지 목록에서 바로 봅니다. 회의 전에 "지난주 뒤로 바뀐 것"을 훑을 때 씁니다.

1. 목록 위 **기준선** 버튼을 누릅니다.
2. **어제**, **1주 전**, **한 달 전** 중 하나를 고릅니다. 다른 날과 비교하려면 **날짜 지정…**을 누르고 **기준선 날짜** 대화상자에서 날짜를 골라 **적용**합니다(오늘 이후 날짜는 고를 수 없음).
3. 목록 위에 **기준선 {{날짜}} 0:00 이후의 변경을 표시합니다.**가 나오고, 목록이 이렇게 표시됩니다.
   - 그 뒤 값이 바뀐 칸에는 표시가 붙습니다. 마우스를 올리거나 누르면 **기준선 때: {{그때 값}}**이 보입니다(그때 비어 있었으면 **비어 있음**).
   - 그 뒤에 만든 작업에는 **새로 생김**이 붙습니다.
4. 그때는 이 목록의 조건에 맞았지만 지금은 빠진 작업(예: 그 뒤 완료되어 **모두 열림**에서 빠진 작업, 우선순위가 바뀌어 우선순위 필터에서 빠진 작업)이 있으면 표 아래에 **기준선 이후 목록에서 빠진 작업 {{n}}건**이 나옵니다.
   - 제목에는 줄이 그어져 있고, 앞의 **#번호**를 누르면 그 작업의 활동 화면이 열립니다.
   - 오른쪽에 바뀐 값이 **{{항목}} {{그때}} → {{지금}}** 순서로 보입니다(예: **우선순위 보통 → 긴급**).
5. 끝나면 안내 줄의 **기준선 끄기**를 누르거나 **기준선** › **끄기**를 고릅니다.

![기준선(어제)을 켠 목록과 표 아래의 기준선 이후 목록에서 빠진 작업](../../replica/clone-screens/S06-baseline-removed.png)

- 비교하는 항목: 제목, 유형, 상태, 우선순위, 담당자, 책임자, 버전, 시작일, 완료일, 기간, 완료 %, 작업량, 남은 작업, 프로젝트, 사용자 정의 필드. 기준 시각은 내 시간대의 그날 0시입니다.
- 빠진 작업은 목록의 필터·검색어·하위 프로젝트 포함 여부를 그때 값에 그대로 적용해 고릅니다. 번호가 낮은 것부터 200건까지 보이고, 더 많으면 **많아서 번호가 낮은 {{n}}건만 보여 줍니다.**가 나옵니다.
- 이런 작업은 빠진 작업에 나오지 않습니다: 그 뒤 삭제된 작업, 그때 공유로만 볼 수 있던 작업. 주시자·코멘트·관계로 거른 목록은 그때가 아니라 지금 상태로 판단합니다.
- 기준선도 보기 설정이라 **보기 저장**으로 남길 수 있습니다. 저장한 "1주 전"은 열 때마다 그날로부터 1주 전과 비교합니다.

## 7. 계획 도구

Gantt, 보드, 캘린더, 팀 플래너는 프로젝트에서 모듈을 켰을 때만 프로젝트 메뉴에 보입니다. 꺼진 모듈 주소로 들어오면 **이 프로젝트에서 꺼진 기능입니다**가 나옵니다([11.4](#114-모듈-켜기끄기)).

### 7.1 Gantt

**보기**

1. 프로젝트 메뉴에서 **Gantt**를 누릅니다(모든 프로젝트를 함께 보려면 전역 메뉴의 **Gantt**).
2. 왼쪽에 작업 목록(번호·유형·제목), 오른쪽에 일정 막대가 보입니다. 마름모는 마일스톤, 괄호 모양 막대는 하위 작업에서 날짜가 정해지는 상위 작업, 화살표는 선후행 관계, 빨간 점선은 오늘입니다.
3. 위쪽 **자동**·**일**·**주**·**월**로 눈금을 바꿉니다(**자동**은 기간 길이에 맞춰 고름). **주** 눈금은 시스템 관리자가 정한 주 시작 요일(기본 일요일)부터 한 주를 셉니다.
4. **오늘로 이동**을 누르면 오늘 위치로 스크롤됩니다.
5. **필터**로 작업 목록과 같은 필터를 씁니다. 왼쪽 메뉴의 저장된 보기도 고를 수 있습니다.

**막대 옆 라벨 바꾸기**

1. 위쪽 **라벨**을 누릅니다. **왼쪽: …**, **오른쪽: …**, **먼 오른쪽: …** 세 항목이 보입니다.
2. 바꿀 위치에 마우스를 올리고(키보드는 → 키) **없음**, **제목**, **담당자**, **상태**, **기간**, **유형**, **우선순위**, **완료 %** 중 하나를 고릅니다.
3. 막대 왼쪽·오른쪽에 고른 값이 보입니다. **먼 오른쪽** 값은 차트 오른쪽 끝에 줄을 맞춰 붙습니다.

- 처음에는 오른쪽에 제목만 보입니다. 예를 들어 왼쪽 **담당자**, 먼 오른쪽 **상태**로 두면 누가 맡았고 어디까지 왔는지 한눈에 봅니다.
- 라벨도 보기 설정이라 주소에 남고, 작업 목록에서 **보기 저장**하면 함께 저장됩니다. 전역 Gantt에서도 같습니다.

**일정 바꾸기**

1. 막대 가운데를 잡고 좌우로 끌면 작업 전체가 옮겨집니다.
2. 막대 왼쪽·오른쪽 끝(마우스를 올리면 보임)을 끌면 시작일·완료일이 바뀝니다. 끄는 동안 막대 옆에 새 날짜가 보입니다.
3. 놓으면 저장되고, 자동 일정인 후행 작업과 상위 작업이 함께 조정됩니다.
4. 막대를 누르면(키보드는 Enter) **날짜** 대화상자가 열립니다([5.5](#55-날짜-정하기)).

**날짜 없는 작업에 막대 그리기**

시작일이나 완료일이 없는 작업은 막대가 없고, 그 행에 마우스를 올리면 포인터가 십자 모양으로 바뀌며 **날짜가 없습니다. 끌어서 막대를 그리면 그 기간이 시작일·완료일이 됩니다(누르기만 하면 하루)**가 보입니다.

1. 정하고 싶은 시작일 칸에서 마우스 버튼을 누릅니다. 날짜 칸이 좁으면 위쪽 **일** 눈금으로 바꾸면 편합니다.
2. 누른 채로 완료일 칸까지 끕니다(왼쪽으로 끌어도 됩니다). 끄는 동안 반투명 막대가 그려집니다.
3. 버튼을 놓으면 그 구간이 시작일·완료일로 저장되고 일반 막대가 됩니다. 자동 일정인 후행 작업과 상위 작업도 함께 조정됩니다.

- 누르기만 하고 바로 놓으면 그날 하루짜리 일정이 됩니다.
- 마일스톤은 끌어도 놓은 날 하루가 날짜가 됩니다.
- 키보드로는 Tab으로 그 행까지 가면 **#{{번호}} 날짜 정하기** 버튼이 나타납니다. Enter를 누르면 **날짜** 대화상자가 열립니다([5.5](#55-날짜-정하기)).
- 작업을 고칠 권한이 없으면 막대를 그릴 수 없습니다.

- 제목을 누르면 오른쪽에 작업 상세가 열립니다(전역 Gantt에서는 작업 전체 화면으로 이동).
- 시작일과 완료일이 모두 있는 작업만 막대가 보입니다. 날짜가 없는 작업은 위처럼 막대를 그리거나 날짜 대화상자로 날짜를 정하세요.
- 괄호 모양 막대(자동 일정 상위 작업)는 끌 수 없습니다.
- 저장이 거부되면 막대가 원래 자리로 돌아가고 사유가 표시됩니다.

### 7.2 보드

**보드 열기**

1. 프로젝트 메뉴에서 **보드**를 누릅니다.
2. 보드 목록에서 보드 이름을 누릅니다. 보드 종류는 **상태별**, **담당자별**, **버전별**, **빈 보드**, **하위 프로젝트별**, **상위-하위**입니다.

**카드 옮기기**

1. 카드를 잡고 다른 열로 끌어 놓습니다. 키보드로는 카드의 끌기 손잡이에서 스페이스로 들고, ←/→로 옆 열, ↑/↓로 열 안 순서를 고른 뒤 스페이스로 놓습니다(Esc는 취소).
2. 보드 종류에 따라 값이 바뀝니다.
   - **상태별**: 상태가 바뀝니다. 내 역할에 허용된 전환만 됩니다.
   - **담당자별**: 담당자가 바뀝니다.
   - **버전별**: 대상 버전이 바뀝니다.
   - **빈 보드**: 작업의 속성은 바뀌지 않고, 보드 안의 위치만 바뀝니다(보드 관리 권한이 있을 때만 옮길 수 있음).
   - **하위 프로젝트별**: 작업이 그 열의 하위 프로젝트로 옮겨집니다(아래 "하위 프로젝트별 보드").
   - **상위-하위**: 작업의 상위 작업이 그 열의 작업으로 바뀝니다(아래 "상위-하위 보드").
3. 같은 열 안에서 위아래로 끌어 순서를 바꿀 수도 있습니다.

- 옮길 수 없는 열에 놓으면 카드가 원래 자리로 돌아가고 **이 열로 옮길 수 없습니다**가 나옵니다.
- 카드를 누르면 오른쪽에 작업 상세가 열립니다.
- 담당자별 보드에는 열린 작업만 보입니다.

**열에서 바로 새 작업 만들기**(상태별·담당자별·버전별·하위 프로젝트별·상위-하위 보드, 작업 만들기 권한)

1. 열 머리의 + 버튼(**{{열}}에 작업 추가**)을 누릅니다. 열 아래에 제목 입력란(**제목을 입력하고 Enter**)이 열립니다.
2. 제목을 입력하고 Enter를 누릅니다. 작업이 만들어지고(**#{{번호}}을(를) 만들었습니다**) 카드가 그 열에 나타납니다. 입력란은 열린 채로 남아 이어서 만들 수 있습니다.
3. 그만두려면 Esc를 누르거나, 빈 입력란에서 다른 곳을 누릅니다.

- 새 작업은 그 열의 값을 받습니다. 예를 들어 **진행 중** 열에서 만들면 상태가 **진행 중**, 어떤 사람의 열에서 만들면 담당자가 그 사람입니다. 하위 프로젝트별 보드의 열에서 만들면 그 하위 프로젝트에, 상위-하위 보드의 열에서 만들면 그 열 작업의 하위 작업으로 만들어집니다.
- 유형은 프로젝트의 기본 유형(없으면 프로젝트의 첫 유형)입니다. 다른 항목은 만든 뒤 카드를 눌러 상세에서 고치세요.
- 제목 없이 Enter를 누르면 **제목을 입력하세요.**가 나오고 작업은 만들어지지 않습니다.

**빈 보드 쓰기**(보드 관리 권한)

빈 보드는 팀이 직접 목록을 만들고 작업을 골라 넣는 보드입니다. 카드를 넣거나 옮기거나 빼도 작업 자체는 바뀌지 않습니다.

1. 열 머리의 + 버튼을 누르면 메뉴가 나옵니다.
   - **새 작업 만들기**: 위와 같이 제목을 입력해 새 작업을 만들고, 그 목록에 넣습니다(작업 만들기 권한도 필요).
   - **기존 작업 넣기**: **'{{열}}'에 작업 넣기** 대화상자가 열립니다.
2. 대화상자의 **제목이나 #번호로 찾기**에 제목 일부나 번호(예: #12)를 입력합니다. 이 프로젝트의 작업이 최근 수정순으로 보입니다.
3. 넣을 작업 옆 **넣기**를 누릅니다(**#{{번호}}을(를) '{{열}}'에 넣었습니다**). 이미 그 목록에 있는 작업에는 **보드에 있음**이 보입니다. 다른 목록에 있던 작업을 넣으면 이 목록으로 옮겨집니다.
4. 다 넣었으면 **닫기**를 누릅니다.
5. 카드를 보드에서 빼려면 카드의 X 버튼(**#{{번호}} 보드에서 빼기**)을 누릅니다(**#{{번호}}을(를) 보드에서 뺐습니다. 작업은 그대로입니다.**).

- 목록(열)을 더하거나 이름을 바꾸는 방법은 [11.8](#118-보드공개-보기-관리)을 보세요.

**하위 프로젝트별 보드**

열마다 이 프로젝트 바로 아래의 하위 프로젝트 하나가 있고, 카드는 그 하위 프로젝트의 작업입니다. 하위 프로젝트끼리 일을 나눠 맡을 때 씁니다.

1. 카드를 다른 하위 프로젝트의 열로 끌어 놓습니다.
2. 작업이 그 하위 프로젝트로 옮겨집니다. 작업 상세 ⋯ › **다른 프로젝트로 이동**과 같습니다: 번호는 그대로이고 하위 작업도 함께 옮겨지며, 옮겨 간 프로젝트의 멤버가 아닌 담당자·책임자와 버전·카테고리는 비워집니다([5.12](#512-복사와-이동)).

- 옮겨 갈 하위 프로젝트가 그 작업(또는 하위 작업)의 유형을 쓰지 않으면 옮겨지지 않고 카드가 원래 자리로 돌아가며 사유가 나옵니다. 그 프로젝트의 **작업 설정**에서 유형을 켜거나, 작업 상세의 **다른 프로젝트로 이동**에서 새 유형을 골라 옮기세요.
- 열에는 내가 작업을 볼 수 있는 하위 프로젝트만 나옵니다. 하위 프로젝트의 하위(손자 프로젝트)는 열이 되지 않습니다. 하위 프로젝트를 다른 상위로 옮기거나 보관하면 그 열은 보드에서 사라지고, 다시 이 프로젝트 바로 아래로 돌아오면 다시 보입니다.
- 하위 프로젝트를 새로 만든 뒤에는 **열 추가**에서 그 프로젝트를 골라 열을 더합니다([11.8](#118-보드공개-보기-관리)).
- 하위 프로젝트를 정하는 방법은 [11.10](#1110-하위-프로젝트상위-프로젝트-정하기)을 보세요.

**상위-하위 보드**

열마다 상위 작업 하나(**#번호 제목**)가 있고, 카드는 그 하위 작업입니다. 큰 작업을 나눈 하위 작업들을 한눈에 보고 다른 상위 작업으로 옮길 때 씁니다.

1. 카드를 다른 상위 작업의 열로 끌어 놓습니다.
2. 작업의 상위 작업이 그 열의 작업으로 바뀝니다(작업 상세의 **상위 작업**도 바뀜).

- 처음에는 이 프로젝트에서 하위 작업이 있는 작업(번호가 작은 순으로 최대 6개)이 열이 됩니다.
- 다른 작업을 열로 더하려면 보드 오른쪽 위 **열 추가**를 누릅니다. **상위 작업을 열로 추가** 대화상자에서 제목이나 #번호로 찾아 **열로 추가**를 누릅니다(보드 관리 권한). 하위 작업이 아직 없는 작업도 열로 넣을 수 있습니다.
- 자기 자신이나 자기 하위 작업 아래로는 옮길 수 없습니다. 그런 열에 놓으면 카드가 원래 자리로 돌아갑니다.

**보드 필터**

1. 보드 오른쪽 위 **필터**를 누릅니다. 작업 목록과 같은 필터 패널이 열립니다([6.1](#61-필터)). **제목이나 #번호로 찾기**로 제목 검색도 됩니다.
2. 필터를 바꾸면 모든 열의 카드가 바로 좁혀집니다. 이때 **저장하지 않은 필터로 보고 있습니다**가 나옵니다. 이 상태는 나에게만 보이고, 새로 고치면 사라집니다.
3. 원래대로 돌리려면 **저장된 필터로 되돌리기**를 누릅니다.
4. 보드 관리 권한이 있으면 **필터 저장**을 눌러 이 필터를 보드에 저장할 수 있습니다(**보드 필터를 저장했습니다**). 저장한 필터는 보드를 보는 모든 사람에게 적용되고, **필터** 버튼에 필터 수가 표시됩니다.

**보드 만들기와 구성**(보드 관리 권한이 있는 사용자)은 [11.8](#118-보드공개-보기-관리)을 참고하세요.

### 7.3 캘린더

**캘린더 만들기**

1. 프로젝트 메뉴에서 **캘린더**를 누릅니다.
2. **캘린더 만들기**를 누릅니다.
3. **이름**을 입력합니다. 프로젝트 멤버와 함께 보려면 **공개**를 켜 둡니다(공개 보기 관리 권한이 있을 때만 보임, 기본 켬).
4. **만들기**를 누릅니다. 새 캘린더가 열립니다. 처음에는 열린 작업이 보입니다.

**캘린더 쓰기**

1. 캘린더 목록에서 이름을 눌러 엽니다.
2. **월** / **주**로 보기 단위를 고르고, **이전**·**오늘**·**다음**으로 기간을 옮깁니다.
3. 작업을 끌어 다른 날로 옮기면 날짜가 바뀝니다. 작업 끝을 끌면 기간이 바뀝니다.
4. 빈 날짜를 끌어 기간을 고르면 그 기간이 채워진 새 작업 폼이 열립니다. **작업 만들기** 버튼으로도 새 작업을 만들 수 있습니다.
5. 작업을 누르면(키보드는 Enter) 오른쪽에 상세가 열립니다.
6. **필터**로 보이는 작업을 좁힐 수 있습니다. 바꾼 필터를 캘린더에 남기려면 **변경 저장**, 버리려면 **변경 취소**를 누릅니다.

- 휴무일은 칸에 이름이 표시되고, 쉬는 날은 음영으로 보입니다. 주는 시스템 관리자가 정한 주 시작 요일부터 시작합니다(기본 일요일).
- 날짜를 바꿀 권한이 없는 작업은 끌 수 없습니다.
- ⋯ 메뉴에서 캘린더 **이름 바꾸기**, **삭제**를 할 수 있습니다. 삭제해도 작업은 그대로 남습니다.

### 7.4 팀 플래너

**팀 플래너 만들기**

1. 프로젝트 메뉴에서 **팀 플래너**를 누릅니다.
2. **팀 플래너 만들기**를 누르고 **이름**을 입력한 뒤 **만들기**를 누릅니다. 처음에는 나 혼자 담당자로 들어가 있습니다.

**사람 추가·빼기**

1. **담당자 추가**를 누르고 프로젝트 멤버를 고릅니다. 바로 저장됩니다.
2. 사람을 빼려면 이름 옆 ⋯ › **{{이름}}을(를) 플래너에서 빼기**를 누릅니다.

**작업 배정하기**

1. **1주** / **2주**(기본)로 기간 길이를 고르고, **이전**·**오늘**·**다음**으로 기간을 옮깁니다. 기간은 주 시작 요일(기본 일요일)부터 셉니다.
2. 작업 막대를 다른 사람의 줄이나 다른 날짜 칸으로 끌어 놓으면 담당자와 날짜가 바뀝니다.
3. 막대 양 끝을 끌면 기간이 바뀝니다.
4. 끄는 동안 나타나는 **여기에 놓으면 담당 해제** 영역에 놓으면 담당자가 비워집니다.
5. 빈 칸을 누르면 그 사람·그날이 채워진 새 작업 폼이 열립니다.

**기존 작업 가져오기**

1. **기존 작업 추가**를 누릅니다. 오른쪽에 패널이 열립니다.
2. **작업 찾기 (#번호나 제목)**에 입력해 열린 작업을 찾습니다.
3. 작업을 사람·날짜 칸으로 끌어 놓거나, 작업 옆 ⋯ › **{{이름}}에게 배정**을 고릅니다.

- 작업을 누르면(키보드는 Enter) 상세가 열립니다.
- 날짜를 바꿀 권한이 없는 작업은 끌 수 없습니다.
- 팀 플래너에는 필터가 없습니다.

## 8. 알림

### 8.1 알림 확인하기

1. 헤더의 종 모양 **알림**(읽지 않은 수 표시) 또는 왼쪽 메뉴 **알림**을 누릅니다.
2. 알림은 작업 단위로 묶여 보입니다. 카드에는 프로젝트, 작업 번호·상태·제목, 최근 알림 내용과 이유(언급, 담당, 책임, 주시, 공유, 새 작업, 코멘트, 상태, 우선순위, 날짜, 시작일 알림, 완료일 알림, 기한 지남)가 보입니다.
3. 카드를 누르면 오른쪽에 그 작업이 **활동** 탭으로 열리고, 그 작업의 알림은 읽음 처리됩니다.
4. 위쪽 **읽지 않음** / **모두**로 목록 범위를 바꿉니다.
5. 한꺼번에 읽음 처리하려면 **모두 읽음으로 표시**를 누릅니다.

- 새 알림이 없으면 **새 알림이 없습니다**가 나옵니다.
- 휴대폰 화면에서는 작업을 열면 목록이 숨겨지고, 패널을 닫으면 돌아옵니다.

### 8.2 알림 거르기

알림이 많을 때 이유나 프로젝트로 좁혀 봅니다. **읽지 않음** / **모두** 버튼 옆에 선택 두 개가 있습니다.

1. **이유로 거르기**를 눌러 이유를 고릅니다.

   | 고르는 이유 | 들어가는 알림 |
   | --- | --- |
   | **언급** | 코멘트에서 나를 언급함 |
   | **담당** / **책임** | 내가 담당자 / 책임자로 지정된 작업 |
   | **주시** | 내가 주시하는 작업의 변경 |
   | **공유** | 작업을 나에게 공유함 |
   | **날짜 알림** | 시작일 알림, 완료일 알림, 기한 지남 |
   | **그 밖의 변경** | 참여하지 않은 작업의 새 작업·코멘트·상태·우선순위·날짜 변경(알림 설정에서 켠 경우) |

2. **프로젝트로 거르기**를 눌러 프로젝트를 고릅니다. 읽지 않은 알림이 있는 프로젝트만 나옵니다(이유를 골랐으면 그 이유의 알림 기준).
3. 목록이 바로 좁혀집니다. 선택지마다 괄호 안에 읽지 않은 알림 수가 보입니다(예: **담당 (2)**, **모바일 앱 2.0 (1)**).
4. 원래대로 보려면 **필터 지우기**를 누르거나, 각 선택에서 **모든 이유** / **모든 프로젝트**를 고릅니다.

- 고른 필터는 화면 주소에 남습니다. 알림을 눌러 작업을 열었다 닫아도, 주소를 복사해 다시 열어도 같은 필터로 보입니다.
- 필터를 건 상태에서 **모두 읽음으로 표시**를 누르면 **그 필터에 맞는 알림만** 읽음 처리됩니다. 목록에 다 보이지 않는 오래된 알림도 필터에 맞으면 함께 읽음이 됩니다. 예를 들어 **담당**으로 거른 뒤 누르면 담당 알림은 모두 읽음이 되고 언급 알림은 읽지 않은 채로 남습니다.
- 조건에 맞는 알림이 없으면 **조건에 맞는 알림이 없습니다**가 나옵니다.
- 필터의 수는 내 모든 읽지 않은 알림을 기준으로 셉니다. **모든 이유**·**모든 프로젝트**의 수는 헤더 종 모양의 수와 같습니다. 목록에는 필터에 맞는 알림 가운데 최근 500건까지 보입니다.

### 8.3 알림 받을 일 정하기

1. 계정 메뉴(아바타) › **알림 설정**을 누릅니다(알림 화면 오른쪽 위 톱니바퀴로도 열림).
2. **알림** 탭의 **기본 설정**에서 항목을 켜고 끕니다.

   | 묶음 | 항목 |
   | --- | --- |
   | **참여한 작업** | **나를 언급할 때**, **주시 중인 작업**(항상 받음), **내가 담당자인 작업**, **내가 책임자인 작업**, **나에게 공유된 작업** |
   | **날짜 알림** | **시작일**, **완료일**(각각 **당일**·**1일 전**·**3일 전**·**7일 전** 중 시점 선택), **기한이 지나면** |
   | **참여하지 않은 작업** | **새 작업**, **모든 코멘트**, **상태 변경**, **우선순위 변경**, **날짜 변경**(볼 수 있는 모든 작업이 대상이라 알림이 많아질 수 있음) |

3. **기본 설정 저장**을 누릅니다.

**특정 프로젝트만 다르게 받기**

1. **프로젝트별 설정**의 **설정을 추가할 프로젝트**에서 프로젝트를 고르고 **추가**를 누릅니다. 기본 설정을 복사한 카드가 생깁니다.
2. 카드에서 항목을 바꾸고 **저장**을 누릅니다.
3. 다시 기본 설정을 쓰려면 카드의 삭제 버튼(**{{프로젝트}} 설정 삭제**)을 누릅니다.

- 날짜 알림은 내 시간대 기준이며, 담당·책임·주시 중인 열린 작업이 대상입니다.

### 8.4 이메일 받는 방식 정하기

1. **알림 설정** 화면에서 **이메일** 탭을 누릅니다.
2. 필요한 항목을 정합니다.
   - **나를 언급하면 바로 메일 받기**: 끄면 언급도 하루 요약 메일에 함께 담깁니다.
   - **읽지 않은 알림을 모아 메일로 받기**: 켜면 **요약 시각**마다 그때까지 읽지 않은 알림을 한 통으로 받습니다. **시각 추가**로 시각을 늘리고(최대 4개), 휴지통으로 지웁니다.
   - **날짜 알림 일시 중지**: 휴가 등으로 쉬는 동안 **이 날짜까지 멈추기**에 날짜를 넣습니다. 다른 알림은 그대로 옵니다. **일시 중지 해제**로 되돌립니다.
3. **이메일 설정 저장**을 누릅니다.

## 9. 검색

### 9.1 빠른 검색

1. 헤더의 **전체 검색** 입력란(**작업, 프로젝트 검색 (#번호)**)에 낱말이나 `#번호`를 입력합니다.
2. 잠시 뒤 아래에 작업과 프로젝트 후보가 나옵니다.
3. 위·아래 화살표로 고르고 Enter를 누르거나 마우스로 누르면 바로 열립니다.
4. 맨 아래 **'{{검색어}}' 전체 결과 보기**를 고르거나, 후보를 고르지 않고 Enter를 누르면 검색 결과 화면이 열립니다.
5. Esc를 누르면 후보 목록이 닫히고, 한 번 더 누르면 입력이 지워집니다.

### 9.2 검색 결과 화면

1. **검색 결과** 화면에서 **모두** / **작업** / **프로젝트** 탭으로 범위를 고릅니다.
2. 결과에는 찾은 위치(**번호**·**제목**·**설명**·**코멘트**에서 찾음)와 일치한 부분이 강조되어 보입니다.
3. 결과를 누르면 해당 작업이나 프로젝트가 열립니다.
4. 결과가 많으면 아래 화살표로 페이지를 넘깁니다.

- 내가 볼 수 있는 작업(공유받은 작업 포함)과 프로젝트만 찾습니다.
- 화면 폭이 768px보다 좁으면 헤더에 검색 입력란이 보이지 않습니다. 넓은 화면에서 쓰거나, 주소창에 openPMS 주소 뒤 `/search`를 붙여 검색 결과 화면을 직접 엽니다.

## 10. 계정 설정

계정 메뉴(아바타) › **내 계정**을 누르면 열립니다.

### 10.1 이름과 시간대

1. **프로필**의 **이름**을 고칩니다.
2. **시간대**를 고릅니다(검색해서 고를 수 있음). 날짜 알림, 요약 메일, '오늘'과 기한 지남은 이 시간대 기준으로 계산합니다.
3. **프로필 저장**을 누릅니다.

- **이메일**은 관리자가 바꿉니다.

### 10.2 비밀번호 바꾸기

1. **비밀번호 변경**에 **현재 비밀번호**, **새 비밀번호**, **새 비밀번호 확인**을 입력합니다. 묶음 설명에 비밀번호 규칙이 나옵니다.
2. **비밀번호 바꾸기**를 누릅니다(**비밀번호를 바꿨습니다**).

- 바꾸면 다른 기기의 로그인은 끝납니다.
- 회사 계정(SSO)도 연결된 계정은 묶음 설명 끝에 **사내 계정({{공급자 이름}})으로도 로그인할 수 있습니다.**가 나옵니다. 비밀번호를 바꿔도 회사 계정 로그인은 그대로 됩니다.

**비밀번호가 없을 때(회사 계정으로만 로그인하는 경우)**

회사 계정(SSO)으로 처음 로그인해 자동으로 만들어진 계정에는 비밀번호가 없습니다. 이때는 **비밀번호 변경** 대신 **비밀번호** 묶음이 보이고, **{{공급자 이름}}(으)로 로그인하고 있어 비밀번호가 없습니다. …** 안내가 나옵니다. 비밀번호를 만들면 로그인 화면에서 이메일과 비밀번호로도 로그인할 수 있습니다.

1. **비밀번호** 묶음의 **비밀번호 만들기 링크 받기**를 누릅니다.
2. **{{이메일}}(으)로 링크를 보냈습니다**가 나오면 메일함에서 제목이 **[openPMS] 비밀번호 만들기**인 메일을 엽니다.
3. 메일의 링크를 누르면 **새 비밀번호 정하기** 화면이 열립니다. 이후는 [2.3](#23-비밀번호를-잊었을-때)의 5–7단계와 같습니다(새 비밀번호 두 번 입력 → **비밀번호 저장** → 새 비밀번호로 로그인).

- 링크는 내 계정의 이메일 주소로만 갑니다. 한 번만 쓸 수 있고 정해진 시간(기본 60분)이 지나면 만료됩니다. 다시 요청하면 이전 링크는 쓸 수 없습니다.
- 비밀번호를 저장하면 모든 기기에서 로그아웃됩니다. 그 뒤에도 회사 계정 로그인은 그대로 쓸 수 있습니다.
- 회사에서 **비밀번호를 잊으셨나요?**(재설정)를 꺼 두었어도 이 방법은 쓸 수 있습니다.
- 버튼을 짧은 시간에 여러 번 누르면 **요청이 너무 많습니다.**가 나옵니다. 잠시 뒤 다시 누르세요. 이미 비밀번호가 있는 계정이면 **이미 비밀번호가 있습니다.**가 나옵니다. 위의 비밀번호 바꾸기를 쓰세요.
- 내가 요청하지 않은 **[openPMS] 비밀번호 만들기** 메일을 받았다면 링크를 열지 말고 시스템 관리자에게 알리세요.

### 10.3 화면 설정

| 항목 | 설명 |
| --- | --- |
| **테마** | **시스템 설정**(운영체제 설정을 따름), **라이트**, **다크**, **고대비**(더 진한 글자와 테두리, 검정 포커스 테두리). 고르면 바로 적용·저장. **고대비**는 운영체제가 다크 모드여도 밝은 고대비로 보임 |
| **최신 활동을 맨 위에** | 작업의 활동 탭을 최신순으로 보여 주고 코멘트 입력란을 위에 둠 |
| **저장하지 않은 내용이 있으면 떠나기 전에 묻기** | 코멘트나 설명을 쓰다가 탭을 닫거나 새로 고칠 때 확인 |
| **키보드 단축키** | 화면 전체 단축키(`?`, `/`, `n`, `g`+글자)를 켜고 끔(새 계정은 켜짐). 목록은 [12.1](#121-화면-전체-단축키) |

- 날짜·시간 표시 형식(예: 2026.10.21, 24시간)과 주 시작 요일은 개인 설정이 아닙니다. 시스템 관리자가 **관리** › **달력과 날짜**의 **날짜 형식**에서 모든 사람에게 같은 형식으로 정합니다. 바꾸고 싶으면 시스템 관리자에게 요청하세요.
- "3시간 전" 같은 상대 시각은 그대로이고, 마우스를 올리면 정해진 형식의 정확한 시각이 보입니다.
- 요약 메일의 항목 시각, 날짜 필터 **이번 주**의 범위(주 시작 요일부터 7일)도 이 설정을 따릅니다.

### 10.4 다른 기기에서 로그아웃하기

1. **로그인 세션**의 **다른 기기에서 모두 로그아웃**을 누릅니다.
2. **다른 기기의 로그인을 모두 끝낼까요?**에서 확인합니다. 지금 쓰는 브라우저의 로그인은 유지됩니다.

### 10.5 API 토큰

사내 시스템(배포 봇, 보고서 도구 등)이 내 이름으로 openPMS를 읽거나 고치게 할 때 토큰을 만듭니다. 토큰은 **내 권한**으로 동작하므로 비밀번호처럼 다룹니다. 연동 프로그램을 만드는 사람은 [14.4](#144-사내-연동-개발자를-위한-안내api-토큰웹훅-서명-확인)도 보세요.

**토큰 만들기**

1. **내 계정** 맨 아래 **API 토큰** 묶음에서 **토큰 만들기**를 누릅니다.
2. **토큰 이름**에 어디에 쓰는지 적습니다(예: 배포 알림 봇).
3. **권한 범위**를 고릅니다.
   - **읽기 전용**(기본): 조회만 합니다(목록 조회·내보내기 포함). 바꾸는 요청은 거절됩니다.
   - **읽기·쓰기**: 내 권한 안에서 만들고 고칠 수 있습니다.
4. **만료**를 고릅니다: **30일 뒤**, **90일 뒤**(기본), **365일 뒤**, **만료 없음**.
5. **만들기**를 누릅니다. **토큰을 만들었습니다** 창에 `opms_`로 시작하는 **토큰 값**이 보입니다.
6. **복사**를 눌러 연동 프로그램의 비밀 설정(비밀값 저장소 등)에 넣고 **확인**을 누릅니다.

- 토큰 값은 이 창에서 **한 번만** 보입니다. 창을 닫으면 openPMS도 원문을 갖고 있지 않아 다시 볼 수 없습니다. 잃어버렸으면 새로 만들고 예전 것은 폐기하세요.
- 꼭 필요할 때만 **읽기·쓰기**를 고르고, 가능하면 만료를 두세요.
- 토큰으로는 로그인·비밀번호·토큰 관리와 연동 설정(관리 · API와 웹훅)을 할 수 없습니다. 관리자의 토큰이라도 마찬가지입니다.

**토큰 목록 보기와 폐기**

- 목록에는 토큰마다 이름, 범위(**읽기 전용** / **읽기·쓰기**), 만든 날, 마지막으로 쓴 때(**아직 쓰지 않음**), 만료일(**만료 없음**)이 보입니다.
- 더 쓰지 않거나 새어 나갔다고 의심되면 그 줄의 **폐기**(**{{이름}} 토큰 폐기**)를 누르고 **'{{이름}}' 토큰을 폐기할까요?**에서 **폐기**를 누릅니다(**토큰을 폐기했습니다**). 그 토큰을 쓰는 연동은 바로 401 오류를 받습니다. 되돌릴 수 없습니다.
- 시스템 관리자도 **관리** › **API와 웹훅**에서 누구의 토큰이든 폐기하거나 토큰 사용 전체를 끌 수 있습니다. 꺼져 있으면 토큰을 만들 수 없고 있는 토큰도 거절됩니다.
- **API 문서 보기**를 누르면 토큰 사용법과 주요 경로가 있는 **API 문서**가 열립니다(헤더 **도움말** › **API 문서**도 같음).

## 11. 프로젝트 관리자 기능

이 장의 기능은 프로젝트 관리자 역할(또는 해당 권한)이 있을 때만 보입니다.

### 11.1 프로젝트 만들기

프로젝트 만들기 권한이 있어야 합니다. 이 권한은 시스템 관리자가 전역 역할(예: **프로젝트 생성자**)로 줍니다([13장](#13-자주-묻는-질문)의 "시스템 관리자에게 오는 요청").

1. 왼쪽 메뉴 **프로젝트** › 오른쪽 위 **프로젝트 만들기**를 누릅니다(헤더 **새로 만들기**(+) › **새 프로젝트**도 됨).
2. 시작 방식을 고릅니다.
   - **빈 프로젝트**(기본): 멤버와 모듈을 직접 정해서 시작합니다.
   - **템플릿에서 시작**: 템플릿으로 정해 둔 프로젝트의 구성과 작업을 복사해 시작합니다([11.9](#119-템플릿-프로젝트)). 템플릿이 하나도 없으면 고를 수 없고 **아직 템플릿이 없습니다. …**가 보입니다.
3. **프로젝트 이름**을 입력합니다.
4. **식별자**를 확인합니다. 이름이 영문이면 자동으로 제안되고, 한글 이름이면 직접 입력합니다. 영문 소문자로 시작하고 영문 소문자, 숫자, 하이픈만 쓸 수 있습니다. 주소에 쓰이며 다른 프로젝트와 겹칠 수 없습니다.
5. 다른 프로젝트 아래에 두려면 **상위 프로젝트**에서 그 프로젝트를 고릅니다. 그대로 두면 **없음(최상위 프로젝트)**입니다([11.10](#1110-하위-프로젝트상위-프로젝트-정하기)).
6. 필요하면 **설명**을 쓰고, 멤버가 아니어도 작업을 볼 수 있게 하려면 **회사 전체에 공개**를 켭니다.
7. **만들기**를 누릅니다(**프로젝트를 만들었습니다**). 새 프로젝트 개요가 열립니다.

- 만든 사람은 새 프로젝트의 관리자 역할로 멤버가 됩니다.
- 이어서 [11.2](#112-멤버-관리)로 멤버를 추가하세요(템플릿에서 멤버를 가져왔다면 확인만 하면 됩니다).

### 11.2 멤버 관리

**멤버 추가**

1. 프로젝트 메뉴에서 **멤버**를 누릅니다.
2. **멤버 추가**를 누릅니다.
3. **이름·이메일·그룹으로 찾기**에 이름, 이메일 또는 그룹명을 입력합니다(예: 김서연, 인프라).
4. 목록에서 추가할 사람이나 그룹을 체크합니다(그룹은 **그룹** 표시). 여러 명을 고를 수 있습니다.
5. **역할**을 고릅니다(기본은 작업을 고칠 수 있는 일반 역할).
6. **추가 ({{n}})**를 누릅니다(**멤버로 추가했습니다 ({{n}})**).

**역할 바꾸기**

1. 멤버 표의 **역할** 칸을 누릅니다.
2. 새 역할을 고르면 바로 저장됩니다.

**멤버 빼기**

1. 멤버 줄 오른쪽 휴지통(**{{이름}} 멤버에서 빼기**)을 누릅니다.
2. **멤버에서 뺄까요?**에서 **삭제**를 누릅니다.

- 뺀 사람은 이 프로젝트의 작업을 더 이상 볼 수 없습니다. 담당 중인 작업은 그대로 남습니다.
- 그룹을 빼면 그 그룹을 통해 받은 권한이 사라지고, 따로 멤버로 추가된 사람은 남습니다.
- 마지막 프로젝트 관리자는 빼거나 다른 역할로 바꿀 수 없습니다(**마지막 프로젝트 관리자입니다.**). 다른 멤버를 먼저 관리자로 지정하세요.
- openPMS 계정이 없는 사람은 시스템 관리자에게 초대를 요청합니다.

### 11.3 프로젝트 정보와 상태

1. 프로젝트 메뉴에서 **프로젝트 설정**을 누릅니다. **정보** 탭이 열립니다.
2. **프로젝트 이름**, **설명**을 고칩니다.
3. **프로젝트 상태**에서 **상태 없음**·**순조로움**·**주의**·**지연** 중 하나를 고르고, **상태 설명**에 한 줄 설명을 씁니다.
4. 공개 여부(**회사 전체에 공개**)를 정합니다.
5. **저장**을 누릅니다.

- 프로젝트 상태와 설명은 개요 화면과 프로젝트 목록에 보입니다.
- 같은 **정보** 탭의 **상위 프로젝트**는 [11.10](#1110-하위-프로젝트상위-프로젝트-정하기), **템플릿으로 쓰기**는 [11.9](#119-템플릿-프로젝트)를 보세요.

### 11.4 모듈 켜기·끄기

1. **프로젝트 설정** › **모듈** 탭을 엽니다.
2. **Gantt**, **보드**, **캘린더**, **팀 플래너**, **시간 기록**(1.6)을 켜거나 끕니다. **작업**은 기본 기능이라 끌 수 없습니다.
3. **저장**을 누릅니다.

- 끈 모듈은 메뉴에서 사라지고, 주소로 들어오면 꺼진 기능이라고 안내합니다. 데이터는 지워지지 않습니다.
- (1.6) **시간 기록**(작업에 쓴 시간을 기록하고 공수 보고서로 모아 봅니다)은 새 프로젝트에서 처음부터 켜져 있습니다. 끄면 **공수 보고서** 메뉴와 작업의 **시간** 탭이 사라지고, 이 프로젝트의 작업은 멤버의 **내 공수**에서 회색(읽기 전용) 칸이 됩니다. 이미 기록한 시간은 지워지지 않고 다시 켜면 그대로 보입니다([15장](#15-공수-기록하기)).

### 11.5 프로젝트 보관

1. **프로젝트 설정** › **정보** 탭 아래 **프로젝트 보관**에서 **보관하기**를 누릅니다.
2. **'{{프로젝트}}' 프로젝트를 보관할까요?**에서 확인합니다.
3. 프로젝트가 읽기 전용이 되고, 프로젝트 목록의 **보관됨**으로 옮겨집니다.

- 복원과 영구 삭제는 시스템 관리자가 합니다.

### 11.6 유형·카테고리·사용자 정의 필드·내부 코멘트

**프로젝트에서 쓸 유형 정하기**

1. **프로젝트 설정** › **작업 설정** 탭을 엽니다.
2. **사용할 유형**에서 이 프로젝트에서 만들 유형을 체크합니다.
3. **저장**을 누릅니다.

- 작업이 있는 유형은 끌 수 없습니다(**쓰고 있는 유형은 끌 수 없습니다.**). 유형은 하나 이상 켜야 합니다.

**카테고리 관리**

1. **카테고리**의 **카테고리 추가**를 누릅니다.
2. **이름**과 **기본 담당자**(선택)를 정하고 **저장**합니다. 기본 담당자를 정하면 이 카테고리로 만든 작업의 담당자로 미리 채워집니다.
3. 고치거나 지우려면 줄 오른쪽 ⋯ › **수정** / **삭제**를 누릅니다. 삭제하면 작업의 카테고리는 비워집니다.

**사용자 정의 필드 켜기**

1. **사용자 정의 필드**에서 이 프로젝트에서 쓸 필드를 체크합니다. **모든 프로젝트** 표시가 있는 필드는 항상 켜져 있습니다.
2. **저장**을 누릅니다.

- 필드는 정해진 유형의 작업에만 보입니다. 필드 자체를 만들거나 고치는 일은 시스템 관리자가 합니다.

**내부 코멘트 켜기**(프로젝트 정보 수정 권한)

1. **프로젝트 설정** › **작업 설정** 탭의 **내부 코멘트** 묶음을 봅니다.
2. **이 프로젝트에서 내부 코멘트 쓰기**를 켜고 저장합니다.
3. 이제 '내부 코멘트 쓰기' 권한이 있는 사람(기본: 프로젝트 관리자)의 코멘트 입력란 아래에 **내부 코멘트** 체크박스가 생깁니다([5.8](#58-코멘트와-멘션)).

- 내부 코멘트는 '내부 코멘트 보기' 권한이 있는 역할(기본: 프로젝트 관리자)만 봅니다. 다른 역할에도 보이게 하려면 시스템 관리자에게 그 역할의 권한을 요청하세요.
- 다시 끄면 새 내부 코멘트는 쓸 수 없지만, 이미 남긴 내부 코멘트는 계속 권한 있는 역할에게만 보입니다.

### 11.7 버전

1. **프로젝트 설정** › **버전** 탭을 엽니다.
2. **버전 추가**를 누릅니다.
3. **이름**, **설명**, **상태**(**진행 중**·**잠김**·**닫힘**), **시작일**, **종료일**을 입력하고 **저장**합니다. 종료일은 시작일 이후여야 합니다.
4. 표에서 버전별 기간과 **완료 / 전체**(닫힌 작업 수 / 전체 작업 수)를 봅니다.
5. 고치거나 지우려면 ⋯ › **수정** / **삭제**를 누릅니다. 삭제하면 그 버전에 묶인 작업의 버전은 비워집니다.

- 버전은 작업의 **버전** 항목과 **버전별** 보드에서 씁니다.

### 11.8 보드·공개 보기 관리

**보드 만들기**(보드 관리 권한)

1. 프로젝트 메뉴 **보드** › **보드 만들기**를 누릅니다.
2. **보드 이름**을 입력합니다.
3. **보드 종류**에서 **상태별**(기본), **담당자별**, **버전별**, **빈 보드**, **상위-하위**, **하위 프로젝트별** 중 하나를 고릅니다. **빈 보드**는 **할 일** 목록 하나로, **하위 프로젝트별**은 바로 아래 하위 프로젝트마다 열 하나로, **상위-하위**는 하위 작업이 있는 작업(최대 6개)마다 열 하나로 시작합니다.
4. **만들기**를 누릅니다(**보드를 만들었습니다**).

- 하위 프로젝트가 없는 프로젝트에서 **하위 프로젝트별** 보드를 만들면 열이 없는 보드가 됩니다. 먼저 하위 프로젝트를 만드세요([11.10](#1110-하위-프로젝트상위-프로젝트-정하기)).

**보드 구성 바꾸기**

| 하고 싶은 일 | 방법 |
| --- | --- |
| 열 추가(상태별·담당자별·버전별·하위 프로젝트별) | 보드 오른쪽 위 **열 추가** › 아직 없는 상태·멤버·버전·하위 프로젝트 선택 |
| 열 추가(빈 보드) | 보드 오른쪽 위 **열 추가** → **열 이름** 입력 → **저장** |
| 열 추가(상위-하위) | 보드 오른쪽 위 **열 추가** → **상위 작업을 열로 추가**에서 제목이나 #번호로 찾기 → **열로 추가**. [7.2](#72-보드) |
| 열 이름 바꾸기(빈 보드) | 열 머리 ⋯ › **열 이름 바꾸기** |
| 열 순서 | 열 머리 ⋯ › **왼쪽으로 옮기기** / **오른쪽으로 옮기기** |
| 열 빼기 | 열 머리 ⋯ › **열 빼기**(작업은 그대로) |
| 보드 이름 바꾸기 | 보드 오른쪽 위 ⋯ › **보드 이름 바꾸기** |
| 보드 삭제 | 보드 오른쪽 위 ⋯ › **보드 삭제** |
| 빈 보드에 작업 넣기·빼기 | 열 머리 + › **기존 작업 넣기**, 카드의 X(**#{{번호}} 보드에서 빼기**). [7.2](#72-보드) |
| 보드 필터 저장 | **필터**로 필터를 바꾼 뒤 **필터 저장**. 보드를 보는 모든 사람에게 적용. [7.2](#72-보드) |

- 열은 30개까지 만들 수 있습니다. 상태·담당자·버전·하위 프로젝트·상위 작업 열의 이름은 그 값의 이름을 따르고 바꿀 수 없습니다. 빈 보드의 열 이름은 1~60자입니다.
- 열 빼기, 빈 보드에서 카드 빼기는 작업을 지우지 않습니다.

**공개 보기 관리**(공개 보기 관리 권한)

- 작업 목록에서 **다른 이름으로 저장** 시 **프로젝트 멤버 모두에게 공개**를 켜면 공개 보기가 됩니다([6.5](#65-저장된-보기)). 캘린더·팀 플래너를 만들 때 **공개**를 켜면 멤버 모두가 볼 수 있습니다.
- 공개 보기의 이름 바꾸기·삭제·덮어쓰기는 고칠 권한이 있는 사람만 할 수 있습니다.

### 11.9 템플릿 프로젝트

잘 꾸려 둔 프로젝트(유형, 모듈, 보드, 반복되는 작업 묶음 등)를 템플릿으로 정해 두면, 새 프로젝트를 만들 때 그대로 복사해 시작할 수 있습니다.

**프로젝트를 템플릿으로 정하기**(프로젝트 정보 수정 권한)

1. 템플릿으로 쓸 프로젝트에서 **프로젝트 설정** › **정보** 탭을 엽니다.
2. **템플릿으로 쓰기**를 켭니다(**새 프로젝트를 만들 때 이 프로젝트를 골라 구성과 작업을 복사할 수 있습니다.**).
3. **저장**을 누릅니다. 이제 새 프로젝트 화면의 템플릿 목록에 이 프로젝트가 나옵니다.

- 템플릿으로 정해도 이 프로젝트는 평소처럼 쓸 수 있습니다. 템플릿에서 빼려면 **템플릿으로 쓰기**를 끄고 저장합니다.
- 보관한 프로젝트와 내가 볼 수 없는 프로젝트는 템플릿 목록에 나오지 않습니다.

**템플릿에서 새 프로젝트 만들기**(프로젝트 만들기 권한)

1. **프로젝트 만들기**에서 **템플릿에서 시작**을 고릅니다.
2. **템플릿**에서 복사할 프로젝트를 고릅니다.
3. **함께 복사할 것**에서 가져갈 것을 고릅니다. 처음에는 모두 켜져 있습니다.

   | 항목 | 가져가는 것 |
   | --- | --- |
   | **멤버와 역할** | 템플릿의 멤버(사람·그룹)와 역할 |
   | **버전** | 버전(이름·상태·기간) |
   | **카테고리** | 카테고리와 기본 담당자 |
   | **작업(계층·관계 포함)** | 모든 작업과 그 상위-하위 관계, 작업끼리의 선후행 등 관계 |
   | **보드** | 보드와 열(하위 프로젝트별 보드는 빼고) |
   | **저장된 보기(공개 보기와 내 보기)** | 템플릿의 공개 보기와, 내가 그 템플릿에 만들어 둔 비공개 보기 |

4. 이름·식별자 등을 입력하고 **만들기**를 누릅니다. 설명을 비워 두면 템플릿의 설명이 들어갑니다.

- 고르지 않아도 늘 가져가는 것: 켜 둔 모듈(Gantt·보드 등), 사용할 작업 유형, 켜 둔 사용자 정의 필드와 프로젝트 특성 값.
- 복사한 작업에는 **만듦** 활동만 남고 알림은 아무에게도 가지 않습니다. 코멘트와 첨부 파일은 복사하지 않습니다.
- 새 프로젝트의 멤버가 아닌 사람은 복사한 작업의 담당자·책임자와 보드 열에서 빠집니다(**멤버와 역할**을 끄면 대부분 비워짐). 복사한 보기·보드 필터에 들어 있던 버전·카테고리는 새 프로젝트의 것으로 바뀝니다.
- **회사 전체에 공개**와 **상위 프로젝트**는 템플릿과 상관없이 이 화면에서 고른 대로입니다.

### 11.10 하위 프로젝트(상위 프로젝트 정하기)

프로젝트를 다른 프로젝트 아래에 두면 하위 프로젝트가 됩니다. 상위 프로젝트의 작업 목록에서 **하위 프로젝트 포함**을 켜면 하위 프로젝트의 작업까지 함께 보이고([6.4](#64-계층-표시와-하위-프로젝트-포함)), **하위 프로젝트별** 보드로 하위 프로젝트끼리 일을 옮길 수 있습니다([7.2](#72-보드)).

**만들 때 정하기**: [11.1](#111-프로젝트-만들기)의 5단계에서 **상위 프로젝트**를 고릅니다.

**나중에 바꾸기**

1. 하위로 옮길 프로젝트에서 **프로젝트 설정** › **정보** 탭을 엽니다.
2. **상위 프로젝트**에서 새 상위 프로젝트를 고릅니다. 맨 위로 올리려면 **없음(최상위 프로젝트)**을 고릅니다.
3. **저장**을 누릅니다.

- 내가 정보를 고칠 수 있는 프로젝트만 상위로 고를 수 있습니다. 목록에 없으면 그 프로젝트의 관리자에게 요청하세요.
- 프로젝트 자신이나 자기 아래의 하위 프로젝트(하위의 하위 포함)는 상위로 고를 수 없습니다(목록에 나오지 않음).
- 프로젝트 목록에서 하위 프로젝트 이름 아래에 **{{상위}}의 하위 프로젝트**가 보입니다.
- 상위 프로젝트를 보관하면 하위 프로젝트는 상위를 복원한 뒤에 복원할 수 있고, 하위 프로젝트가 있는 프로젝트는 삭제할 수 없습니다(시스템 관리자 업무).

### 11.11 프로젝트 복사

이미 잘 꾸려 둔 프로젝트를 그대로 본떠 새 프로젝트를 만듭니다. 템플릿으로 정하지 않은 프로젝트도 복사할 수 있습니다.

1. 복사할 프로젝트에서 **프로젝트 설정** › **정보** 탭을 엽니다.
2. **프로젝트 복사** 묶음의 **프로젝트 복사**를 누릅니다. **{{프로젝트}} 복사** 대화상자가 열립니다.
3. **프로젝트 이름**(처음에는 **{{프로젝트}} (사본)**)과 **식별자**(처음에는 **{{식별자}}-copy**)를 확인하거나 고칩니다.
4. **함께 복사할 것**에서 가져갈 것을 고릅니다. 항목은 템플릿과 같습니다([11.9](#119-템플릿-프로젝트)).
5. **복사해서 만들기**를 누릅니다(**프로젝트를 복사했습니다**). 새 프로젝트 개요가 열립니다.

- 이 버튼은 그 프로젝트의 정보를 고칠 수 있고, 프로젝트 만들기 권한도 있는 사람에게만 보입니다.
- 새 프로젝트는 원본과 같은 상위 프로젝트 아래에 만들어지고, 템플릿으로는 표시되지 않습니다.
- 모듈·유형·사용자 정의 필드, 개요 위젯 구성, 내부 코멘트 설정은 늘 가져갑니다. 복사한 작업에는 알림이 가지 않고, 코멘트·첨부 파일은 복사하지 않습니다.

### 11.12 개요 위젯 편집

프로젝트 개요([4.3](#43-프로젝트-개요-보기))에 보일 위젯과 순서를 정합니다. 프로젝트 정보 수정 권한이 있어야 하고, 정한 구성은 그 프로젝트를 보는 모든 사람에게 같습니다.

1. 프로젝트 개요 오른쪽 위 **위젯 편집**을 누릅니다.
2. 위쪽 **위젯 편집** 묶음에서 보일 위젯을 체크합니다: **설명**, **작업 현황**, **프로젝트 상태**, **멤버**, **버전 진행**, **곧 완료일(14일 안)**, **최근 바뀐 작업(7일)**, **내게 할당된 작업**. 새로 체크한 위젯은 맨 뒤에 붙습니다.
3. 위젯 옆 위·아래 화살표(**{{위젯}} 위로** / **{{위젯}} 아래로**)로 순서를 바꿉니다.
4. 바꿀 때마다 바로 저장됩니다(**저장 중…** → **저장됨**). 다 끝나면 **편집 끝내기**를 누릅니다.

- 위젯을 모두 끄면 개요에 **보이는 위젯이 없습니다**가 나옵니다.
- **내게 할당된 작업** 위젯은 보는 사람마다 자기 작업을 보여 줍니다.
- 프로젝트 상태는 개요에서 바로 고치지 않고 **프로젝트 설정** › **정보**에서 고칩니다([11.3](#113-프로젝트-정보와-상태)).

## 12. 키보드 사용 팁

### 12.1 화면 전체 단축키

로그인 뒤 어느 화면에서나 씁니다. `?`를 누르거나 헤더 **도움말** › **키보드 단축키**를 누르면 이 목록이 열립니다.

| 키 | 동작 |
| --- | --- |
| `?` | 단축키 목록 보기 |
| `/` 또는 `s` | 헤더 **전체 검색**으로 이동 |
| `n` | 이 프로젝트에 새 작업(프로젝트 안, 작업 만들기 권한이 있을 때) |
| `g` 다음 `h` | 홈으로 |
| `g` 다음 `m` | 내 페이지로 |
| `g` 다음 `p` | 프로젝트 목록으로 |
| `g` 다음 `w` | 작업 목록으로(프로젝트 안이면 그 프로젝트의 작업) |
| `g` 다음 `g` | Gantt로(프로젝트 안이면 그 프로젝트의 Gantt) |
| `g` 다음 `b` | 보드로(프로젝트 안) |
| `g` 다음 `o` | 프로젝트 개요로(프로젝트 안) |
| `g` 다음 `n` | 알림으로 |
| `g` 다음 `a` | 관리로(시스템 관리자) |

- `g`를 누른 뒤 1.5초 안에 다음 글자를 누릅니다.
- 입력 칸이나 편집기에 글을 쓰는 동안, 대화상자나 메뉴가 열려 있을 때, Ctrl·Alt·⌘를 누른 채일 때, 한글을 조합하는 중에는 동작하지 않습니다. 그래서 검색창에 `gp`를 입력해도 화면이 바뀌지 않습니다.
- 단축키가 거슬리면 **내 계정** › **화면**의 **키보드 단축키**를 끕니다([10.3](#103-화면-설정)). 꺼도 `?` 목록은 도움말 메뉴에서 볼 수 있습니다.
- 헤더 검색창은 화면 폭이 768px 이상일 때만 보여 `/`·`s`도 그때만 동작합니다.

## 13. 자주 묻는 질문

**로그인과 계정**

| 질문 | 답 |
| --- | --- |
| **이메일 또는 비밀번호가 올바르지 않습니다.**가 나와요. | 이메일과 비밀번호를 다시 확인하세요. 비밀번호를 모르면 **비밀번호를 잊으셨나요?**로 재설정합니다([2.3](#23-비밀번호를-잊었을-때)). |
| **잠긴 계정입니다.**가 나와요. | 로그인을 여러 번 틀렸거나 관리자가 계정을 잠근 경우입니다. 여러 번 틀려서 잠겼다면 잠금 시간(기본 15분)이 지나기를 기다리거나, **비밀번호를 잊으셨나요?**로 새 비밀번호를 정하면(정하는 즉시 풀림) 됩니다. 급하면 관리자에게 잠금 해제를 요청하세요. 관리자가 잠근 계정은 관리자만 풀 수 있습니다. |
| 회사 계정으로만 로그인하는데, 비밀번호로도 로그인하고 싶어요. | **내 계정** › **비밀번호** › **비밀번호 만들기 링크 받기**를 누르고, 메일로 받은 링크에서 비밀번호를 정하세요([10.2](#102-비밀번호-바꾸기)). |
| 내 계정에 **비밀번호 변경**이 없고 **비밀번호 만들기 링크 받기**만 있어요. | 회사 계정(SSO)으로 만들어져 아직 비밀번호가 없는 계정입니다. 비밀번호가 필요 없으면 그대로 두어도 됩니다. |
| 회사 계정으로 로그인했는데 **openPMS 계정이 없습니다.**가 나와요. | 관리자에게 초대를 요청하세요. 초대를 받은 뒤 다시 SSO로 로그인하면 연결됩니다. |
| **로그인을 취소했거나 공급자가 허용하지 않았습니다.**가 나와요. | 회사 계정 화면에서 취소했거나 접근이 거부된 경우입니다. 다시 시도하고, 계속되면 관리자에게 문의하세요. |
| **로그인 공급자가 이메일 주소를 확인되지 않은 주소로 알려 왔습니다.**가 나와요. | 회사 계정 시스템에서 내 이메일이 인증되지 않은 상태입니다. 회사 계정 설정을 확인하세요. |
| **지금은 이 방법으로 로그인할 수 없습니다.**가 나와요. | 관리자가 해당 SSO를 껐거나 일시적인 문제입니다. 이메일·비밀번호로 로그인하거나 관리자에게 문의하세요. |
| 재설정·초대 메일의 링크가 열리지 않아요(**쓸 수 없는 링크입니다**). | 링크는 한 번만 쓸 수 있고 시간이 지나면 만료됩니다. 재설정은 **새 링크 받기**로, 초대는 관리자에게 다시 요청하세요. |
| 공용 PC에서 로그아웃을 잊었어요. | 다른 기기에서 **내 계정** › **다른 기기에서 모두 로그아웃**을 누르세요([10.4](#104-다른-기기에서-로그아웃하기)). |

**작업**

| 질문 | 답 |
| --- | --- |
| **만들기** 버튼이 없어요. | 작업을 만들 권한이 없거나 전역 **작업** 목록에 있는 경우입니다. 프로젝트 안의 **작업** 화면으로 가세요. 권한이 필요하면 프로젝트 관리자에게 요청하세요. |
| 저장하는 순간 인터넷이 끊겼어요. 작업이 두 번 생겼을까요? | 생기지 않습니다. 만들기·코멘트·복사 요청은 연결이 끊기면 화면이 한 번 다시 보내고, 서버는 같은 요청을 한 번만 처리합니다. 목록을 새로 고쳐 작업이 있는지만 확인하세요([5.1](#51-작업-만들기)). |
| 원하는 상태가 목록에 없어요. | 내 역할로 허용된 상태만 보입니다. 프로젝트 관리자나 시스템 관리자에게 워크플로 변경을 요청하세요. |
| 상태 말고는 아무것도 고칠 수 없어요. | 읽기 전용 상태(예: 완료 처리된 상태)입니다. 고치려면 먼저 상태를 바꾸세요. |
| 날짜를 고칠 수 없어요. | 자동 일정인 상위 작업은 날짜가 하위 작업에서 정해집니다(**날짜는 하위 작업에서 정해집니다**). 하위 작업의 날짜를 바꾸거나 일정 방식을 **수동**으로 바꾸세요. 수정 권한이 없을 수도 있습니다. |
| 완료 %를 입력할 수 없어요. | 진행률을 상태 기준으로 계산하도록 설정된 경우입니다(**완료 %는 상태를 따릅니다.**). |
| **다른 사람이 먼저 수정했습니다**가 나와요. | 그사이 다른 사람이 같은 작업을 고쳤습니다. 화면이 최신 내용으로 바뀌었으니 확인한 뒤 다시 고치세요. |
| 남은 작업을 입력하니 오류가 나요. | 남은 작업은 작업량보다 클 수 없고, 0 이상이어야 합니다. |
| 담당자로 고를 사람이 없어요. | 프로젝트 멤버만 담당자가 될 수 있습니다. 프로젝트 관리자에게 멤버 추가를 요청하세요. |
| 파일이 올라가지 않아요. | 파일 하나는 25MB까지입니다. 빈 파일도 올릴 수 없습니다. 첨부 권한이 없으면 파일 영역이 보이지 않습니다. |
| 다른 프로젝트로 옮긴 작업의 번호가 바뀌나요? | 아니요. 번호는 그대로이고, 예전 주소를 열어도 새 위치로 이동합니다. |
| 삭제한 작업을 되살릴 수 있나요? | 아니요. 삭제는 되돌릴 수 없습니다. 남겨 둘 작업은 상태를 바꾸는 방식으로 정리하세요. |

| 보기를 공개로 저장할 수 없어요. | **프로젝트 멤버 모두에게 공개**는 공개 보기 관리 권한이 있을 때만 보입니다. |

| Gantt에 막대가 안 보이는 작업이 있어요. | 시작일과 완료일이 모두 있어야 막대가 보입니다. 그 행을 시작일부터 완료일까지 끌어 막대를 그리면 날짜가 정해집니다([7.1](#71-gantt)). |

**공수(시간 기록)**

| 질문 | 답 |
| --- | --- |
| 내 공수에서 왜 칸이 회색인가요? | 두 가지 경우입니다. ① 그날 그 작업의 기록이 여러 건(예: 회의와 개발로 나눠 두 번 기록)이면 입력표에서는 고칠 수 없습니다. 칸에 마우스를 올리면 **n건으로 기록된 칸입니다. 작업의 시간 탭에서 고치세요.**가 보입니다. 행의 **#번호**를 눌러 작업을 열고 **시간** 탭에서 한 건씩 고치세요([15.2](#152-작업에-시간-기록하기시간-탭)). ② 그 작업에 더는 기록할 수 없게 된 경우입니다(**이 작업에는 더 기록할 수 없습니다(권한이나 모듈이 바뀜).**). 프로젝트에서 **시간 기록** 모듈이 꺼졌거나 내 역할이 바뀌었으니 프로젝트 관리자에게 문의하세요. 이미 저장된 값은 그대로 남아 있습니다. |
| 하루에 24시간 넘게 입력하면 어떻게 되나요? | 저장되지 않습니다. 한 사람이 하루에 기록할 수 있는 시간은 모든 작업·모든 프로젝트를 합쳐 24시간까지입니다. 넘으면 그날 합계에 **하루에 24시간을 넘게 기록할 수 없습니다.**가 붙고 **저장하지 않았습니다.**와 함께 그 주의 변경이 모두 저장되지 않습니다. 그 날의 칸을 줄이고 다시 저장하세요. 하루 근무 시간(기본 8시간)을 넘는 것은 빨간 합계로 알려 줄 뿐이고 그대로 저장됩니다. |
| 1시간 30분은 어떻게 입력하나요? | `1:30`이나 `1.5`로 입력합니다. `1,5`도 됩니다. 저장하면 `1.5`로 보입니다. 45분은 `0:45`(0.75), 15분은 `0:15`(0.25)입니다. 시간은 소수 둘째 자리까지 저장되므로 `0:20`처럼 나누어떨어지지 않는 값은 0.33으로 저장됩니다. |
| 합계 숫자가 빨간색이고 경고 표시가 있어요. | 그날 합계가 하루 근무 시간(시스템 관리자가 정한 값, 기본 8시간)을 넘었다는 뜻입니다. 실제로 오래 일했다면 그대로 저장해도 됩니다. 잘못 입력했는지 확인하는 용도입니다. |
| **저장하지 않았습니다.**가 나왔어요. | 칸 하나라도 저장할 수 없으면 그 주 전체가 저장되지 않습니다. 빨간 테두리 칸에 마우스를 올리거나 표 아래 빨간 목록에서 사유(권한 없음, 여러 건으로 기록된 칸, 하루 24시간 초과 등)를 보고 고친 뒤 다시 저장하세요. 입력한 값은 화면에 그대로 남아 있습니다. |
| **저장** 버튼이 눌리지 않아요. | 빨간 테두리 칸(숫자가 아니거나 0–24를 벗어난 값)이 있습니다. 고치거나 **되돌리기**를 누르세요. 바뀐 칸이 하나도 없으면 저장 바 자체가 보이지 않습니다. |
| Ctrl+S를 눌렀더니 브라우저의 '페이지 저장'이 떠요. | 커서가 표의 칸 안에 있을 때만 공수 저장으로 동작합니다. 칸을 한 번 누른 뒤 Ctrl+S를 누르거나 **저장** 버튼을 쓰세요. |
| 내 공수에 작업이 하나도 없어요. | 이번 주에 아직 기록이 없어서입니다. **내게 할당된 작업 불러오기**나 **번호나 제목으로 찾기**로 행을 추가하세요. 추가한 행은 시간을 넣고 저장해야 다음에도 보입니다. |
| 지난주 공수를 고치고 싶어요. | **내 공수** 위쪽 ‹ 버튼(지난주)으로 그 주로 가서 고치고 저장합니다. 주소 끝에 `?week=2026-10-05`처럼 날짜를 붙여도 됩니다. 마감·승인 기능은 없어 지난 기록도 고칠 수 있으니 회사의 마감 규칙을 따르세요. |
| 작업에 **시간** 탭이, 프로젝트에 **공수 보고서** 메뉴가 없어요. | 프로젝트에서 **시간 기록** 모듈이 꺼져 있거나 내 역할에 시간 기록 권한이 없습니다(참관자는 기본으로 없음). **공수 보고서**는 '시간 기록 보기' 권한이 있어야 보입니다. 프로젝트 관리자에게 문의하세요. |
| 팀원의 공수를 대신 입력할 수 있나요? | 화면에서는 안 됩니다. 각자 **내 공수**에서 입력합니다. 프로젝트 관리자는 작업의 **시간** 탭에서 팀원의 기록을 고치거나 지울 수 있고, 팀원별 합계는 **공수 보고서**의 **사람별**로 봅니다. |
| 입력표로 넣은 기록의 활동을 바꾸거나 메모를 남기고 싶어요. | 입력표가 만든 기록은 기본 활동(처음에는 **개발**)에 메모가 없습니다. 작업의 **시간** 탭에서 연필 버튼(**고치기**)으로 바꾸세요. |
| 공수 보고서를 Excel로 받았는데 CSV 파일이에요. | 데모(가짜 데이터) 모드로 띄운 화면에서만 그렇습니다. 회사 서버에서는 `공수 {시작}~{끝}.xlsx`로 내려받습니다. |

| 화면이 어두워졌어요/밝아졌어요. | **내 계정** › **테마**가 **시스템 설정**이면 운영체제 설정을 따릅니다. **라이트**, **다크**, **고대비** 중 하나로 고정할 수 있습니다. |
| 글자와 테두리를 더 진하게 보고 싶어요. | **내 계정** › **테마**에서 **고대비**를 고르세요. 운영체제가 다크 모드여도 밝은 고대비로 보입니다. |
| 키를 눌렀더니 화면이 바뀌었어요. | 키보드 단축키(예: `g` 다음 `p`는 프로젝트 목록)입니다. `?`로 목록을 보거나 **내 계정** › **키보드 단축키**를 끄세요([12.1](#121-화면-전체-단축키)). |
| 단축키가 동작하지 않아요. | 입력 칸에 커서가 있거나 대화상자·메뉴가 열려 있으면 동작하지 않습니다. 빈 곳을 한 번 누른 뒤 다시 눌러 보세요. **내 계정**에서 **키보드 단축키**가 꺼져 있는지도 확인하세요. |

**시스템 관리자에게 오는 요청**

관리 화면 사용법 전체는 10 운영자 매뉴얼에 있습니다. 여기에는 사용자의 로그인 문의와 권한 요청(프로젝트 만들기 등)에 바로 이어지는 것만 적습니다.

| 질문 | 답 |
| --- | --- |
| 사용자 목록(**관리** › **사용자**)에 **일시 잠김**이 보여요. 무슨 뜻인가요? | 그 사람이 로그인을 정해진 횟수(관리 › 로그인·비밀번호의 **잠그기 전 실패 횟수**, 기본 5회) 이상 틀려 **잠금 시간**(기본 15분) 동안 자동으로 잠긴 상태입니다. 배지 아래 **로그인 실패가 많아 {{시각}}까지**에 잠김이 끝나는 시각이 나옵니다. 관리자가 직접 잠근 **잠김**과 달리 계정 상태는 **활성** 그대로이며, 그 시각이 지나면 저절로 풀립니다. |
| 일시 잠긴 사람을 바로 풀어 주고 싶어요. | 사용자 목록 위 **잠김** 필터를 누르면 관리자가 잠근 계정과 일시 잠긴 계정이 함께 나옵니다. 그 사람 행의 ⋯ › **잠금 해제**를 누르면 **{{이름}}님의 잠금을 풀었습니다**가 나오고 바로 로그인할 수 있습니다. 본인이 틀린 것이 아니라면(다른 사람이 계정을 시도한 흔적일 수 있음) 비밀번호를 바꾸도록 안내하세요. |
| 회사 계정으로만 로그인하는 사람이 비밀번호를 원해요. | 관리자가 할 일은 없습니다. 본인이 **내 계정**에서 **비밀번호 만들기 링크 받기**를 누르면 본인 메일로 링크가 갑니다([10.2](#102-비밀번호-바꾸기)). |
| 어떤 사람이 프로젝트를 만들 수 있게 해 달래요(전역 역할 주기). | 프로젝트 만들기·사용자 관리처럼 프로젝트와 상관없는 권한은 전역 역할로 줍니다. ① **관리** › **사용자**에서 그 사람 행의 ⋯ › **전역 역할**을 누릅니다. ② **{{이름}}님의 전역 역할** 대화상자에서 줄 역할(예: **프로젝트 생성자**)을 체크하고 **저장**을 누릅니다(**저장했습니다**). ③ 사용자 표의 **전역 역할** 열에 역할이 보이고, 그 사람은 바로 **프로젝트 만들기**를 쓸 수 있습니다. 거두려면 같은 대화상자에서 체크를 풀고 저장합니다. 권한도 바로 사라집니다. |
| 전역 역할 대화상자에 고를 역할이 없어요. | 전역 역할을 아직 만들지 않은 경우입니다(**아직 전역 역할이 없습니다. …**). **관리** › **역할 및 권한** › **역할 추가**에서 범위를 **전역 역할**로 정해 만들고 권한(예: 프로젝트 만들기)을 고르세요. 자세한 절차는 10 운영자 매뉴얼에 있습니다. |
| 모든 역할의 권한을 한눈에 보고 고치고 싶어요. | **관리** › **역할 및 권한** › **권한 보고서**에서 역할 × 권한 표의 칸을 바꾸고 **역할 n개 저장**을 누릅니다. 바꾼 역할만 저장되고 바로 적용됩니다. 자세한 절차는 10 운영자 매뉴얼에 있습니다. |
| 연동 담당자가 웹훅을 등록해 달래요. | **관리** › **API와 웹훅** › **웹훅 추가**에서 이름·받는 주소·보낼 이벤트·프로젝트를 정해 저장하고, 한 번만 보이는 **서명 키**를 담당자에게 안전하게 전달합니다. **테스트 전송**과 **최근 전송 기록**으로 확인합니다. 자세한 절차는 10 운영자 매뉴얼에, 받는 쪽의 서명 확인은 [14.4](#144-사내-연동-개발자를-위한-안내api-토큰웹훅-서명-확인)에 있습니다. |
| 시간 기록 활동(예: 고객 지원)을 추가해 달래요. | **관리** › **달력과 날짜** 아래 **시간 기록 활동**에서 **활동 이름**을 넣고 **활동 추가**를 누릅니다. 쓰지 않을 활동은 **끄기**(지난 기록에는 남음), 내 공수 입력표가 쓰는 기본 활동은 **기본으로**로 바꿉니다([15.4](#154-시간-기록-활동시스템-관리자)). 자세한 절차는 10 운영자 매뉴얼에 있습니다. |
| 사용자 관리 권한이 있는데 **전역 역할** 메뉴가 없어요. | 전역 역할은 회사 전체에 걸친 권한이라 시스템 관리자만 줄 수 있습니다. 사용자 관리 권한만 있으면 **전역 역할** 열은 보이지만 바꿀 수 없습니다. |

### 14.1 기본 역할별로 할 수 있는 일

개발용 예시 데이터에 들어 있는 기본 역할 기준입니다. 운영 환경의 역할과 권한은 시스템 관리자가 정하므로 다를 수 있습니다(**확인 필요**).

- 프로젝트 만들기, 사용자·그룹 관리는 프로젝트 역할이 아니라 시스템 관리자가 전역 역할로 주는 전역 권한입니다(관리 › 사용자 › ⋯ › **전역 역할**, [13장](#13-자주-묻는-질문)).
- 템플릿으로 쓰기, 상위 프로젝트 바꾸기, 개요 위젯 편집, 내부 코멘트 켜기는 프로젝트 정보·상태 수정 권한(프로젝트 관리자)으로 합니다. 상위 프로젝트로 고를 프로젝트에도 같은 권한이 있어야 합니다. 프로젝트 복사에는 프로젝트 만들기 권한(전역 역할)도 필요합니다.
- API 토큰은 누구나 자기 계정에서 만들 수 있고, 토큰은 만든 사람의 역할만큼만 동작합니다.
- (1.6) 시간 기록 권한은 프로젝트에서 **시간 기록** 모듈이 켜져 있을 때만 쓰입니다. 시간 기록 활동은 시스템 관리자가 정합니다.

### 14.4 사내 연동 개발자를 위한 안내(API 토큰·웹훅 서명 확인)

사내 시스템에서 openPMS를 부르거나 openPMS의 알림(웹훅)을 받는 프로그램을 만드는 사람을 위한 요약입니다. 화면의 **도움말** › **API 문서**와 `/api/v1/openapi.json`(OpenAPI 3.1)에 같은 규칙과 주요 경로가 있습니다.

**API 부르기**

1. 연동에 쓸 계정(사람 계정 또는 연동 전용으로 만든 계정)으로 로그인해 [10.5](#105-api-토큰)대로 토큰을 만듭니다. 읽기만 하면 **읽기 전용**을 고릅니다.
2. 모든 요청에 `Authorization: Bearer <토큰>` 헤더를 붙입니다. 세션 쿠키와 CSRF 토큰은 필요 없습니다.

   ```
   curl -H "Authorization: Bearer opms_…" https://<openPMS 주소>/api/v1/work-packages/12
   ```

3. 작업을 고칠 때는 조회 응답의 `lockVersion`을 그대로 함께 보냅니다(`PATCH /api/v1/work-packages/{번호}`). 그사이 다른 사람이 고쳤으면 409와 최신 값이 오니 다시 읽고 고칩니다.
4. 무엇을 만드는 POST(작업·코멘트·프로젝트 만들기, 복사 등)에는 `Idempotency-Key` 헤더를 붙입니다. 아래 **같은 요청을 두 번 처리하지 않게 하기**를 보세요.

**같은 요청을 두 번 처리하지 않게 하기(`Idempotency-Key`)**

응답을 받기 전에 연결이 끊기면 요청이 처리됐는지 알 수 없습니다. 그대로 다시 보내면 작업이 두 개 생길 수 있으니, 요청마다 키를 붙여 두고 다시 보낼 때는 **같은 키**를 씁니다.

```
curl -X POST -H "Authorization: Bearer opms_…" -H "Content-Type: application/json"      -H "Idempotency-Key: 6f1c2a0e-3b7d-4c55-9a7e-1d2f3a4b5c6d"      -d '{"subject":"배포 점검","typeId":"…"}'      https://<openPMS 주소>/api/v1/projects/web-platform/work-packages
```

- 키는 요청마다 새로 만듭니다(UUID 권장, 1–255자). 키는 사람(토큰 주인)마다 따로 관리되므로 다른 계정의 키와 겹쳐도 상관없습니다.
- 같은 키·같은 내용으로 다시 보내면 openPMS는 일을 다시 하지 않고 처음 성공 응답(상태 코드와 본문)을 그대로 돌려주며, 응답 헤더에 `Idempotent-Replayed: true`가 붙습니다. 이 응답의 번호로 이어서 처리하면 됩니다.
- 처음 성공 응답은 24시간 보관합니다. 다시 보내기는 그 안에 끝내세요. 24시간이 지난 키는 새 요청으로 처리됩니다.
- 같은 키로 **다른 내용**(주소나 본문이 다름)을 보내면 422 **같은 Idempotency-Key를 다른 요청에 썼습니다. 요청마다 새 키를 쓰세요.**입니다.
- 처음 요청이 아직 처리 중일 때 같은 키가 오면 409 **같은 요청을 아직 처리하고 있습니다. 잠시 뒤 다시 시도하세요.**입니다. 몇 초 기다렸다가 같은 키로 다시 보냅니다.
- 실패한 요청(4xx·5xx)은 보관하지 않습니다. 입력을 고쳐 다시 보낼 때는 같은 키를 써도 되고 새 키를 써도 됩니다.
- 파일 올리기(`multipart/form-data`)와 응답이 1MB를 넘는 요청에는 적용되지 않습니다. 이런 요청은 다시 보내기 전에 조회로 처리 여부를 확인하세요.
- GET·PATCH·DELETE에는 붙이지 않아도 됩니다(키를 보지 않음). PATCH는 `lockVersion`이 같은 변경이 두 번 적용되는 것을 막습니다(두 번째는 409).

| 응답 | 뜻과 대처 |
| --- | --- |
| 401 | 토큰이 없거나 틀렸거나 만료·폐기됨, 또는 관리자가 토큰 사용을 끔. 새 토큰을 받거나 관리자에게 확인 |
| 403 | 그 사람의 권한 밖이거나, 읽기 전용 토큰으로 바꾸는 요청(**읽기 전용 토큰입니다.**), 또는 토큰으로 막힌 경로(로그인·비밀번호·토큰 관리·연동 설정: **API 토큰으로는 로그인·비밀번호·토큰·연동 설정을 다룰 수 없습니다.**) |
| 404 | 없거나 볼 수 없는 것(볼 권한이 없어도 404) |
| 409 | 동시 수정이면 다시 읽고 고침. `Idempotency-Key`를 붙인 요청이면 같은 키의 처음 요청이 아직 처리 중: 잠시 뒤 같은 키로 다시 |
| 422 | 입력 오류. 본문 `errors[{field, message}]` 확인. `Idempotency-Key`를 다른 요청에 다시 썼거나 키가 255자를 넘어도 422 |
| 429 | 토큰마다 분당 300회를 넘음. 잠시 기다렸다가 다시 |

- 오류 본문은 `application/problem+json`(title, detail, errors)입니다.
- 경로는 `/api/v1` 아래입니다. v1 안에서는 응답에 필드가 더해질 수만 있으니, 모르는 필드는 무시하도록 만드세요. 필드를 빼거나 뜻을 바꾸는 변경은 `/api/v2`로 나옵니다.
- 토큰은 프로그램 코드나 저장소에 넣지 말고 비밀값 저장소에 둡니다. 만료일 전에 새 토큰으로 바꿔 끼우세요.

**웹훅 받기와 서명 확인**

웹훅은 시스템 관리자가 **관리** › **API와 웹훅**에서 받는 주소를 등록합니다. 등록할 때 한 번만 보이는 **서명 키**(`whsec_…`)를 관리자에게서 안전하게 받아 두세요.

openPMS는 작업이 생기거나(`work_package.created`, 프로젝트 복사·템플릿으로 만든 작업도 하나씩), 바뀌거나(`work_package.updated`, 다른 프로젝트로 옮긴 경우, 선행 작업 때문에 자동 일정으로 날짜가 밀린 작업, 첨부 파일을 올리거나 지운 경우 포함), 지워지거나(`work_package.deleted`), 코멘트가 달리면(`work_package.commented`) 받는 주소로 다음 요청을 보냅니다. 관리자의 **테스트 전송**은 `ping`입니다.

| 항목 | 값 |
| --- | --- |
| 메서드·본문 | `POST`, `Content-Type: application/json` |
| `X-OpenPMS-Event` | 이벤트 이름(예: `work_package.updated`, `ping`) |
| `X-OpenPMS-Delivery` | 전송 ID. 다시 보낼 때도 같은 ID |
| `X-OpenPMS-Signature` | `sha256=` + 본문을 서명 키로 HMAC-SHA256 한 값(16진수 소문자) |
| 본문 | `event`, `occurredAt`(UTC), `actor`(한 사람), `workPackage`(번호·제목·주소·프로젝트·유형·상태·우선순위·담당자·시작일·완료일·완료 %), 변경이면 `changes`[{field, label, from, to}](그 요청에서 바뀐 항목만. 첨부는 label **첨부 파일**), 코멘트면 `comment` |

받는 쪽은 이렇게 확인합니다.

1. 요청 본문을 **받은 그대로의 바이트**로 읽습니다. JSON으로 바꿨다가 다시 문자열로 만들면 공백·순서가 달라져 서명이 맞지 않습니다.
2. 서명 키(문자열 전체, `whsec_` 포함)를 키로 본문의 HMAC-SHA256을 구해 16진수로 바꾸고 앞에 `sha256=`를 붙입니다.
3. `X-OpenPMS-Signature` 값과 **상수 시간 비교**로 같은지 봅니다. 다르면 401 등으로 거절하고 처리하지 않습니다.
4. 같으면 10초 안에 2xx로 답하고, 오래 걸리는 처리는 뒤에서 합니다.

   ```python
   import hmac, hashlib

   def verify(raw_body: bytes, header: str, secret: str) -> bool:
       expected = "sha256=" + hmac.new(secret.encode("utf-8"), raw_body, hashlib.sha256).hexdigest()
       return hmac.compare_digest(expected, header or "")
   ```

   ```javascript
   // Node.js: express.raw({ type: "application/json" })로 받은 원문 Buffer
   const crypto = require("crypto");
   function verify(rawBody, header, secret) {
     const expected = "sha256=" + crypto.createHmac("sha256", secret).update(rawBody).digest("hex");
     return header && header.length === expected.length && crypto.timingSafeEqual(Buffer.from(header), Buffer.from(expected));
   }
   ```

- 2xx가 아니거나 10초 안에 답하지 않으면 1분·5분·30분·120분 뒤 다시 보내고, 그래도 안 되면 **실패**로 남깁니다. 같은 전송이 두 번 올 수 있으니 `X-OpenPMS-Delivery`로 이미 처리한 것은 건너뛰세요.
- 리다이렉트(3xx)는 따라가지 않습니다. 받는 주소는 최종 주소로 등록합니다.
- 내부 코멘트는 보내지 않습니다. 자동 일정으로 한 번에 여러 작업의 날짜가 밀리면 작업마다 `work_package.updated`가 하나씩 갑니다.
- 받는 주소가 사내망(10.x, 172.16–31.x, 192.168.x 등)이나 루프백인데 등록이 **사내망·루프백 주소로는 보낼 수 없습니다(운영 설정에서 막혀 있음).**로 거절되면, 운영자가 사내망 주소로 보내는 것을 막아 둔 것입니다(`OPENPMS_WEBHOOK_BLOCK_PRIVATE`). 시스템 관리자와 받는 주소를 정하세요. 169.254.x 같은 링크 로컬 주소는 늘 거절됩니다.
- 서명 키가 새어 나갔다고 의심되면 관리자에게 **서명 키 새로 만들기**를 요청하고 새 키로 바꿉니다. 그 순간부터 예전 키의 서명은 맞지 않습니다.

## 15. 공수 기록하기

작업에 쓴 시간(공수)을 기록하고 모아 보는 기능입니다(1.6). 매일 또는 한 주를 마칠 때 **내 공수** 한 화면에서 그 주를 키보드로 채우는 것이 기본이고, 활동과 메모까지 남기려면 작업의 **시간** 탭을 씁니다. 팀장·프로젝트 관리자는 프로젝트의 **공수 보고서**로 모아 보고 Excel로 내려받아 보고에 씁니다.

- 프로젝트에서 **시간 기록** 모듈이 켜져 있어야 합니다(새 프로젝트는 기본으로 켜짐, [11.4](#114-모듈-켜기끄기)).
- 내 역할에 시간 기록 권한이 있어야 합니다. 기본 역할은 프로젝트 관리자·멤버가 기록하고 볼 수 있고, 참관자는 할 수 없습니다([14.1](#141-기본-역할별로-할-수-있는-일)).
- 비용·단가·예산 기능은 없습니다. 시간만 기록합니다.

### 15.1 내 공수 입력하기(주간 입력표)

1. 왼쪽 메뉴(프로젝트 밖)에서 **내 공수**를 누릅니다. 이번 주 표가 열립니다. 행은 이번 주에 이미 시간을 기록한 작업, 열은 한 주 7일(시스템 관리자가 정한 주 시작 요일부터)입니다.
2. 표에 없는 작업은 표 아래에서 추가합니다.
   - **번호나 제목으로 찾기**에 번호(예: `12`)나 제목 일부를 입력하고 후보를 누릅니다. Enter를 누르면 첫 후보가 들어갑니다.
   - **내게 할당된 작업 불러오기**를 누르면 내게 할당된 열린 작업이 한꺼번에 행으로 들어옵니다.
3. 칸을 하나 누르고 키보드로 채웁니다. 칸에 들어가면 값이 선택되어 바로 덮어쓸 수 있습니다.
   - 숫자로 입력합니다: `2`, `1.5`, `1,5`, 또는 시:분 `1:30`(1.5시간), `0:45`(0.75시간).
   - →는 다음 날 칸, ←는 앞 날 칸으로 갑니다(칸 안 글자의 맨 끝·맨 앞에서). ↓ 또는 Enter는 아래 작업, ↑는 위 작업의 같은 날 칸입니다.
   - 칸을 비우거나 `0`을 넣으면 그날 그 작업의 기록이 지워집니다.
4. 표 맨 아래 **합계** 줄을 확인합니다. 하루 합계가 하루 근무 시간(기본 8시간)을 넘으면 빨간 글씨와 경고 아이콘이 붙습니다(화면 낭독기는 **하루 근무 시간(8시간)을 넘었습니다**로 읽음). 경고일 뿐 저장은 됩니다.
5. Ctrl+S(Mac은 ⌘+S)를 누르거나 화면 아래 **저장**을 누릅니다. **이번 주 공수를 저장했습니다**가 나오면 끝입니다.
   - 바뀐 칸에는 파란 테두리가 생기고, 화면 아래에 **저장하지 않은 변경이 있습니다**와 **되돌리기**·**저장**이 붙어 있습니다.
   - 숫자가 아니거나 0–24를 벗어난 칸은 빨간 테두리가 되고, 고치기 전에는 **저장**이 눌리지 않습니다.
   - 입력을 모두 버리려면 **되돌리기**를 누릅니다.
6. 다른 주는 위쪽 ‹(지난주)·›(다음 주)로 옮기고, **이번 주**로 돌아옵니다. 주소 끝에 `?week=2026-10-05`처럼 날짜를 붙이면 그 날이 든 주가 바로 열립니다.

![내 공수: 바뀐 칸(파란 테두리)과 하루 근무 시간을 넘은 날(빨간 합계와 경고 아이콘)](../../replica/clone-screens/X10-timesheet.png)

- **한 주는 한 번에 저장됩니다.** 칸 하나라도 저장할 수 없으면 **저장하지 않았습니다.** / **n칸에서 문제가 있어 이 주의 변경을 모두 되돌렸습니다.**가 나오고 아무것도 저장되지 않습니다. 빨간 테두리 칸에 마우스를 올리거나 표 아래 빨간 목록에서 사유를 보고 고친 뒤 다시 저장하세요. 입력한 값은 화면에 남아 있습니다.
- 한 사람이 하루에 기록할 수 있는 시간은 모든 작업을 합쳐 24시간까지입니다. 넘으면 저장되지 않습니다.
- 회색 칸은 고칠 수 없는 칸입니다. 그날 기록이 여러 건이면 작업의 **시간** 탭에서 고치고([15.2](#152-작업에-시간-기록하기시간-탭)), 모듈이 꺼졌거나 권한이 바뀐 작업이면 프로젝트 관리자에게 문의하세요. 칸에 마우스를 올리면 사유가 보입니다.
- 입력표로 만든 기록의 활동은 기본 활동(처음에는 **개발**)이고 메모는 비어 있습니다. 활동·메모를 바꾸려면 작업의 **시간** 탭을 씁니다.
- 날짜 머리글의 빨간 작은 글씨는 휴무일 이름(예: 한글날)이고, 회색 바탕 열은 근무일이 아닌 날입니다. 이런 날에도 기록할 수 있습니다.
- 추가만 하고 시간을 넣지 않은 행은 저장되지 않아 다음에 열면 없습니다.
- 저장하지 않은 채 다른 주로 가거나 화면을 떠나려 하면 **저장하지 않은 공수가 있습니다. 이 페이지를 떠날까요?**라고 묻습니다.
- 행의 **#번호**를 누르면 그 작업이 열립니다. 내 공수에는 내 시간만 나옵니다.

### 15.2 작업에 시간 기록하기(시간 탭)

1. 작업을 엽니다(목록에서 골라 오른쪽 상세, 또는 전체 화면).
2. 탭 **시간**을 누릅니다. 위쪽 **모두 N시간**은 이 작업에 기록된 시간의 합이고, 아래에 기록이 최근 날짜부터 보입니다(날짜, 사람, 활동, 메모, 시간).
3. **시간 기록**을 누릅니다.
4. 대화상자에서 **날짜**(기본 오늘), **시간**(`1.5` 또는 `1:30`), **활동**(기본 활동이 미리 골라져 있음), **메모**(선택)를 넣고 **저장**을 누릅니다. **시간을 기록했습니다**가 나오고 목록과 합계가 바뀝니다.
5. 내 기록을 고치려면 그 줄의 연필 버튼(**고치기**), 지우려면 휴지통 버튼(**지우기**)을 누르고 **이 시간 기록을 지울까요?**에서 확인합니다.

![작업 #3의 시간 탭: 모두 16시간, 날짜·사람·활동·메모·시간과 고치기·지우기](../../replica/clone-screens/S08-time.png)

- 목록에는 내가 볼 수 있는 기록이 나옵니다. 기본 역할의 프로젝트 관리자·멤버는 모든 사람의 기록을 봅니다.
- 고치기·지우기는 내 기록에만 보입니다. 프로젝트 관리자는 다른 사람의 기록도 고치고 지울 수 있습니다.
- 같은 날 같은 작업에 활동을 나눠 여러 건 기록할 수 있습니다(예: 회의 1시간, 개발 3시간). 이런 날은 내 공수에서 회색 칸이 됩니다.
- 작업을 다른 프로젝트로 옮기면 기록도 함께 옮겨집니다. 작업을 복사하면 기록은 복사되지 않고, 작업을 삭제하면 기록도 함께 지워집니다. 삭제 대화상자가 기록된 시간을 경고합니다([5.12](#512-복사와-이동), [5.13](#513-삭제)).
- 시간 기록과 그 수정은 작업의 **활동** 탭에 남지 않습니다.
- **시간** 탭이 없으면 프로젝트의 **시간 기록** 모듈이 꺼져 있거나 내 역할에 시간 기록 권한이 없는 것입니다.

### 15.3 공수 보고서 보기

1. 프로젝트 왼쪽 메뉴에서 **공수 보고서**를 누릅니다.
2. **시작**과 **끝** 날짜를 정합니다. 처음에는 이번 달 1일부터 말일까지입니다. 한 번에 1년까지 볼 수 있고, 끝이 시작보다 빠르면 **끝 날짜가 시작 날짜보다 빠릅니다**, 1년을 넘으면 **한 번에 1년까지만 볼 수 있습니다**가 끝 칸 아래에 나옵니다. 이때는 표가 사라지고 **Excel로 내려받기**도 누를 수 없습니다. 날짜를 고치면 다시 나옵니다.
3. **묶기**에서 **사람별**, **작업별**, **활동별**, **날짜별** 중 하나를 고릅니다.
4. 표에서 묶음마다 시간과 비율(막대와 %)을 보고, 맨 아래 **합계**를 확인합니다. 사람·작업·활동별은 시간이 많은 순, 날짜별은 날짜순입니다.
5. 파일이 필요하면 오른쪽 위 **Excel로 내려받기**를 누릅니다. 같은 기간의 기록이 한 줄씩(날짜, 사람, 프로젝트, 번호, 작업, 활동, 시간, 메모) 들어 있고 맨 아래에 합계가 있습니다. 파일 이름은 `공수 2026-10-01~2026-10-31.xlsx` 같은 모양입니다.

![공수 보고서: 이번 달, 사람별 시간과 비율, 합계](../../replica/clone-screens/X11-time-report.png)

- **공수 보고서** 메뉴는 '시간 기록 보기' 권한이 있을 때 보입니다(기본: 프로젝트 관리자, 멤버).
- 내가 볼 수 있는 기록만 셉니다.
- 보고서는 프로젝트마다 봅니다. 여러 프로젝트를 한꺼번에 묶는 화면은 없습니다.
- 화면의 합계는 기록 건수와 상관없이 기간 안의 기록을 모두 셉니다.
- Excel 파일에는 기록이 5만 줄까지만 들어갑니다. 기간이 길고 기록이 아주 많으면(기간 안 5만 건 이상) 기간을 나눠 내려받으세요.

### 15.4 시간 기록 활동(시스템 관리자)

시간을 기록할 때 고르는 활동은 시스템 관리자가 정합니다. 처음에는 **개발**(기본), **설계**, **회의**, **테스트**, **문서**, **관리**, **기타** 7개가 있습니다.

1. **관리** › **달력과 날짜**를 열고 맨 아래 **시간 기록 활동**으로 갑니다.
2. 활동을 더하려면 **활동 이름**에 이름(60자까지, 같은 이름은 안 됨)을 넣고 **활동 추가**(또는 Enter)를 누릅니다.
3. 기본 활동을 바꾸려면 그 활동 줄의 **기본으로**를 누릅니다. 기본 활동은 내 공수 입력표가 새 기록에 쓰고, **시간 기록** 대화상자에 미리 골라져 있습니다.
4. 더 쓰지 않을 활동은 **끄기**를 누릅니다. 끈 활동은 새 기록에서 고를 수 없고, 지난 기록에는 그대로 남습니다. **켜기**로 되돌립니다. 기본 활동은 끌 수 없으니 다른 활동을 먼저 기본으로 정하세요.

- 활동을 지우거나 이름·순서를 바꾸는 버튼은 없습니다.
- 내 공수의 경고 기준인 하루 근무 시간은 같은 화면 위쪽 **근무 주**의 **하루 근무 시간**입니다. 관리 화면의 자세한 절차는 10 운영자 매뉴얼에 있습니다.

### 15.5 알아 둘 점

- 주 단위 승인이나 마감(잠금)이 없습니다. 지난 기록도 권한만 있으면 고칠 수 있으니, 회사의 마감 규칙(예: 다음 주 월요일까지 입력)을 운영으로 정하세요.
- 팀원의 주를 대신 입력하는 화면은 없습니다.
- 작업 목록에는 기록한 시간 열·필터가 없고, 내 페이지·프로젝트 개요 위젯에도 공수가 나오지 않습니다. 공수는 내 공수, 작업의 시간 탭, 공수 보고서에서 봅니다.
- 시간 기록 권한과 모듈은 프로젝트마다 다릅니다. 한 화면(내 공수)에 여러 프로젝트의 작업이 섞여 있어도 저장은 각 작업 프로젝트의 권한대로 됩니다.
