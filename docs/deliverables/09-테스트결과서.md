- 1.0 이후 넣은 세 기능(목록 그룹화·합계, 보드 보강, 날짜·시간 형식)을 포함해 JUnit·E2E 전체 회귀를 다시 통과했고, 새 케이스 13건(JUnit 7, E2E 6)을 더했습니다.
- 1.0의 배포 조건 1("SSO가 포함된 이미지로 배포 스모크를 다시 함")은 2026-10-11 최신 이미지 재검증(3.4.2: 마이그레이션 V1–V10, 헬스 `UP`, SSO 공개 응답, 브라우저 핵심 흐름)으로 충족되어 조건에서 뺐습니다.
- 접근성 자동 검사를 통과했고(WCAG 2.1 A/AA), 데이터 격리·CSRF·잠금·SSO 위조 방지 같은 보안 관련 동작을 자동 테스트로 확인했습니다.

배포 때 지켜야 할 조건:
1. 사내 SMTP로 초대 메일이 실제로 도착하는지 확인합니다(OI-08).
2. 사내 SSO를 쓸 경우, `replica/deploy.md` "사내 SSO 연결" 순서대로 실제 IdP와 연결을 시험한 뒤 사용자에게 공개합니다(OI-07).
3. 운영 서버에 배포한 뒤에는 운영자 매뉴얼의 설치 절차대로 헬스 `UP`과 로그인을 확인합니다(일반 설치 확인이며, 이미지 검증은 3.4.2로 끝남).
4. 미결 항목(5장)은 출시를 막지 않는 항목으로 보고, 다음 단계에서 처리합니다.
