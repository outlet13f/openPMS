# CI/CD 연동 2단계(빌드·배포 상태) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 작업 패키지의 "개발" 탭에서 연결된 커밋·MR/PR의 **빌드 결과**(GitLab CI, GitHub Actions, Jenkins)와 **어느 환경(개발 → 스테이징 → 운영)까지 배포됐는지**(GitLab·GitHub 환경, Jenkins, Argo CD)를 같은 비중으로 보여 준다. 배포가 담은 커밋 하나에서 코드 저장 도구의 비교 API로 "이 배포로 들어간 커밋·빠진 커밋"을 계산해 환경마다 지금 들어 있는 커밋을 유지한다. 저장소 떼기는 기록을 지우지 않는 방식으로 바뀐다.

**Architecture:** 1단계의 `com.openpms.cicd` 위에 얹는다. 정규화 이벤트 `CicdEvent`에 `pipeline`·`deployment`를 더하고, GitLab·GitHub 어댑터가 새 웹훅·폴링을 읽고 비교 API(`compare`·`contains`)를 제공한다. Jenkins·Argo CD는 새 연동 종류이며 하나의 **표준 알림** 형식(`StandardAdapter`)으로 받는다. 예약 작업 `cicd-process`가 (1) 이벤트를 `cicd_pipelines`·`cicd_deployments`로 옮기고(`CicdBuilds`), (2) 성공한 배포를 환경마다 차례로 반영하며(`CicdDeployments`: `cicd_environment_heads` 행 잠금, 양방향 비교), (3) 첫 배포의 포함 여부를 나눠 확인한다(`CicdFirstDeploy`). 바깥 호출은 모두 트랜잭션 밖이다. 환경 정의는 `CicdEnvironments`, 화면은 개발 탭(환경 줄·빌드 배지)·프로젝트 설정 › 환경·저장소(뗀 저장소·빌드 기록 정리)·관리 › CI/CD 연동(Jenkins·Argo CD, 알림 틀).

**Tech Stack:** Spring Boot 4 / Java 21(가상 스레드) / jOOQ / Flyway / PostgreSQL 17 / db-scheduler, JDK `HttpClient`·`HttpServer`(테스트), React 19 / Vite / TypeScript / TanStack Query / Tailwind v4, JUnit 5 + MockMvc, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-16-cicd-phase2-design.md` (HTML `2026-10-16-cicd-phase2-design.html`). 앞 단계: `docs/superpowers/specs/2026-10-15-cicd-design.md`, `docs/superpowers/plans/2026-10-15-cicd-phase1.md`.

## 설계서 보완 (코드·공개 문서 조사 뒤 정함, Task 1에서 설계서에도 적음)

1. **Argo CD의 서명.** Argo CD Notifications의 웹훅 서비스는 고정 헤더만 보낼 수 있고 본문 HMAC을 만들지 못한다. 그래서 `argocd` 연동은 `X-OpenPMS-Signature`(HMAC) **또는** `X-OpenPMS-Token: <웹훅 비밀>`(상수 시간 비교)을 받는다. `jenkins`는 HMAC만(Jenkinsfile 셸 단계가 `openssl`로 서명). 거절은 그대로 모두 같은 404.
2. **Argo CD 알림 틀은 `sha`를 보내지 않는다.** Argo CD 앱의 `syncResult.revision`은 배포 설정(매니페스트) 저장소의 커밋이지 앱 코드의 커밋이 아니다. 틀은 `image`(앱이 쓰는 이미지)만 보내고 커밋 번호는 이미지 태그 규칙으로 뽑는다.
3. **비교 응답 상한 8 MiB.** GitLab `repository/compare`와 GitHub `compare`는 커밋 목록과 함께 diff·바뀐 파일 목록을 돌려줘 2 MiB를 쉽게 넘는다. 비교·조상 확인 호출만 응답 본문 상한을 8 MiB로 둔다(나머지 1단계 규칙 — 10초 전체 마감, 리다이렉트 안 따름 — 은 그대로). GitLab은 그래도 넘으면 같은 범위를 커밋 목록 API(`repository/commits?ref_name=<base>..<head>`, diff 없음)로 다시 읽는다. GitHub는 넘으면 다시 시도하지 않고 바로 "확인 실패".
4. **조상 확인.** 첫 배포의 "그 커밋이 배포 커밋에 들어 있나"는 GitLab `repository/merge_base`(병합 기준 = 그 커밋이면 포함), GitHub `compare/{그 커밋}...{배포 커밋}`의 `status`가 `ahead`·`identical`이면 포함으로 본다(설계서의 "뒤에 있음·같음").
5. **첫 배포 확인 대상 표 `cicd_first_deploy_checks`.** 설계서의 여섯 표 밖에 하나 더 둔다: 첫 배포가 확인할 연결된 커밋(최대 200개)과 결과(`in`·`out`·`error`). 실행마다 저장소당 50번까지 확인하고, 모두 끝나면 배포가 `first`가 된다. 200개보다 오래된 연결은 배포의 `first_cutoff_at`(확인한 가장 오래된 커밋 시각)으로 "첫 배포 이전"을 판단한다.
6. **MR의 병합 커밋.** MR로만 연결된 작업(브랜치 이름의 `#123`)도 환경 줄이 나오도록 `cicd_merge_requests.merge_commit_sha`(V28)를 더한다(GitLab `squash_commit_sha` → `merge_commit_sha`, GitHub `merge_commit_sha`, 병합된 MR만). 환경 판정에서 "연결된 커밋"은 끊지 않은 커밋 연결 + 연결된 병합 MR의 병합 커밋이다.
7. **빌드 배지는 워크플로마다 최신 하나를 모은다.** GitHub는 한 커밋에 워크플로가 여러 개(빌드·린트·배포) 돈다. 최신 하나만 보이면 실패한 빌드가 나중에 끝난 린트에 가려진다. `cicd_pipelines.name`(GitLab 파이프라인 이름, GitHub 워크플로 이름, Jenkins 작업 이름. 없으면 "")을 두고, 커밋(또는 MR 원본 브랜치)마다 이름별 최신을 모아 하나라도 `failed`면 실패, 아니면 `running`이 있으면 진행 중, 모두 `canceled`면 취소, 그 밖은 성공. 배지 링크는 그 상태를 만든 빌드 중 최신.
8. **다시 시도 간격.** 비교 API 실패는 다음 실행에서 다시 하되 1·2·4·8분 간격(`next_attempt_at`)으로 하고 5번째 실패에 "확인 실패"(도구 서버를 몇 분 재시작해도 모두 실패로 끝나지 않게). 비교에 쓸 토큰이 없거나(웹훅만 쓰는 GitLab·GitHub 연동) 연동이 꺼졌으면 바로 "확인 실패". "확인 실패"여도 환경 머리는 그 배포로 옮긴다(다음 배포가 그것과 비교).
9. **Jenkins·Argo CD 저장소 찾기.** 표준 알림의 `repository`를 대소문자 무시로 그 연동의 허용 프로젝트에 붙은(떼지 않은) GitLab·GitHub 저장소의 `full_path`와 맞춘다. 둘 이상 맞으면(같은 경로가 GitLab·GitHub 양쪽에) 버리고 경고 로그(연동 id와 건수만).
10. **환경 맞추기.** 환경 이름도 별칭처럼 맞춘다(대소문자 무시). 숨긴 환경은 새 배포와 맞추지 않는다(미지정이 됨). 별칭은 소문자로 저장하고, 한 프로젝트 안에서 다른 환경의 이름·별칭과 겹치면 422.
11. **기본 환경을 넣는 때.** 모듈 `cicd`를 켜는 순간(프로젝트 수정 `PATCH /projects/{id}`의 `enabledModules`, 템플릿·프로젝트 복사) 그 프로젝트에 환경이 하나도 없을 때만 `개발`·`스테이징`·`운영`을 넣는다. 템플릿의 환경 정의는 복사하지 않는다. V28은 이미 모듈을 쓰는 프로젝트에 넣는데, 새 개발 DB에서는 V28이 V1010(모듈을 켬)보다 먼저 돌므로 V1012가 web-platform·mobile-app에 넣는다.
12. **뗀 저장소의 경계.** 허용 프로젝트에서 빼기는 붙은(떼지 않은) 저장소만 막는다(409). 연동 목록의 저장소 수는 붙은 것만, 연동 삭제 409는 뗀 것까지 센다. 다시 붙이기는 `POST /projects/{p}/cicd/repositories/{id}/reattach`(원격 조회 없음, 토큰이 없는 연동도 됨), 다른 프로젝트로는 찾기 → 붙이기가 같은 행을 옮긴다. 저장소 찾기 결과의 `attachedProject`는 붙은 것만 표시. 손 연결은 뗀 저장소의 MR을 받지 않는다.
13. **이미지 태그 규칙.** Java 정규식, 200자까지, 태그(마지막 `/` 뒤의 `:` 뒤, `@digest` 앞) 128자까지, 첫 묶음(없으면 일치 전체), 결과가 16진수 7–40자리이고 숫자만이 아닐 때만 커밋 번호(날짜·빌드 번호 태그 `20261015` 제외). 검사 단계 상한(문자 읽기 20만 번)을 넘으면 "커밋 모름". 화면의 "시험"은 서버 `POST /api/v1/admin/cicd/image-tag-test`가 답한다(브라우저 정규식과 결과가 다르지 않게).
14. **표준 알림에 선택 필드 `name`**(빌드 이름, 배지 묶음용)을 더한다. 받을 수 있는 값과 길이는 Task 5.
15. **연동 입력.** Jenkins·Argo CD도 `baseUrl` 칸을 "도구 주소"로 받고 서버가 `tool_url`에 같은 값을 둔다(`base_url`은 not null 그대로). API 토큰을 보내면 422 "Jenkins·Argo CD 연동에는 API 토큰을 쓰지 않습니다.".
16. **빌드 기록 정리.** 기준은 고른 날짜 00:00(Asia/Seoul) 이전, 시각은 `coalesce(finished_at, updated_at)`. 오늘보다 뒤 날짜는 422. 환경 설정과 빌드 기록 정리 경로는 `ApiTokenFilter`에서 API 토큰으로 닫는다(정규식 `^/api/v1/projects/[^/]+/cicd/(environments|pipelines)(/.*)?$`).
17. **배포 시각과 상태.** 늦게 온 옛 배포 판단의 배포 시각은 GitLab `status_changed_at`(폴링은 `updated_at`), GitHub `deployment_status.created_at`, 표준 `at`. GitHub `inactive`(새 배포가 성공하면 GitHub가 옛 배포에 붙이는 상태)는 버린다. `error`는 실패. GitLab `canceled` 배포는 실패로 기록만.
18. **도움말 번호.** 07은 16.5가 마지막 → 새 16.6 빌드·배포 보기, 16.7 환경 설정. 10의 9.18은 9.18.10이 마지막 → 9.18.11 Jenkins 연동, 9.18.12 Argo CD 연동, 9.18.13 저장소 떼기와 빌드 기록 정리. `topics.ts`: 개발 탭은 16.2 그대로(16.2에 16.6을 가리키는 문장), 설정 › 환경 → 16.7, `/admin/cicd`는 9.18 그대로.

```java
package com.openpms.cicd;

import com.openpms.common.ApiException;
import java.util.Locale;
import java.util.Optional;
import java.util.regex.Pattern;
import java.util.regex.PatternSyntaxException;

/**
 * The commit number in a container image's tag ("web/portal:1a2b3c4"), by a connection's own pattern (Jenkins, Argo CD).
 * The tag is what follows the last ':' after the last '/', before any "@digest", at most 128 characters. The first group of
 * the pattern (or the whole match) must be 7–40 hex digits and not digits only (a date or build number is no commit).
 * A pattern is written by a delegated CI/CD 연동 관리자, so matching gives up after a fixed number of character reads.
 */
final class ImageTags {
    static final String DEFAULT_PATTERN = "[0-9a-f]{7,40}";
    static final int MAX_PATTERN = 200;
    static final int MAX_TAG = 128;
    static final long STEP_BUDGET = 200_000;
    private static final Pattern HEX = Pattern.compile("[0-9a-f]{7,40}");
    private static final Pattern DIGITS = Pattern.compile("[0-9]+");

    private ImageTags() {}

    static String validate(String pattern) {
        if (pattern == null || pattern.isBlank()) return null;
        var p = pattern.strip();
        var bad = ApiException.field("imageTagPattern", "이미지 태그 규칙이 올바르지 않습니다.");
        if (p.length() > MAX_PATTERN || p.chars().anyMatch(c -> c < 0x20)) throw bad;
        try {
            Pattern.compile(p);
        } catch (PatternSyntaxException e) {
            throw bad;
        }
        return p;
    }

    static String tagOf(String image) {
        if (image == null) return "";
        var s = image.strip();
        int at = s.indexOf('@');
        if (at >= 0) s = s.substring(0, at);
        int slash = s.lastIndexOf('/');
        int colon = s.lastIndexOf(':');
        if (colon <= slash) return "";
        var tag = s.substring(colon + 1);
        return tag.isEmpty() || tag.length() > MAX_TAG ? "" : tag;
    }

    static Optional<String> sha(String image, String pattern) {
        var tag = tagOf(image);
        if (tag.isEmpty()) return Optional.empty();
        Pattern p;
        try {
            p = Pattern.compile(pattern == null || pattern.isBlank() ? DEFAULT_PATTERN : pattern, Pattern.CASE_INSENSITIVE);
        } catch (PatternSyntaxException e) {
            return Optional.empty();
        }
        try {
            var m = p.matcher(new Bounded(tag, new long[] {STEP_BUDGET}));
            if (!m.find()) return Optional.empty();
            var g = m.groupCount() >= 1 && m.group(1) != null ? m.group(1) : m.group();
            var found = g.toLowerCase(Locale.ROOT);
            return HEX.matcher(found).matches() && !DIGITS.matcher(found).matches() ? Optional.of(found) : Optional.empty();
        } catch (TooSlow e) {
            return Optional.empty();
        }
    }

    private static final class TooSlow extends RuntimeException {
        TooSlow() { super(null, null, false, false); }
    }

    /** A CharSequence whose reads are counted; past the budget every read throws, which ends a runaway match. */
    private record Bounded(CharSequence text, long[] left) implements CharSequence {
        @Override public int length() { return text.length(); }
        @Override public char charAt(int i) {
            if (--left[0] < 0) throw new TooSlow();
            return text.charAt(i);
        }
        @Override public CharSequence subSequence(int s, int e) { return new Bounded(text.subSequence(s, e), left); }
        @Override public String toString() { return text.toString(); }
    }
}
```

```java
package com.openpms.cicd;

import java.net.URI;

/** Build and deployment links: only an http(s) address on the same origin as the allowed base (no user part); else "". */
final class CicdLinks {
    private CicdLinks() {}

    static String sameOrigin(String url, String base) {
        if (url == null || url.isBlank() || base == null || base.isBlank()) return "";
        try {
            var u = URI.create(url.strip());
            var b = URI.create(base.strip());
            var scheme = u.getScheme() == null ? "" : u.getScheme().toLowerCase();
            if (!(scheme.equals("http") || scheme.equals("https")) || u.getHost() == null || u.getRawUserInfo() != null) return "";
            if (!scheme.equalsIgnoreCase(b.getScheme() == null ? "" : b.getScheme()) || !u.getHost().equalsIgnoreCase(b.getHost() == null ? "" : b.getHost())
                    || port(u) != port(b)) return "";
            return url.strip();
        } catch (IllegalArgumentException e) {
            return "";
        }
    }

    private static int port(URI u) {
        if (u.getPort() != -1) return u.getPort();
        return "http".equalsIgnoreCase(u.getScheme()) ? 80 : 443;
    }
}
```

```java
package com.openpms.cicd;

import java.time.OffsetDateTime;
import java.util.Collection;

/** Order of build and deployment notices, and the one badge for several workflows of one commit or branch. */
final class CicdStates {
    private CicdStates() {}

    /** running comes before an end (success, failed, canceled). */
    static int rank(String status) {
        return "running".equals(status) ? 0 : 1;
    }

    /** Does a notice (newStatus at newAt) replace what is stored? Later wins; at the same instant an end beats running. */
    static boolean replaces(String oldStatus, OffsetDateTime oldAt, String newStatus, OffsetDateTime newAt) {
        if (oldStatus == null || oldAt == null) return true;
        if (newAt == null) return false;
        int c = newAt.toInstant().compareTo(oldAt.toInstant());
        if (c != 0) return c > 0;
        return rank(newStatus) > rank(oldStatus);
    }

    /** latestPerName: the status of the newest build of each workflow name. Any failure shows; then running; all canceled is canceled. */
    static String summarize(Collection<String> latestPerName) {
        if (latestPerName.isEmpty()) return null;
        if (latestPerName.contains("failed")) return "failed";
        if (latestPerName.contains("running")) return "running";
        if (latestPerName.stream().allMatch("canceled"::equals)) return "canceled";
        return "success";
    }
}
```

```java
    @Override public Comparison compare(Remote remote, String repoExternalId, String base, String head, int limit) throws IOException {
        var id = enc(repoExternalId);
        List<CicdEvent.Commit> found;
        boolean truncated = false;
        try {
            var res = http.get(api(remote) + "/projects/" + id + "/repository/compare?from=" + enc(base) + "&to=" + enc(head) + "&straight=false",
                    auth(remote), CicdHttp.MAX_COMPARE_BODY);
            if (res.status() / 100 != 2) throw new IOException("unexpected status " + res.status());
            found = commitsOf(readTree(res.body()).path("commits"));
        } catch (IOException e) {
            if (!"response too large".equals(e.getMessage())) throw e;
            // the diffs made it too big: the same range from the commit list, which carries no diffs
            found = new ArrayList<>();
            for (int page = 1; ; page++) {
                var items = getJson(remote, "/projects/" + id + "/repository/commits?ref_name=" + enc(base + ".." + head)
                        + "&per_page=" + PAGE_SIZE + "&page=" + page);
                found.addAll(commitsOf(items));
                if (items.size() < PAGE_SIZE) break;
                if (page == MAX_PAGES) { truncated = true; break; }
            }
        }
        found.sort(java.util.Comparator.comparing(CicdEvent.Commit::committedAt, java.util.Comparator.nullsLast(java.util.Comparator.reverseOrder())));
        if (found.size() > limit) { found = new ArrayList<>(found.subList(0, limit)); truncated = true; }
        return new Comparison(List.copyOf(found), truncated);
    }

    @Override public boolean contains(Remote remote, String repoExternalId, String head, String commit) throws IOException {
        var base = text(getJson(remote, "/projects/" + enc(repoExternalId) + "/repository/merge_base?refs%5B%5D=" + enc(commit)
                + "&refs%5B%5D=" + enc(head)).path("id")).toLowerCase(java.util.Locale.ROOT);
        var c = commit.toLowerCase(java.util.Locale.ROOT);
        return !base.isEmpty() && (base.startsWith(c) || c.startsWith(base));
    }
```

```java
        mac.init(new SecretKeySpec(secret.getBytes(StandardCharsets.UTF_8), "HmacSHA256"));

        assertThat(argo.verify(Map.of("x-openpms-signature", hmac(b, "s3cret")), b, "s3cret")).isTrue();
```

- Produces: `CicdDeployments.advance(Instant now)` → 상태가 바뀐 배포 수. 상수 `MAX_PER_DIRECTION = 1000`, `MAX_ATTEMPTS = 5`, `FIRST_CANDIDATES = 200`(첫 배포 후보 상한, Task 11도 이 상수를 씀), `static Duration retryDelay(int attempts)` = 1·2·4·8분, `static String errorCode(Exception e)` = `"unexpected status N"` → `"status N"`, `"request timed out"` → `"timeout"`, `"response too large"` → `"too_large"`, 그 밖 `"failed"`.
- `CicdProcessor.run(now)`: 이벤트를 다 처리한 뒤 `for (int i = 0; i < 3; i++) { int n = deployments.advance(now); handled += n; if (n == 0) break; }`(Task 11이 `firstDeploy.check(now)`를 같은 반복에 더함).

규칙:
- **줄 서기:** 처리 대상은 `inclusion = 'checking'`이고, 환경 머리(`cicd_environment_heads.deployment_id`)가 아니며(머리인 `checking`은 첫 배포 확인 중), 같은 `(repository_id, environment_id)`에서 `(deployed_at, id)`가 더 이른 `checking` 배포가 없는 것, 그리고 `next_attempt_at`이 null이거나 `now` 이전인 것. `(deployed_at, id)` 순으로 한 번에 100개.
- **머리 읽기(잠그지 않음) → 계획:**
  - 머리 없음 → **첫 배포 시작**(트랜잭션 하나): `insert into cicd_environment_heads … on conflict do nothing`(0행이면 다른 실행이 먼저 시작함: 넘어감). 배포 커밋 자체가 `cicd_commits`에 있으면 바로 `cicd_deployment_commits`·`cicd_environment_commits`에 넣는다. 후보 = 이 저장소의 커밋 중 끊지 않은 연결이 있는 것 ∪ 연결된 병합 MR의 병합 커밋(배포 커밋 자신 제외), `committed_at` 내림차순 200개 → `cicd_first_deploy_checks`. 200개를 꽉 채웠으면 `first_cutoff_at` = 그 중 가장 오래된 `committed_at`. 후보가 없으면 `inclusion = 'first'`, 있으면 `checking` 그대로(Task 11이 끝냄).
  - `d.deployed_at < head.deployed_at` → **늦게 온 옛 배포**: `inclusion = null`(기록만).
  - 같은 커밋(`head.sha`와 `d.sha` 중 하나가 다른 하나로 시작) → 비교 없이 머리만 옮김(`deployment_id`·`deployed_at`), `inclusion = 'compared'`.
  - 저장소의 연동이 꺼졌거나 토큰이 없음 → **바로 실패**(아래 "실패 확정", `check_error = 'no_token'`).
  - 그 밖: 트랜잭션 **밖에서** `added = compare(head.sha → d.sha)`, `removed = compare(d.sha → head.sha)`(각 `MAX_PER_DIRECTION`).
- **반영(트랜잭션 하나):** `select … from cicd_environment_heads where repository_id = ? and environment_id = ? for update` → `deployment_id`가 읽을 때와 다르면 아무것도 하지 않음(다음 반복이 다시 계획). 같으면:
  - `added`의 커밋마다 `commitStore.upsert(repo, c)` → `insert into cicd_deployment_commits … on conflict do nothing`, `insert into cicd_environment_commits (environment_id, repository_id, commit_id, deployment_id) … on conflict (environment_id, commit_id) do update set deployment_id = excluded.deployment_id`.
  - `removed`의 커밋마다 `delete from cicd_environment_commits where environment_id = ? and commit_id = (select id from cicd_commits where repository_id = ? and sha = ?)`.
  - 머리를 `d`로(`sha`, `deployment_id`, `deployed_at`), `inclusion` = 어느 한쪽이라도 `truncated`면 `partial`(+ `log.warn("cicd deployment {} partial: more than {} commits one way", id, MAX)`), 아니면 `compared`. `attempts = 0`, `next_attempt_at = null`, `check_error = null`.
- **실패:** 비교 중 예외 → `IOException("response too large")`이면 바로 실패 확정(`check_error = 'too_large'`), 아니면 `attempts + 1`; 5 미만이면 `next_attempt_at = now + retryDelay(attempts)`, `check_error` = 짧은 말(`status 401`, `timeout`, `failed`)만. 5번째면 실패 확정. **실패 확정:** 머리를 잠그고 읽은 것과 같으면 머리를 `d`로 옮기고 `inclusion = 'failed'`(환경 커밋은 그대로). 로그는 `log.warn("cicd deployment {} repository {} connection {}: compare failed ({})", …)`(URL·토큰 없음).
- HTTP를 기다리는 동안 DB 트랜잭션·잠금을 쥐지 않는다. `synchronized`·`computeIfAbsent` 없음.
