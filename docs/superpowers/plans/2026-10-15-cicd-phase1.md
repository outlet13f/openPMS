# CI/CD 연동 1단계(연동 기반·추적성) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GitLab·GitHub 저장소를 프로젝트에 붙이면, 커밋·MR/PR에 적은 `#123`이 그 프로젝트의 작업 패키지에 연결되고, 작업의 "개발" 탭에서 MR/PR 상태와 커밋을 본다. 도구 연동은 전역 권한으로 위임하고, 일반 멤버는 보기·연결 고치기, 개발 리더는 저장소 관리를 한다.

**Architecture:** 새 패키지 `com.openpms.cicd`. 들어오는 웹훅(`CicdHookController`)과 보완 폴링(`CicdPoller`)이 모두 도구별 어댑터(`CicdAdapter`: `GitLabAdapter`·`GitHubAdapter`)로 정규화 이벤트를 만들어 `cicd_events`에 넣고(유일 키로 중복 제거), 예약 작업 `cicd-process`가 이벤트를 커밋·MR 표로 옮기고 `CicdLinker`가 참조(`RefParser`, 순수 함수)를 프로젝트 범위 안의 작업에만 연결한다. 자격 증명은 `SecretBox`(AES-GCM)로 암호화한다.

**Tech Stack:** Spring Boot 4 / Java 21(가상 스레드) / jOOQ / Flyway / PostgreSQL 17 / db-scheduler, JDK `HttpClient`·`HttpServer`(테스트), React 19 / Vite / TypeScript / TanStack Query / Tailwind v4, JUnit 5 + MockMvc, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-15-cicd-design.md` (HTML `2026-10-15-cicd-design.html`)

## 설계서 보완 (코드 조사 뒤 정함, Task 1에서 설계서에도 적음)

1. **웹훅 경로는 `/api/v1/hooks/cicd/{hookKey}`.** 설계서의 `/hooks/cicd/...`는 `SpaConfig`가 `/api` 밖의 주소를 모두 `index.html`로 돌려주고, 운영 프록시도 `/api`만 백엔드로 보내므로 `/api` 아래로 둔다. `SecurityConfig`에서 이 경로만 `permitAll`과 CSRF 제외를 건다(`/api/**` authenticated보다 앞에).
2. **감사 로그는 로거 `openpms.audit`.** 저장소에 감사 로그 표가 없다. 연동 만들기·바꾸기·비밀 다시 발급·지우기를 `openpms.audit` 로거에 INFO로 남긴다(누가, 무엇을, 연동 id·이름. 토큰·비밀·URL의 사용자 정보는 남기지 않음). 감사 표는 필요해지면 따로 정한다.
3. **암호화 키 형식.** `OPENPMS_SECRET_KEY`는 32바이트를 Base64로 적은 값(`openssl rand -base64 32`). 설정 키 `openpms.secret-key`. dev 프로필은 고정된 개발용 키를 기본값으로 둔다(운영 기본값은 빈 값 → 연동 저장 422 "암호화 키(OPENPMS_SECRET_KEY)가 설정되지 않았습니다.").
4. **개발 데이터의 연동은 비밀 없이.** SQL로는 AES-GCM 값을 만들 수 없으므로 V1010의 연동은 `api_token_enc`·`webhook_secret_enc`가 비어 있고 `active = false`다(화면에서 "비밀 다시 발급"과 토큰 입력으로 켠다). 저장소·커밋·MR·연결은 V1010이 넣는다.
5. **토큰이 없는 연동은 폴링하지 않는다.** `api_token_enc`가 비면 웹훅만 받는다(GitHub Cloud처럼 들어오는 길만 있는 경우 대비가 아니라 그 반대: 토큰 없이 웹훅만 쓰는 설치). 저장소 검색(붙이기 화면)은 토큰이 있어야 한다.
6. **기존 역할에 권한 더하기.** V20은 역할 id로 더했지만, 설계서대로 가진 권한으로 판단한다: `scope = 'project' and builtin is null`이고 `wp.view`가 있으면 `cicd.view`, `wp.edit`이 있으면 `cicd.link`, `project.manage_members`가 있으면 `cicd.manage`. 비멤버·요청자 내장 역할은 건드리지 않는다.

- 참조는 저장소가 붙은 프로젝트와 그 하위 프로젝트의 작업에만 연결한다. 끊은 연결(`dismissed_at`)은 다시 살아나지 않는다.

- 이름: 식별자 `cicd_`·`Cicd*`. CMDB의 `ci`(구성 항목)와 섞지 않는다. 화면 문구는 "CI/CD", "개발".

```java
package com.openpms.cicd;

import static org.assertj.core.api.Assertions.assertThat;

import java.util.List;
import org.jooq.DSLContext;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.test.context.ActiveProfiles;

@SpringBootTest(properties = "openpms.jobs.enabled=false")
@ActiveProfiles("dev")
class CicdMigrationIT {
    @Autowired DSLContext db;

    List<String> perms(String id) {
        return List.of(db.fetchOne("select permissions from roles where id = ?::uuid", id).get(0, String[].class));
    }

    @Test void rolesGetTheCicdPermissions() {
        // 프로젝트 관리자 · 멤버 · 참관자
        assertThat(perms("0329397e-d933-5ac1-b27c-95889ba1a893")).contains("cicd.view", "cicd.link", "cicd.manage");
        assertThat(perms("6d4333fb-e975-5213-8ebc-552cca26e1d4")).contains("cicd.view", "cicd.link").doesNotContain("cicd.manage");
        assertThat(perms("f957f36a-72ca-5379-b8b9-c0e7dabe2d1e")).contains("cicd.view").doesNotContain("cicd.link", "cicd.manage");
        // 비멤버 · 요청자: 없음
        assertThat(perms("21f83874-5c75-520e-aa32-76a829a19e30")).noneMatch(p -> p.startsWith("cicd."));
        assertThat(perms("a9137727-cb80-51db-98d8-8a9a04f84802")).noneMatch(p -> p.startsWith("cicd."));
    }

    @Test void devLeadIsMemberPlusManage() {
        var lead = perms("8e9c194d-fcdf-5c47-b081-ab2b2b61c89a");
        assertThat(lead).containsAll(perms("6d4333fb-e975-5213-8ebc-552cca26e1d4").stream().filter(p -> !p.equals("cicd.manage")).toList());
        assertThat(lead).contains("cicd.manage");
        assertThat(db.fetchValue("select name from roles where id = '8e9c194d-fcdf-5c47-b081-ab2b2b61c89a'")).isEqualTo("개발 리더");
        assertThat(db.fetchValue("select scope from roles where id = 'bae8d8f2-850d-5250-9c69-25b1631be394'")).isEqualTo("global");
```

```java
package com.openpms.cicd;

import com.openpms.common.ApiException;
import java.nio.charset.StandardCharsets;
import java.security.GeneralSecurityException;
import java.security.SecureRandom;
import java.util.Base64;
import javax.crypto.Cipher;
import javax.crypto.spec.GCMParameterSpec;
import javax.crypto.spec.SecretKeySpec;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

/**
 * Tool tokens and webhook secrets at rest: AES-256-GCM with the key from OPENPMS_SECRET_KEY (32 bytes, Base64). Without a key
 * nothing can be saved (422); a lost key means entering the tokens again (10 운영자 매뉴얼).
 */
@Component
public class SecretBox {
    private static final SecureRandom RANDOM = new SecureRandom();
    private final SecretKeySpec key;

    public SecretBox(@Value("${openpms.secret-key:}") String base64Key) {
        if (base64Key == null || base64Key.isBlank()) {
            key = null;
            return;
        }
        var raw = Base64.getDecoder().decode(base64Key.trim());
        if (raw.length != 32) throw new IllegalArgumentException("OPENPMS_SECRET_KEY must be 32 bytes (Base64), got " + raw.length);
        key = new SecretKeySpec(raw, "AES");
    }

    public boolean ready() {
        return key != null;
    }

    public void requireReady() {
        if (key == null) throw new ApiException(422, "암호화 키(OPENPMS_SECRET_KEY)가 설정되지 않았습니다.");
    }

    public String seal(String plain) {
        requireReady();
        try {
            var iv = new byte[12];
            RANDOM.nextBytes(iv);
            var c = Cipher.getInstance("AES/GCM/NoPadding");
            c.init(Cipher.ENCRYPT_MODE, key, new GCMParameterSpec(128, iv));
            var ct = c.doFinal(plain.getBytes(StandardCharsets.UTF_8));
            var b64 = Base64.getEncoder();
            return "v1:" + b64.encodeToString(iv) + ":" + b64.encodeToString(ct);
        } catch (GeneralSecurityException e) {
            throw new IllegalStateException("seal failed", e);
        }
    }

    public String open(String sealed) {
        requireReady();
        var parts = sealed.split(":");
        if (parts.length != 3 || !"v1".equals(parts[0])) throw new IllegalStateException("unknown secret format");
        try {
            var b64 = Base64.getDecoder();
            var c = Cipher.getInstance("AES/GCM/NoPadding");
            c.init(Cipher.DECRYPT_MODE, key, new GCMParameterSpec(128, b64.decode(parts[1])));
            return new String(c.doFinal(b64.decode(parts[2])), StandardCharsets.UTF_8);
        } catch (GeneralSecurityException | IllegalArgumentException e) {
            throw new IllegalStateException("secret could not be opened (wrong key or changed value)");
        }
    }

    public static String hint(String plain) {
        return plain == null || plain.length() <= 4 ? "****" : plain.substring(plain.length() - 4);
    }
}
```

```java
package com.openpms.cicd;

import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.regex.Pattern;

/**
 * Work package numbers in commit messages, MR/PR titles and descriptions ("#123") and branch names ("feature/123-login").
 * A branch under release/ or hotfix/, or one whose first part looks like a version (v1.2), is not read: "release/2026-10"
 * is a date, not work package 2026. At most 20 numbers per event, 1–12 digits.
 */
public final class RefParser {
    public record Ref(long number, String source) {}

    static final int MAX = 20;
    private static final Pattern TEXT = Pattern.compile("(?<=^|[\\s(\\[,])#(\\d{1,12})(?![\\w\\d])", Pattern.MULTILINE);
    private static final Pattern TOO_LONG = Pattern.compile("#\\d{13,}");
    private static final Pattern BRANCH_PART = Pattern.compile("^(\\d{1,12})(?:[-_].*)?$");
    private static final Pattern SKIP_BRANCH = Pattern.compile("^(release|hotfix|v\\d)", Pattern.CASE_INSENSITIVE);

    private RefParser() {}

    public static List<Ref> inText(String text, String source) {
        var out = new ArrayList<Ref>();
        if (text == null) return out;
        var cleaned = TOO_LONG.matcher(text).replaceAll(" ");
        var m = TEXT.matcher(cleaned);
        while (m.find() && out.size() < MAX) out.add(new Ref(Long.parseLong(m.group(1)), source));
        return merge(out);
    }

    public static List<Ref> inBranch(String branch) {
        if (branch == null || branch.isBlank() || SKIP_BRANCH.matcher(branch).find()) return List.of();
        var parts = branch.split("/");
        var m = BRANCH_PART.matcher(parts[parts.length - 1]);
        return m.matches() ? List.of(new Ref(Long.parseLong(m.group(1)), "branch")) : List.of();
    }

    @SafeVarargs
    public static List<Ref> merge(List<Ref>... lists) {
        var byNumber = new LinkedHashMap<Long, Ref>();
        for (var l : lists) for (var r : l) if (byNumber.size() < MAX) byNumber.putIfAbsent(r.number(), r);
        return List.copyOf(byNumber.values());
    }
}
```

- 이벤트 종류와 delivery key:
  - GitLab `X-Gitlab-Event: Push Hook` → 커밋마다 `commit` 이벤트, key `commit:<projectId>:<sha>`. `Merge Request Hook` → `merge_request`, key `mr:<projectId>:<iid>:<updated_at>`.

- 검증: GitLab은 `x-gitlab-token`과 secret을 `MessageDigest.isEqual`로. GitHub는 `x-hub-signature-256`이 `sha256=` + HMAC-SHA256(body, secret) 16진수와 `MessageDigest.isEqual`로. 헤더가 없으면 false.
- 폴링 API(공개 문서 기준):
  - GitLab: `GET {base}/api/v4/projects/{id}/repository/commits?since=<ISO>&per_page=100`, `GET {base}/api/v4/projects/{id}/merge_requests?updated_after=<ISO>&per_page=100`, 헤더 `PRIVATE-TOKEN`. 저장소 검색 `GET {base}/api/v4/projects?search=<q>&membership=true&per_page=20`. 확인 `GET {base}/api/v4/user`.

```java
@RestController
public class CicdHookController {
    private static final Logger log = LoggerFactory.getLogger(CicdHookController.class);
    private final DSLContext db;
    private final SecretBox box;
    private final Adapters adapters;
    private final CicdEvents events;
    private final int maxBytes;

    // constructor with @Value("${openpms.cicd.max-hook-bytes:1048576}") int maxBytes

    @PostMapping("/api/v1/hooks/cicd/{hookKey}")
    public ResponseEntity<Map<String, Integer>> receive(@PathVariable String hookKey, HttpServletRequest req) throws IOException {
        if (req.getContentLengthLong() > maxBytes) throw new ApiException(413, "본문이 너무 큽니다.");
        byte[] body = req.getInputStream().readNBytes(maxBytes + 1);
        if (body.length > maxBytes) throw new ApiException(413, "본문이 너무 큽니다.");
        var c = db.selectFrom(CICD_CONNECTIONS).where(CICD_CONNECTIONS.HOOK_KEY.eq(hookKey)).fetchOne();
        var headers = lowerCaseHeaders(req);
        // unknown key, switched off, no secret and a bad signature answer the same, so nothing can be probed
        if (c == null || !c.getActive() || c.getWebhookSecretEnc() == null || !box.ready()
                || !adapters.of(c.getKind()).verify(headers, body, box.open(c.getWebhookSecretEnc())))
            throw ApiException.notFound("찾을 수 없습니다.");
        var parsed = adapters.of(c.getKind()).parse(headers, body);
        int n = events.store(c.getId(), parsed, "webhook");
        log.debug("cicd hook {} delivery={} events={} new={}", c.getId(), headers.getOrDefault("x-github-delivery", headers.get("x-gitlab-event-uuid")), parsed.size(), n);
        return ResponseEntity.accepted().body(Map.of("accepted", n));
    }
}
```

`ApiException`의 413·404 생성 방식은 `ApiException.java`에서 확인해 맞춘다. 파싱 오류(JSON이 깨짐)는 400 "본문을 읽을 수 없습니다."(서명이 맞은 뒤에만 도달하므로 정보가 새지 않음). `RateLimiter`가 IP별 제한을 제공하면 이 경로에 분당 600건으로 건다(`RateLimiter` 사용법은 `ApiTokenFilter` 참고).
