# ITSM 1단계(장애·서비스 요청, SLA, 요청자 포털) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 서비스 데스크 모듈을 켠 프로젝트에서 장애·서비스 요청을 작업 패키지로 받고, 정책별 달력(24×7·근무 시간)으로 SLA 기한을 계산·멈춤·위반 감지하며, 프로젝트 멤버가 아닌 직원은 `/portal`에서 자기 티켓만 접수·조회·답변한다.

**Architecture:** 티켓은 작업 패키지 유형 "장애"·"서비스 요청"이고, ITSM 값은 1:1 확장 테이블 `service_tickets`에 둔다(공동 담당자 `Assignees`와 같은 방식). 새 패키지 `com.openpms.itsm`이 SLA 계산(`SlaClock`, 순수 함수), 저장 훅(`ServiceDesk`), 설정 API, 포털 API, 작업(`SlaJobs`, `PortalMail`)을 맡는다. 작업 패키지 저장 경로(`WorkPackageService`)에는 같은 트랜잭션 안에서 부르는 훅 세 곳만 더하고, 포털은 권한 검사만 다른 같은 저장 경로(`Acting.PORTAL`)를 쓴다.

**Tech Stack:** Spring Boot 4 / Java 21(가상 스레드) / jOOQ / Flyway / PostgreSQL 17 / db-scheduler, React 19 / Vite / TypeScript / TanStack Query / Tailwind v4, JUnit 5 + MockMvc, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-14-itsm-design.md` (로드맵은 `2026-10-14-itsm-index.html`)

## 설계서와 달라진 점 (구현 조사 뒤 정함, Task 1에서 설계서도 고침)

1. **권한 키 이름**: 저장소 규칙(`wp.view`처럼 점으로 나눔)에 맞춰 `service.view`, `service.handle`, `service.manage`로 한다(설계서의 `view_service_tickets` 등). 모듈 `service_desk`가 꺼지면 빠진다(`Ctx.MODULE_OF`).
2. **요청자 상태 전환**: 요청자는 프로젝트 역할이 없어서 기존 워크플로 검사(`Assembler.allowedStatusIds`, 역할 기준)에 걸리지 않는다. 그래서 내장 역할 "요청자"(`roles.builtin = 'requester'`)를 두고, 포털에서는 이 역할의 워크플로(`applies_to = 'author'`, 작성자 = 요청자)로 검사한다. 관리자는 기존 워크플로 화면에서 이 역할의 전환을 고칠 수 있다. 멤버 지정 화면에는 나오지 않는다(기존 `builtin() == null` 필터).
3. **요청자 알림**: 기존 알림 센터·메일은 받는 사람이 `wp.view`를 가져야 해서 멤버가 아닌 요청자에게 쓸 수 없다. 요청자에게는 포털의 "새 소식" 표시(`service_tickets.requester_seen_at`)와 별도 메일 작업 `portal-mail`(접수 확인·처리자 답변·해결)로 알린다. 처리자 알림은 기존 알림 센터를 쓰고, SLA 임박·위반은 새 이유 `sla_warning`·`sla_breached`로 보낸다.
4. **서비스 데스크 프로젝트는 비공개만**: 공개 프로젝트는 비멤버 역할에 `wp.view`가 있어 전 직원이 모든 티켓을 보게 된다. `service_desk` 모듈과 `isPublic = true`를 함께 둘 수 없다(422).
5. **ITSM 값 편집**: 요청자·영향도·긴급도·처리 그룹은 작업 패키지 PATCH가 아니라 `PATCH /api/v1/work-packages/{number}/service-ticket`로 고친다(저널에 남김). 목록 열을 위해 `Dto.WorkPackage`에 `serviceTicket` 필드를 더한다.

```java
package com.openpms.itsm;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

import java.time.DayOfWeek;
import java.time.Duration;
import java.time.Instant;
import java.time.LocalDate;
import java.time.LocalDateTime;
import java.time.LocalTime;
import java.time.ZoneId;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.Set;
import org.junit.jupiter.api.Test;

class SlaClockTest {
    static final ZoneId SEOUL = ZoneId.of("Asia/Seoul");
    static final SlaClock.Calendar WEEKDAYS = SlaClock.Calendar.business(SEOUL, weekdays(LocalTime.of(9, 0), LocalTime.of(18, 0)));

    static List<SlaClock.Window> weekdays(LocalTime start, LocalTime end) {
        var out = new ArrayList<SlaClock.Window>();
        for (int d = 1; d <= 5; d++) out.add(new SlaClock.Window(DayOfWeek.of(d), start, end));
        return out;
    }

    static Instant at(String local) {
        return LocalDateTime.parse(local).atZone(SEOUL).toInstant();
    }

    @Test void allDayCalendarJustAdds() {
        var cal = SlaClock.Calendar.always(SEOUL);
        assertThat(SlaClock.add(at("2026-10-17T23:00"), Duration.ofHours(4), cal, Set.of())).isEqualTo(at("2026-10-18T03:00"));
    }

    @Test void insideWorkingHoursStaysOnTheSameDay() {
        assertThat(SlaClock.add(at("2026-10-14T10:00"), Duration.ofHours(4), WEEKDAYS, Set.of())).isEqualTo(at("2026-10-14T14:00"));
    }

    @Test void theRestCarriesToTheNextWorkingMorning() {
        // 수 17:00 + 4h = 수 18:00까지 1h, 목 09:00부터 3h
        assertThat(SlaClock.add(at("2026-10-14T17:00"), Duration.ofHours(4), WEEKDAYS, Set.of())).isEqualTo(at("2026-10-15T12:00"));
    }

    @Test void fridayEveningSkipsTheWeekendAndAHoliday() {
        // 금 17:30 + 4h: 금 30분, 토·일 건너뜀, 월(휴무일) 건너뜀, 화 09:00부터 3h30m
        var holidays = Set.of(LocalDate.parse("2026-10-19"));
        assertThat(SlaClock.add(at("2026-10-16T17:30"), Duration.ofHours(4), WEEKDAYS, holidays)).isEqualTo(at("2026-10-20T12:30"));
    }

    @Test void receivedBeforeOpeningStartsAtOpening() {
        assertThat(SlaClock.add(at("2026-10-14T07:00"), Duration.ofMinutes(30), WEEKDAYS, Set.of())).isEqualTo(at("2026-10-14T09:30"));
    }

    @Test void receivedAtClosingStartsNextMorning() {
        assertThat(SlaClock.add(at("2026-10-14T18:00"), Duration.ofMinutes(30), WEEKDAYS, Set.of())).isEqualTo(at("2026-10-15T09:30"));
    }

    @Test void endingExactlyAtClosingStaysThatDay() {
        assertThat(SlaClock.add(at("2026-10-14T17:00"), Duration.ofHours(1), WEEKDAYS, Set.of())).isEqualTo(at("2026-10-14T18:00"));
    }

    @Test void splitDaysCountEachWindow() {
        var lunch = SlaClock.Calendar.business(SEOUL, List.of(
                new SlaClock.Window(DayOfWeek.WEDNESDAY, LocalTime.of(9, 0), LocalTime.of(12, 0)),
                new SlaClock.Window(DayOfWeek.WEDNESDAY, LocalTime.of(13, 0), LocalTime.of(18, 0))));
        assertThat(SlaClock.add(at("2026-10-14T11:00"), Duration.ofHours(2), lunch, Set.of())).isEqualTo(at("2026-10-14T14:00"));
```

```java
package com.openpms.itsm;

import java.time.DayOfWeek;
import java.time.Duration;
import java.time.Instant;
import java.time.LocalDate;
import java.time.LocalTime;
import java.time.ZoneId;
import java.time.ZonedDateTime;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.Map;
import java.util.Set;

/**
 * SLA time (docs/superpowers/specs/2026-10-14-itsm-design.md §5): a 24x7 calendar counts every minute, a business
 * calendar only its weekly windows outside holidays. Pure: the caller passes the holidays (non_working_days).
 */
public final class SlaClock {
    /** About ten years of days: a business calendar always has a window, so this only stops a broken one. */
    private static final int MAX_DAYS = 3660;

    public record Window(DayOfWeek day, LocalTime start, LocalTime end) {
        public Window {
            if (!end.isAfter(start)) throw new IllegalArgumentException("근무 시간의 끝이 시작보다 늦어야 합니다.");
        }
    }

    public record Calendar(boolean allDay, ZoneId zone, List<Window> windows) {
        public static Calendar always(ZoneId zone) {
            return new Calendar(true, zone, List.of());
        }

        public static Calendar business(ZoneId zone, List<Window> windows) {
            return new Calendar(false, zone, List.copyOf(windows));
        }

        List<Window> on(DayOfWeek d) {
            return windows.stream().filter(w -> w.day() == d).sorted(Comparator.comparing(Window::start)).toList();
        }
    }

    private SlaClock() {}

    /** The moment {@code amount} of calendar time after {@code start}. */
    public static Instant add(Instant start, Duration amount, Calendar cal, Set<LocalDate> holidays) {
        if (amount.isNegative()) throw new IllegalArgumentException("음수 시간은 더할 수 없습니다.");
        if (cal.allDay()) return start.plus(amount);
        if (cal.windows().isEmpty()) throw new IllegalArgumentException("근무 시간이 없는 달력입니다.");
        var left = amount;
        ZonedDateTime cursor = start.atZone(cal.zone());
        for (int i = 0; i < MAX_DAYS; i++) {
            var day = cursor.toLocalDate();
            if (!holidays.contains(day)) {
                for (var w : cal.on(day.getDayOfWeek())) {
                    var open = day.atTime(w.start()).atZone(cal.zone());
                    var close = day.atTime(w.end()).atZone(cal.zone());
                    var from = cursor.isAfter(open) ? cursor : open;
                    if (!from.isBefore(close)) continue;
                    var room = Duration.between(from, close);
                    if (left.compareTo(room) <= 0) return from.plus(left).toInstant();
                    left = left.minus(room);
                    cursor = close;
                }
            }
            cursor = day.plusDays(1).atStartOfDay(cal.zone());
        }
        throw new IllegalStateException("SLA 기한을 계산할 수 없습니다.");
    }

    /** How much calendar time lies in [from, to). */
    public static Duration workingTime(Instant from, Instant to, Calendar cal, Set<LocalDate> holidays) {
        if (!to.isAfter(from)) return Duration.ZERO;
        if (cal.allDay()) return Duration.between(from, to);
        var total = Duration.ZERO;
        var end = to.atZone(cal.zone());
        ZonedDateTime cursor = from.atZone(cal.zone());
        for (int i = 0; i < MAX_DAYS && cursor.isBefore(end); i++) {
            var day = cursor.toLocalDate();
            if (!holidays.contains(day)) {
                for (var w : cal.on(day.getDayOfWeek())) {
                    var open = day.atTime(w.start()).atZone(cal.zone());
                    var close = day.atTime(w.end()).atZone(cal.zone());
                    var a = cursor.isAfter(open) ? cursor : open;
                    var b = end.isBefore(close) ? end : close;
                    if (a.isBefore(b)) total = total.plus(Duration.between(a, b));
                }
            }
            cursor = day.plusDays(1).atStartOfDay(cal.zone());
        }
        return total;
    }

    /** service_calendars.hours: [{"day": 1, "start": "09:00", "end": "18:00"}] with ISO days. */
    public static List<Window> parseHours(List<Map<String, Object>> hours) {
        var out = new ArrayList<Window>();
        for (var h : hours) {
            var day = ((Number) h.get("day")).intValue();
            if (day < 1 || day > 7) throw new IllegalArgumentException("요일은 1(월)부터 7(일)까지입니다.");
            out.add(new Window(DayOfWeek.of(day), LocalTime.parse((String) h.get("start")), LocalTime.parse((String) h.get("end"))));
        }
        return out;
    }
}
```

```java
    public CalendarDto saveCalendar(UUID id, Map<String, Object> in) {

                throw ApiException.field("name", "같은 이름의 달력이 있습니다.");
            r.setName(name);

        }
        if (id == null || In.has(in, "timeZone")) {

        }
```

```java
import static com.openpms.db.Tables.SERVICE_TICKETS;
```

```java
/** service_tickets, read in bulk for lists (like wp/Assignees). */
@Component
public class ServiceTickets {
    private final DSLContext db;

    public ServiceTickets(DSLContext db) {
        this.db = db;
    }

    public Map<UUID, ServiceTicketsRecord> of(Collection<UUID> ids) {
        var out = new HashMap<UUID, ServiceTicketsRecord>();
        if (ids.isEmpty()) return out;
        db.selectFrom(SERVICE_TICKETS).where(SERVICE_TICKETS.WORK_PACKAGE_ID.in(ids)).fetch().forEach(t -> out.put(t.getWorkPackageId(), t));
        return out;
    }

    public Optional<ServiceTicketsRecord> of(UUID id) {
        return Optional.ofNullable(db.selectFrom(SERVICE_TICKETS).where(SERVICE_TICKETS.WORK_PACKAGE_ID.eq(id)).fetchOne());
    }

    public static Dto.Sla sla(ServiceTicketsRecord t) {
        return new Dto.Sla(t.getFirstResponseDueAt(), t.getFirstRespondedAt(), t.getResolveDueAt(), t.getResolvedAt(), t.getPausedSince() != null,
                t.getPausedTotalSeconds(), t.getResponseBreached(), t.getResolveBreached());
    }

    public static Dto.ServiceTicket dto(Snapshot s, ServiceTicketsRecord t) {
        if (t == null) return null;
        var group = t.getAssignmentGroupId() == null ? null
                : Optional.ofNullable(s.groups().get(t.getAssignmentGroupId())).map(g -> new Dto.IdName(g.id(), g.name())).orElse(null);
        return new Dto.ServiceTicket(Refs.user(s, t.getRequesterId()), t.getChannel(), t.getImpact(), t.getUrgency(), group, sla(t));
    }
}
```

```java
package com.openpms.itsm;

import static com.openpms.db.Tables.SERVICE_TICKETS;
import static com.openpms.db.Tables.USER_GROUPS;

import com.openpms.common.ApiException;
import com.openpms.common.In;
import com.openpms.core.Ctx;
import com.openpms.core.Snapshot;
import com.openpms.db.tables.records.ServiceTicketsRecord;
import com.openpms.db.tables.records.WorkPackagesRecord;
import java.time.Duration;
import java.time.Instant;
import java.time.OffsetDateTime;
import java.time.ZoneId;
import java.time.ZoneOffset;
import java.util.Map;
import java.util.Objects;
import java.util.UUID;
import org.jooq.DSLContext;
import org.springframework.stereotype.Component;

/**
 * What a service desk adds to saving a work package (docs/superpowers/specs/2026-10-14-itsm-design.md §5): the
 * service_tickets row and its SLA. Called by WorkPackageService inside its transaction; never calls it back.
 */
@Component
public class ServiceDesk {
    public record Draft(UUID requesterId, String channel, int impact, int urgency, UUID groupId) {}

    private final DSLContext db;
    private final ServiceDeskConfig config;
    private final ServiceTickets tickets;

    public ServiceDesk(DSLContext db, ServiceDeskConfig config, ServiceTickets tickets) {
        this.db = db;
        this.config = config;
        this.tickets = tickets;
    }

    public boolean applies(Snapshot.ProjectRow p, UUID typeId) {
        return p.enabledModules().contains(ItsmIds.MODULE) && ItsmIds.TICKET_TYPES.contains(typeId);
    }

    /** Reads requester, impact, urgency and group from a create request. The requester is the caller unless an agent names someone. */
    public Draft draft(Ctx ctx, Snapshot.ProjectRow p, Map<String, Object> in, String channel) {
        var requesterId = "portal".equals(channel) ? ctx.userId() : In.uuid(in, "requesterId", "requester");
        if (requesterId == null) requesterId = ctx.userId();
        var requester = ctx.s().user(requesterId).filter(u -> "active".equals(u.status())).orElse(null);
        if (requester == null) throw ApiException.field("requester", "요청자는 활성 사용자여야 합니다.");
        return new Draft(requesterId, channel, level(in, "impact"), level(in, "urgency"), "portal".equals(channel) ? null : group(in));
    }

    static int level(Map<String, Object> in, String key) {
        var v = In.integer(in, key, key);
        if (v == null) return 2;
        if (v < 1 || v > 3) throw ApiException.field(key, "1(높음)·2(보통)·3(낮음) 중에서 고르세요.");
        return v;
    }

    UUID group(Map<String, Object> in) {
        var id = In.uuid(in, "assignmentGroupId", "assignmentGroup");
        if (id != null && !db.fetchExists(USER_GROUPS, USER_GROUPS.ID.eq(id))) throw ApiException.field("assignmentGroup", "알 수 없는 그룹입니다.");
        return id;
    }

    public UUID priorityFor(Snapshot.ProjectRow p, Draft d) {
        return config.matrixPriority(p.id(), d.impact(), d.urgency()).orElse(null);
    }

    public void created(Ctx ctx, WorkPackagesRecord w, Draft d) {
        var t = db.newRecord(SERVICE_TICKETS);
        t.setWorkPackageId(w.getId());
        t.setRequesterId(d.requesterId());
        t.setChannel(d.channel());
        t.setImpact((short) d.impact());
        t.setUrgency((short) d.urgency());
        t.setAssignmentGroupId(d.groupId());
        t.setCreatedAt(w.getCreatedAt());
        t.setUpdatedAt(w.getCreatedAt());
        recompute(ctx, t, w, Instant.now());
        t.store();
    }

    public void updated(Ctx ctx, WorkPackagesRecord before, WorkPackagesRecord after) {
        var p = ctx.s().project(after.getProjectId()).orElseThrow();
        boolean was = applies(p, before.getTypeId()), is = applies(p, after.getTypeId());
        if (was != is) throw ApiException.field("type", "티켓 유형(장애·서비스 요청)과 다른 유형 사이는 바꿀 수 없습니다.");
        if (!is) return;
        var t = tickets.of(after.getId()).orElse(null);
        if (t == null) return; // made before the module was switched on
        var now = Instant.now();
        var s = ctx.s();
        var from = s.status(before.getStatusId()).orElseThrow();
        var to = s.status(after.getStatusId()).orElseThrow();
        boolean statusChanged = !from.id().equals(to.id());
        if (statusChanged) {
            if (to.slaPause() && t.getPausedSince() == null && !to.isClosed()) t.setPausedSince(at(now));
            if ((!to.slaPause() || to.isClosed()) && t.getPausedSince() != null) closePause(ctx, t, after, now);
            if (to.isClosed() && !from.isClosed()) t.setResolvedAt(at(now));
            if (!to.isClosed() && from.isClosed()) t.setResolvedAt(null);
            firstResponse(ctx, t, now);
        }
        if (statusChanged || !Objects.equals(before.getPriorityId(), after.getPriorityId()) || !Objects.equals(before.getTypeId(), after.getTypeId())) {
            recompute(ctx, t, after, now);
        }
        if (t.changed()) t.store();
    }

    public void commented(Ctx ctx, WorkPackagesRecord w, boolean internal) {
        if (internal) return;
        var t = tickets.of(w.getId()).orElse(null);
        if (t == null) return;
        firstResponse(ctx, t, Instant.now());
        if (t.changed()) t.store();
    }

    private void firstResponse(Ctx ctx, ServiceTicketsRecord t, Instant now) {
        if (t.getFirstRespondedAt() == null && !ctx.userId().equals(t.getRequesterId())) t.setFirstRespondedAt(at(now));
    }

    private void closePause(Ctx ctx, ServiceTicketsRecord t, WorkPackagesRecord w, Instant now) {
        var cal = config.policyFor(w.getProjectId(), w.getTypeId(), w.getPriorityId()).map(ServiceDeskConfig.Policy::calendar)
                .orElse(SlaClock.Calendar.always(ZoneId.of("Asia/Seoul")));
        var paused = SlaClock.workingTime(t.getPausedSince().toInstant(), now, cal, ctx.s().calendar().holidays());
        t.setPausedTotalSeconds(t.getPausedTotalSeconds() + paused.toSeconds());
        t.setPausedSince(null);
    }

    /** Deadlines from the ticket's start, the current policy and the pauses so far. Breaches stay; a later deadline may warn again. */
    private void recompute(Ctx ctx, ServiceTicketsRecord t, WorkPackagesRecord w, Instant now) {
        var policy = config.policyFor(w.getProjectId(), w.getTypeId(), w.getPriorityId()).orElse(null);
        if (policy == null) {
            t.setSlaPolicyId(null);
            t.setFirstResponseDueAt(null);
            t.setResolveDueAt(null);
            return;
        }
        var holidays = ctx.s().calendar().holidays();
        var start = t.getCreatedAt().toInstant();
        var respond = at(SlaClock.add(start, policy.firstResponse(), policy.calendar(), holidays));
        var resolve = at(SlaClock.add(start, policy.resolve().plus(Duration.ofSeconds(t.getPausedTotalSeconds())), policy.calendar(), holidays));
        if (!respond.equals(t.getFirstResponseDueAt()) && respond.toInstant().isAfter(now)) t.setResponseWarned(false);
        if (!resolve.equals(t.getResolveDueAt()) && resolve.toInstant().isAfter(now)) t.setResolveWarned(false);
        t.setSlaPolicyId(policy.id());
        t.setFirstResponseDueAt(respond);
        t.setResolveDueAt(resolve);
    }

    private static OffsetDateTime at(Instant i) {
        return i.atOffset(ZoneOffset.UTC);
    }
}
```

```java
@RequestMapping("/api/v1")
public class ServiceTicketController {
    private final Current current;
    private final WorkPackageService workPackages;
    private final ServiceTickets tickets;
    private final ServiceDesk serviceDesk;
    private final ServiceDeskConfig config;
    private final Journals journals;
    private final Assembler assembler;

    public ServiceTicketController(Current current, WorkPackageService workPackages, ServiceTickets tickets, ServiceDesk serviceDesk,
                                   ServiceDeskConfig config, Journals journals, Assembler assembler) {
        this.current = current;
        this.workPackages = workPackages;
        this.tickets = tickets;
        this.serviceDesk = serviceDesk;
        this.config = config;
        this.journals = journals;
        this.assembler = assembler;
    }

    @GetMapping("/work-packages/{number}/service-ticket")
    public Dto.ServiceTicket get(@PathVariable long number) {
        var ctx = current.ctx();
        var f = workPackages.find(ctx, number);
        if (!ctx.can(f.project(), "service.view")) throw ApiException.notFound("작업을 찾을 수 없습니다.");
        return ServiceTickets.dto(ctx.s(), tickets.of(f.wp().getId()).orElseThrow(() -> ApiException.notFound("서비스 데스크 티켓이 아닙니다.")));
    }

    /** requesterId, impact, urgency, assignmentGroupId; applyMatrix also sets the priority from the matrix. */
    @PatchMapping("/work-packages/{number}/service-ticket")
    @Transactional
    public Dto.WorkPackage patch(@PathVariable long number, @RequestBody Map<String, Object> in) {
        var ctx = current.ctx();
        var f = workPackages.find(ctx, number);
        if (!ctx.can(f.project(), "service.view")) throw ApiException.notFound("작업을 찾을 수 없습니다.");
        ctx.require(f.project(), "service.handle", "티켓을 처리할 권한이 없습니다.");
        var t = tickets.of(f.wp().getId()).orElseThrow(() -> ApiException.notFound("서비스 데스크 티켓이 아닙니다."));
        var changes = new LinkedHashMap<String, List<Object>>();
        if (In.has(in, "requesterId")) {
            var next = serviceDesk.draft(ctx, f.project(), Map.of("requesterId", String.valueOf(in.get("requesterId"))), "agent").requesterId();
            if (!next.equals(t.getRequesterId())) changes.put("requesterId", Journals.listOf(t.getRequesterId(), next));
            t.setRequesterId(next);
        }
        for (var key : List.of("impact", "urgency")) {
            if (!In.has(in, key)) continue;
            short next = (short) ServiceDesk.level(in, key);
            short prev = "impact".equals(key) ? t.getImpact() : t.getUrgency();
            if (next != prev) changes.put(key, Journals.listOf((int) prev, (int) next));
            if ("impact".equals(key)) t.setImpact(next);
            else t.setUrgency(next);
        }
        if (In.has(in, "assignmentGroupId")) {
            var next = serviceDesk.group(in);
            if (!Objects.equals(next, t.getAssignmentGroupId())) changes.put("assignmentGroupId", Journals.listOf(t.getAssignmentGroupId(), next));
            t.setAssignmentGroupId(next);
        }
        if (t.changed()) t.store();
        if (!changes.isEmpty()) {
            var j = journals.write(ctx, f.wp(), changes, "", null, false);
            journals.fanOut(ctx, f.wp(), j, List.of());
        }
        if (Boolean.TRUE.equals(In.bool(in, "applyMatrix"))) {
            var priority = config.matrixPriority(f.project().id(), t.getImpact(), t.getUrgency()).orElse(null);
            if (priority != null && !priority.equals(f.wp().getPriorityId())) {
                return workPackages.update(ctx, number, Map.of("lockVersion", f.wp().getLockVersion(), "priorityId", priority.toString()));
            }
        }
        return workPackages.get(ctx, number);
    }
}
```

`workPackages.get(ctx, number)`의 실제 이름(상세 조회 메서드)은 `WorkPackageController`의 `GET /work-packages/{number}`가 부르는 메서드를 따른다. `ServiceDesk.level`과 `group`은 같은 패키지라 package-private로 둔다.

```java
    /** @param assigneeIds everyone who has the item: a "담당자일 때" rule applies to each of them (공동 담당자) */
    public static List<UUID> allowedStatusIds(Ctx ctx, UUID typeId, UUID statusId, UUID projectId, UUID authorId, java.util.Collection<UUID> assigneeIds) {
        var s = ctx.s();
        if (ctx.isAdmin()) return s.statuses().stream().map(Snapshot.StatusRow::id).filter(id -> !id.equals(statusId)).toList();

    /** The same for given roles, without the administrator's shortcut: the portal checks the built-in 요청자 role (ITSM 1단계). */
    public static List<UUID> allowedFor(Snapshot s, java.util.Collection<UUID> roleIds, UUID userId, UUID typeId, UUID statusId, UUID authorId,
                                        java.util.Collection<UUID> assigneeIds) {
        var out = new ArrayList<UUID>();
        for (var w : s.workflows()) {
            if (!w.typeId().equals(typeId) || !w.from().equals(statusId) || !roleIds.contains(w.roleId())) continue;
            boolean applies = switch (w.appliesTo()) {
                case "author" -> userId.equals(authorId);
                case "assignee" -> assigneeIds.contains(userId);
                default -> true;
            };
            if (applies && !out.contains(w.to())) out.add(w.to());
        }
        return out;
    }
```

```java
package com.openpms.itsm;

import static com.openpms.db.Tables.ATTACHMENTS;
import static com.openpms.db.Tables.CUSTOM_FIELDS;

import static com.openpms.db.Tables.PROJECT_CUSTOM_FIELDS;
import static com.openpms.db.Tables.SERVICE_TICKETS;
import static com.openpms.db.Tables.WORK_PACKAGES;

import com.openpms.api.Dto;
import com.openpms.common.ApiException;
import com.openpms.common.In;
import com.openpms.core.Ctx;
import com.openpms.core.Snapshot;
import com.openpms.wp.Assembler;
import com.openpms.wp.Assignees;
import com.openpms.wp.Journals;
import com.openpms.wp.WorkPackageService;
import java.time.OffsetDateTime;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.UUID;
import org.jooq.DSLContext;
import org.jooq.impl.DSL;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

/**
 * The requester's side of the service desk (docs/superpowers/specs/2026-10-14-itsm-design.md §4). Every read and
 * write is narrowed to service_tickets.requester_id = the caller; anything else is the same 404.
 */
@Service
public class PortalService {
    public record PortalField(UUID id, String name, String format, boolean required, boolean multi, List<String> options) {}

    public record PortalDesk(String identifier, String name, String descriptionText, List<Dto.IdName> types, List<PortalField> fields) {}

    public record PortalSummary(long number, String subject, String desk, String type, Dto.StatusRef status, OffsetDateTime createdAt,
                                OffsetDateTime updatedAt, boolean hasNews) {}

    public record PortalEntry(UUID id, String author, boolean fromMe, String notesHtml, String statusFrom, String statusTo, OffsetDateTime at) {}

    public record PortalFile(UUID id, String fileName, long byteSize, OffsetDateTime createdAt) {}

    public record FieldValue(String name, String value) {}

    public record PortalTicket(long number, String subject, String descriptionHtml, String desk, Dto.IdName type, Dto.StatusRef status, boolean closed,
                               OffsetDateTime createdAt, OffsetDateTime updatedAt, int lockVersion, List<Dto.IdName> allowedStatuses,
                               List<FieldValue> fields, List<PortalEntry> activity, List<PortalFile> files) {}

    private static final String NOT_FOUND = "요청을 찾을 수 없습니다.";

    private final DSLContext db;
    private final WorkPackageService workPackages;
    private final Journals journals;
    private final Assignees assignees;
    private final com.openpms.customfield.CustomFields customFields;

    public PortalService(DSLContext db, WorkPackageService workPackages, Journals journals, Assignees assignees,
                         com.openpms.customfield.CustomFields customFields) {
        this.db = db;
        this.workPackages = workPackages;
        this.journals = journals;
        this.assignees = assignees;
        this.customFields = customFields;
    }

    /* ---------- desks ---------- */

    private List<Snapshot.ProjectRow> desks(Snapshot s) {
        return s.projects().stream().filter(p -> p.archivedAt() == null && !p.isTemplate() && p.enabledModules().contains(ItsmIds.MODULE)).toList();
    }

    public List<PortalDesk> desks(Ctx ctx) {
        var s = ctx.s();
        return desks(s).stream().map(p -> new PortalDesk(p.identifier(), p.name(), com.openpms.common.Html.text(p.descriptionHtml()),
                p.typeIds().stream().filter(ItsmIds.TICKET_TYPES::contains).map(t -> s.type(t).map(x -> new Dto.IdName(x.id(), x.name())).orElseThrow()).toList(),
                fields(s, p))).toList();
    }

    private List<PortalField> fields(Snapshot s, Snapshot.ProjectRow p) {
        var visible = new HashSet<>(db.select(CUSTOM_FIELDS.ID).from(CUSTOM_FIELDS).where(CUSTOM_FIELDS.PORTAL_VISIBLE).fetch(CUSTOM_FIELDS.ID));
        var enabled = new HashSet<>(db.select(PROJECT_CUSTOM_FIELDS.CUSTOM_FIELD_ID).from(PROJECT_CUSTOM_FIELDS).where(PROJECT_CUSTOM_FIELDS.PROJECT_ID.eq(p.id()))
                .fetch(PROJECT_CUSTOM_FIELDS.CUSTOM_FIELD_ID));
        return s.customFields().stream()
                .filter(cf -> visible.contains(cf.id()) && (cf.isForAll() || enabled.contains(cf.id())) && cf.typeIds().stream().anyMatch(ItsmIds.TICKET_TYPES::contains))
                .map(cf -> new PortalField(cf.id(), cf.name(), cf.format(), cf.isRequired(), cf.isMultiValue(), cf.options().stream().map(Snapshot.OptionRow::value).toList()))
                .toList();
    }

    private Snapshot.ProjectRow desk(Snapshot s, String identifier) {
        return desks(s).stream().filter(p -> p.identifier().equals(identifier)).findFirst().orElseThrow(() -> ApiException.notFound("서비스 데스크를 찾을 수 없습니다."));
    }

    /* ---------- submit ---------- */

    @Transactional
    public PortalTicket submit(Ctx ctx, String identifier, Map<String, Object> in) {
        var s = ctx.s();
        var p = desk(s, identifier);
        var typeId = In.uuid(in, "typeId", "type");
        if (typeId == null || !ItsmIds.TICKET_TYPES.contains(typeId) || !p.typeIds().contains(typeId)) throw ApiException.field("type", "장애 신고나 서비스 요청을 고르세요.");
        // only what the portal offers goes on: no assignee, status, priority, dates or hidden fields
        var allowedFields = fields(s, p).stream().map(f -> f.id().toString()).collect(java.util.stream.Collectors.toSet());
        var custom = new HashMap<String, Object>();
        if (in.get("customValues") instanceof Map<?, ?> m) m.forEach((k, v) -> { if (allowedFields.contains(String.valueOf(k))) custom.put(String.valueOf(k), v); });
        var safe = new HashMap<String, Object>();
        safe.put("typeId", typeId.toString());
        safe.put("subject", In.str(in, "subject"));
        safe.put("descriptionHtml", In.str(in, "descriptionHtml"));
        if (In.has(in, "impact")) safe.put("impact", in.get("impact"));
        if (In.has(in, "urgency")) safe.put("urgency", in.get("urgency"));
        safe.put("customValues", custom);
        var w = workPackages.createForPortal(ctx, p, safe);
        return ticket(ctx, new WorkPackageService.Found(w, p), false);
    }

    /* ---------- my tickets ---------- */

    public WorkPackageService.Found find(Ctx ctx, long number) {
        var w = db.select(WORK_PACKAGES.fields()).from(WORK_PACKAGES).join(SERVICE_TICKETS).on(SERVICE_TICKETS.WORK_PACKAGE_ID.eq(WORK_PACKAGES.ID))
                .where(WORK_PACKAGES.NUMBER.eq(number), SERVICE_TICKETS.REQUESTER_ID.eq(ctx.userId())).fetchOneInto(WORK_PACKAGES);
        if (w == null) throw ApiException.notFound(NOT_FOUND);
        var p = ctx.s().project(w.getProjectId()).filter(x -> x.enabledModules().contains(ItsmIds.MODULE) && x.archivedAt() == null).orElse(null);
        if (p == null) throw ApiException.notFound(NOT_FOUND);
        return new WorkPackageService.Found(w, p);
    }

    /** Public news: a comment or a status change by someone else, after the requester last looked. */
    private org.jooq.Condition news(UUID requesterId) {
        return DSL.exists(DSL.selectOne().from(JOURNALS).where(JOURNALS.WORK_PACKAGE_ID.eq(SERVICE_TICKETS.WORK_PACKAGE_ID), JOURNALS.IS_INTERNAL.isFalse(),
                JOURNALS.USER_ID.ne(requesterId), JOURNALS.CREATED_AT.gt(DSL.coalesce(SERVICE_TICKETS.REQUESTER_SEEN_AT, SERVICE_TICKETS.CREATED_AT)),
                JOURNALS.NOTES_TEXT.ne("").or(DSL.field("{0} ? 'statusId'", Boolean.class, JOURNALS.CHANGES))));
    }

    public List<PortalSummary> list(Ctx ctx, String state) {
        var s = ctx.s();
        var closed = s.statuses().stream().filter(Snapshot.StatusRow::isClosed).map(Snapshot.StatusRow::id).toList();
        var where = SERVICE_TICKETS.REQUESTER_ID.eq(ctx.userId());
        if ("open".equals(state)) where = where.and(WORK_PACKAGES.STATUS_ID.notIn(closed));
        if ("closed".equals(state)) where = where.and(WORK_PACKAGES.STATUS_ID.in(closed));
        var hasNews = DSL.field(news(ctx.userId())).as("has_news");
        return db.select(WORK_PACKAGES.NUMBER, WORK_PACKAGES.SUBJECT, WORK_PACKAGES.PROJECT_ID, WORK_PACKAGES.TYPE_ID, WORK_PACKAGES.STATUS_ID,
                        WORK_PACKAGES.CREATED_AT, WORK_PACKAGES.UPDATED_AT, hasNews)
                .from(SERVICE_TICKETS).join(WORK_PACKAGES).on(WORK_PACKAGES.ID.eq(SERVICE_TICKETS.WORK_PACKAGE_ID))
                .where(where).orderBy(WORK_PACKAGES.UPDATED_AT.desc()).limit(200)
                .fetch(r -> new PortalSummary(r.value1(), r.value2(), s.project(r.value3()).map(Snapshot.ProjectRow::name).orElse(""),
                        s.type(r.value4()).map(Snapshot.TypeRow::name).orElse(""), com.openpms.wp.Refs.status(s, r.value5()), r.value6(), r.value7(),
                        Boolean.TRUE.equals(r.value8())));
    }

    @Transactional
    public PortalTicket open(Ctx ctx, long number) {
        var f = find(ctx, number);
        db.update(SERVICE_TICKETS).set(SERVICE_TICKETS.REQUESTER_SEEN_AT, OffsetDateTime.now()).where(SERVICE_TICKETS.WORK_PACKAGE_ID.eq(f.wp().getId())).execute();
        return ticket(ctx, f, true);
    }

    PortalTicket ticket(Ctx ctx, WorkPackageService.Found f, boolean withActivity) {
        var s = ctx.s();
        var w = f.wp();
        var status = s.status(w.getStatusId()).orElseThrow();
        var allowed = Assembler.allowedFor(s, Set.of(ItsmIds.ROLE_REQUESTER), ctx.userId(), w.getTypeId(), w.getStatusId(), ctx.userId(),
                Assignees.ids(assignees.of(w.getId()))).stream().map(id -> s.status(id).map(x -> new Dto.IdName(x.id(), x.name())).orElseThrow()).toList();
        var visible = fields(s, f.project()).stream().map(PortalField::id).collect(java.util.stream.Collectors.toSet());
        var values = customFields.values(s, w).entrySet().stream()
                .filter(e -> visible.contains(UUID.fromString(e.getKey())))
                .map(e -> new FieldValue(s.customField(UUID.fromString(e.getKey())).map(Snapshot.CustomFieldRow::name).orElse(""), display(e.getValue())))
                .toList();
        var activity = withActivity ? activity(ctx, w.getId()) : List.<PortalEntry>of();
        var files = db.selectFrom(ATTACHMENTS).where(ATTACHMENTS.WORK_PACKAGE_ID.eq(w.getId())).orderBy(ATTACHMENTS.CREATED_AT)
                .fetch(a -> new PortalFile(a.getId(), a.getFileName(), a.getByteSize(), a.getCreatedAt()));
        return new PortalTicket(w.getNumber(), w.getSubject(), w.getDescriptionHtml(), f.project().name(),
                s.type(w.getTypeId()).map(t -> new Dto.IdName(t.id(), t.name())).orElseThrow(), com.openpms.wp.Refs.status(s, w.getStatusId()),
                status.isClosed(), w.getCreatedAt(), w.getUpdatedAt(), w.getLockVersion(), allowed, values, activity, files);
    }

    private List<PortalEntry> activity(Ctx ctx, UUID wpId) {
        var s = ctx.s();
        var out = new ArrayList<PortalEntry>();
        for (var j : db.selectFrom(JOURNALS).where(JOURNALS.WORK_PACKAGE_ID.eq(wpId), JOURNALS.IS_INTERNAL.isFalse()).orderBy(JOURNALS.CREATED_AT).fetch()) {
            var changes = Journals.changesOf(j);
            var st = changes.get("statusId");
            String from = null, to = null;
            if (st != null) {
                from = st.get(0) == null ? null : s.status(UUID.fromString(String.valueOf(st.get(0)))).map(Snapshot.StatusRow::name).orElse(null);
                to = st.get(1) == null ? null : s.status(UUID.fromString(String.valueOf(st.get(1)))).map(Snapshot.StatusRow::name).orElse(null);
            }
            if (j.getNotesHtml().isEmpty() && to == null) continue;
            out.add(new PortalEntry(j.getId(), com.openpms.wp.Refs.user(s, j.getUserId()).name(), j.getUserId().equals(ctx.userId()), j.getNotesHtml(), from, to,
                    j.getCreatedAt()));
        }
        return out;
    }

    private static String display(Object v) {
        if (v instanceof Dto.CustomValue cv) return String.valueOf(cv.display());
        return String.valueOf(v);
    }
}
```

맞춰 볼 이름(실제 코드를 열어 고친다):
- `Journals.changesOf(JournalsRecord)`가 `private`면 `public static`으로 바꾼다(`fanOut`이 쓰는 것).
- `Refs.status(Snapshot, UUID)`가 없으면 `Assembler`가 `StatusRef`를 만드는 방식을 따른다.
- `customFields.values(s, w)`의 반환형(`Map<String, Dto.CustomValue>`)과 `CustomValue`의 표시 값 필드 이름에 맞게 `display`를 고친다.
- `s.customField(UUID)`가 없으면 `s.customFields()`에서 찾는다.
- `s.projects()`는 스냅숏의 프로젝트 목록 메서드 이름을 따른다.

```java
package com.openpms.itsm;

import static com.openpms.db.Tables.NOTIFICATIONS;
import static com.openpms.db.Tables.SERVICE_TICKETS;
import static com.openpms.db.Tables.WORK_PACKAGES;

import com.openpms.core.Ctx;
import com.openpms.core.Snapshot;
import com.openpms.db.tables.records.ServiceTicketsRecord;
import com.openpms.db.tables.records.WorkPackagesRecord;
import com.openpms.webhook.Webhooks;
import com.openpms.wp.Assignees;
import java.time.Duration;
import java.time.Instant;
import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import java.util.LinkedHashSet;
import java.util.Map;
import java.util.Set;
import java.util.UUID;
import java.util.function.Supplier;
import org.jooq.DSLContext;
import org.jooq.TableField;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

/** Every minute: SLA deadlines that are close (20 % left) or past, announced once to the ticket's people (ITSM 1단계 §5). */
@Component
public class SlaJobs {
    private final DSLContext db;
    private final ServiceDeskConfig config;
    private final Assignees assignees;
    private final Webhooks webhooks;
    private final Supplier<Snapshot> snapshots;

    public SlaJobs(DSLContext db, ServiceDeskConfig config, Assignees assignees, Webhooks webhooks, com.openpms.core.Snapshots snapshots) {
        this.db = db;
        this.config = config;
        this.assignees = assignees;
        this.webhooks = webhooks;
        this.snapshots = snapshots::load;
    }

    @Transactional
    public int run(Instant now) {
        var s = snapshots.get();
        int sent = 0;
        var rows = db.select().from(SERVICE_TICKETS).join(WORK_PACKAGES).on(WORK_PACKAGES.ID.eq(SERVICE_TICKETS.WORK_PACKAGE_ID))
                .where(SERVICE_TICKETS.RESOLVED_AT.isNull(), SERVICE_TICKETS.PAUSED_SINCE.isNull(), SERVICE_TICKETS.SLA_POLICY_ID.isNotNull())
                .fetch();
        for (var r : rows) {
            var t = r.into(SERVICE_TICKETS);
            var w = r.into(WORK_PACKAGES);
            var p = s.project(w.getProjectId()).orElse(null);
            if (p == null || p.archivedAt() != null || !p.enabledModules().contains(ItsmIds.MODULE)) continue;
            var policy = config.policyFor(w.getProjectId(), w.getTypeId(), w.getPriorityId()).orElse(null);
            if (policy == null) continue;
            var holidays = s.calendar().holidays();
            if (t.getFirstRespondedAt() == null && t.getFirstResponseDueAt() != null) {
                sent += check(s, p, w, t, now, "response", t.getFirstResponseDueAt(), policy.firstResponse(), policy, holidays,
                        SERVICE_TICKETS.RESPONSE_BREACHED, SERVICE_TICKETS.RESPONSE_WARNED);
            }
            if (t.getResolveDueAt() != null) {
                sent += check(s, p, w, t, now, "resolve", t.getResolveDueAt(), policy.resolve(), policy, holidays,
                        SERVICE_TICKETS.RESOLVE_BREACHED, SERVICE_TICKETS.RESOLVE_WARNED);
            }
        }
        return sent;
    }

    private int check(Snapshot s, Snapshot.ProjectRow p, WorkPackagesRecord w, ServiceTicketsRecord t, Instant now, String kind, OffsetDateTime due,
                      Duration target, ServiceDeskConfig.Policy policy, Set<java.time.LocalDate> holidays,
                      TableField<ServiceTicketsRecord, Boolean> breached, TableField<ServiceTicketsRecord, Boolean> warned) {
        if (!due.toInstant().isAfter(now)) {
            // set once: a second run, or another instance, finds it already set
            int marked = db.update(SERVICE_TICKETS).set(breached, true).set(warned, true)
                    .where(SERVICE_TICKETS.WORK_PACKAGE_ID.eq(t.getWorkPackageId()), breached.isFalse()).execute();
            if (marked == 0) return 0;
            webhooks.enqueueSystem(s, w, "service_ticket.sla_breached", Map.of("sla", Map.of("kind", kind, "dueAt", due.toString())));
            return announce(s, p, w, t, "sla_breached", now);
        }
        var left = SlaClock.workingTime(now, due.toInstant(), policy.calendar(), holidays);
        if (left.multipliedBy(5).compareTo(target) > 0) return 0; // more than 20 % left
        int marked = db.update(SERVICE_TICKETS).set(warned, true)
                .where(SERVICE_TICKETS.WORK_PACKAGE_ID.eq(t.getWorkPackageId()), warned.isFalse()).execute();
        return marked == 0 ? 0 : announce(s, p, w, t, "sla_warning", now);
    }

    private int announce(Snapshot s, Snapshot.ProjectRow p, WorkPackagesRecord w, ServiceTicketsRecord t, String reason, Instant now) {
        var people = new LinkedHashSet<UUID>(Assignees.ids(assignees.of(w.getId())));
        if (t.getAssignmentGroupId() != null && s.groups().containsKey(t.getAssignmentGroupId())) people.addAll(s.groups().get(t.getAssignmentGroupId()).memberIds());
        var recipients = people.stream().filter(id -> canSee(s, id, p)).toList();
        if (recipients.isEmpty()) {
            recipients = s.projectUsers(p.id()).stream().map(Snapshot.UserRow::id).filter(id -> new Ctx(id, () -> s).can(p, "service.manage")).toList();
        }
        var at = now.atOffset(ZoneOffset.UTC);
        for (var id : recipients) {
            db.insertInto(NOTIFICATIONS).set(NOTIFICATIONS.RECIPIENT_ID, id).set(NOTIFICATIONS.WORK_PACKAGE_ID, w.getId()).set(NOTIFICATIONS.PROJECT_ID, p.id())
                    .set(NOTIFICATIONS.REASON, reason).set(NOTIFICATIONS.CREATED_AT, at).set(NOTIFICATIONS.UPDATED_AT, at).execute();
        }
        return recipients.size();
    }

    private static boolean canSee(Snapshot s, UUID userId, Snapshot.ProjectRow p) {
        var u = s.user(userId).filter(x -> "active".equals(x.status())).orElse(null);
        return u != null && new Ctx(userId, () -> s).can(p, "service.view");
    }
```

```java
package com.openpms.itsm;

import static com.openpms.db.Tables.JOURNALS;
import static com.openpms.db.Tables.SERVICE_TICKETS;
import static com.openpms.db.Tables.USERS;
import static com.openpms.db.Tables.WORK_PACKAGES;

import com.openpms.common.Html;
import com.openpms.common.Mailer;
import com.openpms.core.Snapshot;
import com.openpms.wp.Journals;
import java.time.Instant;
import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import java.util.UUID;
import java.util.function.Supplier;
import org.jooq.DSLContext;
import org.jooq.impl.DSL;
import org.springframework.stereotype.Component;

/**
 * Mail to requesters, who are not project members and so get nothing from the notification centre (ITSM 1단계):
 * a receipt, then one mail per batch of public answers and status changes by others.
 */
@Component
public class PortalMail {
    static final java.time.Duration SETTLE = java.time.Duration.ofMinutes(1);

    private final DSLContext db;
    private final Mailer mailer;
    private final Supplier<Snapshot> snapshots;
    private final Supplier<String> appUrl;

    public PortalMail(DSLContext db, Mailer mailer, com.openpms.core.Snapshots snapshots, com.openpms.jobs.MailJobs mailJobs) {
        this.db = db;
        this.mailer = mailer;
        this.snapshots = snapshots::load;
        this.appUrl = mailJobs::appUrl;
    }

    public int run(Instant now) {
        var s = snapshots.get();
        int sent = 0;
        var settled = now.minus(SETTLE).atOffset(ZoneOffset.UTC);
        var rows = db.select(SERVICE_TICKETS.WORK_PACKAGE_ID, SERVICE_TICKETS.REQUESTER_ID, SERVICE_TICKETS.REQUESTER_MAILED_AT, WORK_PACKAGES.NUMBER,
                        WORK_PACKAGES.SUBJECT, WORK_PACKAGES.PROJECT_ID, USERS.EMAIL, USERS.STATUS)
                .from(SERVICE_TICKETS).join(WORK_PACKAGES).on(WORK_PACKAGES.ID.eq(SERVICE_TICKETS.WORK_PACKAGE_ID))
                .join(USERS).on(USERS.ID.eq(SERVICE_TICKETS.REQUESTER_ID))
                .where(SERVICE_TICKETS.REQUESTER_MAILED_AT.isNull().or(DSL.exists(DSL.selectOne().from(JOURNALS).where(
                        JOURNALS.WORK_PACKAGE_ID.eq(SERVICE_TICKETS.WORK_PACKAGE_ID), JOURNALS.IS_INTERNAL.isFalse(),
                        JOURNALS.USER_ID.ne(SERVICE_TICKETS.REQUESTER_ID), JOURNALS.CREATED_AT.gt(SERVICE_TICKETS.REQUESTER_MAILED_AT),
                        JOURNALS.CREATED_AT.le(settled)))))
                .fetch();
        for (var r : rows) {
            UUID wpId = r.value1();
            OffsetDateTime last = r.value3();
            String subject, body;
            var link = appUrl.get() + "/portal/tickets/" + r.value4();
            var desk = s.project(r.value6()).map(Snapshot.ProjectRow::name).orElse("서비스 데스크");
            if (last == null) {
                subject = "[openPMS] #" + r.value4() + " 요청이 접수되었습니다: " + r.value5();
                body = desk + "에 요청이 접수되었습니다.\n\n" + r.value5() + "\n\n진행 상황: " + link + "\n";
            } else {
                var text = new StringBuilder();
                boolean resolved = false;
                for (var j : db.selectFrom(JOURNALS).where(JOURNALS.WORK_PACKAGE_ID.eq(wpId), JOURNALS.IS_INTERNAL.isFalse(),
                        JOURNALS.USER_ID.ne(r.value2()), JOURNALS.CREATED_AT.gt(last), JOURNALS.CREATED_AT.le(settled)).orderBy(JOURNALS.CREATED_AT).fetch()) {
                    var who = com.openpms.wp.Refs.user(s, j.getUserId()).name();
                    var st = Journals.changesOf(j).get("statusId");
                    if (st != null && st.get(1) != null) {
                        var to = s.status(UUID.fromString(String.valueOf(st.get(1)))).orElse(null);
                        if (to != null) {
                            text.append(who).append(": 상태 → ").append(to.name()).append('\n');
                            resolved = to.isClosed();
                        }
                    }
                    if (!j.getNotesText().isEmpty()) text.append(who).append(":\n").append(j.getNotesText()).append("\n\n");
                }
                if (text.isEmpty()) {
                    mark(wpId, last, now);
                    continue;
                }
                subject = "[openPMS] #" + r.value4() + (resolved ? " 요청이 해결되었습니다: " : " 새 답변: ") + r.value5();
                body = text + "\n진행 상황: " + link + "\n";
            }
            if (!"active".equals(r.value8())) {
                mark(wpId, last, now);
                continue;
            }
            if (!mark(wpId, last, now)) continue; // another instance took it
            if (mailer.send(r.value7(), subject, body)) sent++;
        }
        return sent;
    }

    /** Moves requester_mailed_at on if nobody else did since we read it. */
    private boolean mark(UUID wpId, OffsetDateTime last, Instant now) {
        var cond = last == null ? SERVICE_TICKETS.REQUESTER_MAILED_AT.isNull() : SERVICE_TICKETS.REQUESTER_MAILED_AT.eq(last);
        return db.update(SERVICE_TICKETS).set(SERVICE_TICKETS.REQUESTER_MAILED_AT, now.minus(SETTLE).atOffset(ZoneOffset.UTC))
                .where(SERVICE_TICKETS.WORK_PACKAGE_ID.eq(wpId), cond).execute() == 1;
    }
}
```

```ts
// 백엔드 itsm/SlaClock과 같은 규칙: 24x7은 그대로 더하고, 근무 시간 달력은 요일별 창만 센다(휴무일 제외).
// 가짜 계층은 Asia/Seoul(UTC+9, 서머타임 없음)만 계산한다.
export interface Window { day: number; start: string; end: string } // day: ISO 1(월)~7(일)
export interface Calendar { allDay: boolean; windows: Window[] }

const OFFSET = 9 * 3600_000;
const MIN = 60_000;
const minutesOf = (hhmm: string) => Number(hhmm.slice(0, 2)) * 60 + Number(hhmm.slice(3, 5));
const localDay = (t: number) => Math.floor((t + OFFSET) / 86_400_000); // 서울 기준 날짜 번호
const isoDay = (dayNo: number) => ((new Date(dayNo * 86_400_000).getUTCDay() + 6) % 7) + 1;
const dateKey = (dayNo: number) => new Date(dayNo * 86_400_000).toISOString().slice(0, 10);
const at = (dayNo: number, minutes: number) => dayNo * 86_400_000 - OFFSET + minutes * MIN;

function windowsOn(cal: Calendar, dayNo: number, holidays: Set<string>): [number, number][] {
  if (holidays.has(dateKey(dayNo))) return [];
  return cal.windows
    .filter((w) => w.day === isoDay(dayNo))
    .map((w) => [at(dayNo, minutesOf(w.start)), at(dayNo, minutesOf(w.end))] as [number, number])
    .sort((a, b) => a[0] - b[0]);
}

/** start(ms) + minutes of calendar time → ms */
export function addMinutes(start: number, minutes: number, cal: Calendar, holidays: Set<string>): number {
  if (cal.allDay) return start + minutes * MIN;
  if (cal.windows.length === 0) throw new Error("근무 시간이 없는 달력입니다.");
  let left = minutes * MIN;
  let cursor = start;
  for (let i = 0; i < 3660; i++) {
    const day = localDay(cursor);
    for (const [open, close] of windowsOn(cal, day, holidays)) {
      const from = Math.max(cursor, open);
      if (from >= close) continue;
      const room = close - from;
      if (left <= room) return from + left;
      left -= room;
      cursor = close;
    }
    cursor = at(day + 1, 0);
  }
  throw new Error("SLA 기한을 계산할 수 없습니다.");
}

/** calendar time in [from, to) in ms */
export function workingMs(from: number, to: number, cal: Calendar, holidays: Set<string>): number {
  if (to <= from) return 0;
  if (cal.allDay) return to - from;
  let total = 0;
  for (let day = localDay(from); at(day, 0) < to; day++) {
    for (const [open, close] of windowsOn(cal, day, holidays)) {
      const a = Math.max(from, open);
      const b = Math.min(to, close);
      if (a < b) total += b - a;
    }
  }
  return total;
}
```

```ts
import type { Sla } from "../../api/types";

export type SlaState = "breached" | "paused" | "warning" | "ok" | "met" | "none";
const WARN_MS = 2 * 3600_000;

export function slaState(sla: Sla, now: number): SlaState {
  if (!sla.resolveDueAt && !sla.firstResponseDueAt) return "none";
  if (sla.responseBreached || sla.resolveBreached) return "breached";
  if (sla.resolvedAt) return "met";
  if (sla.paused) return "paused";
  const due = [sla.firstRespondedAt ? null : sla.firstResponseDueAt, sla.resolveDueAt].filter((x): x is string => !!x).map(Date.parse);
  if (due.some((d) => d <= now)) return "breached"; // 작업이 아직 표시하지 않았어도 지난 것은 지난 것
  return due.some((d) => d - now <= WARN_MS) ? "warning" : "ok";
}

export function remainingLabel(dueAt: string | null, now: number): string {
  if (!dueAt) return "";
  const diff = Date.parse(dueAt) - now;
  const m = Math.round(Math.abs(diff) / 60_000);
  const text = m >= 60 ? `${Math.floor(m / 60)}시간${m % 60 ? ` ${m % 60}분` : ""}` : `${m}분`;
  return diff >= 0 ? `${text} 남음` : `${text} 지남`;
}
```
